# 平台模型能力测试与组织默认文本模型

平台测试台只供现有 platform operator 使用。operator 必须是测试目标正式组织的真实成员，费用和配额归因于该 operator；不允许在请求中指定其他 billed user、密钥或 endpoint。公共百炼目录不授予真实调用权限。只有组织已启用、部署绑定经过核实、计量及不可变价格满足有限预留的正式模型，才可测试。

测试流程：选择组织、能力、可用模型；提供明确非保密样本与费用/输出/原生数量/时间上界；显式启动。测试 UUID 与主体及输入不可变，同 UUID 仅查询或恢复结算，不重发厂商调用。结果和结算独立显示；缺少真实 usage 或取消后的未知结果保留预留。取消在当前进程转发 AbortSignal，跨实例的停止不能靠数据库状态假称完成。暂未实现安全关闭证明的预留不会制造零费用释放。

组织 admin 可保存一个默认文本模型，并填写审计原因。选中绑定包含正式模型、真实 provider/API ID 和配置 revision；私有连接标识仅内部保存。新默认助手 run 在受理事务冻结该选择，部署绑定变化导致明确不可用。其他 agent 的既有模型 pin、历史 run、重放和重试保持原选择。图片与语音分别使用对应能力模型。

实现范围与验收

- 已有 JSON 目录和配额 PR 分别为 #5373、#5269；本功能 issue #5374 依赖两者，独立工作树实现。
- 前端已完成能力表单、显式费用上界、查询/取消与未知状态；组织默认选择包含版本冲突刷新和审计。
- 已接通可信适配与准入账本，提供文本、图片、embedding、rerank、Qwen TTS 和 Qwen ASR 客户端。实际可用性须部署注册、账号配置及冻结价格验证。ASR 缺严格 Token 上界，普通组织明确不可用；企业组织仍有费用和时长上界。真实供应商报告的输入/输出明细可保存，未知总量不伪报零。
- 本地测试采用替代依赖；组件浏览器截图明确替代 API，不代表正常登录、数据库、付费供应商或全链路验收。
- 本地未启动数据库、Docker或迁移，没有修改生产额度或权限。实际 PostgreSQL 验证交由正常 CI；部署和合并由父线程协调。
