# Board 十轮交付计划

用户于 2026-09-23 授权开始开发，Studio 增加顶级菜单 `Board`。每轮是可审查交付增量，不是重复运行十次同一检查。范围仍以 requirements.md 为准；各轮完成必须有真实证据，不因达到轮数自动判定需求完成。

| 轮次 | 交付与依赖 | 验收出口 | 当前状态 |
|---|---|---|---|
| 1 | Studio `/studio/board`、可复用白板交互组件、七态与响应式，材料审阅 | 导航、便签/图形/连线、拖动、撤销/重做、批量输入的真实浏览器交互 | UI 预览已实现；不是持久化产品 |
| 2 | 完成领域对象、契约束/签核、组织与项目授权、白板生命周期 | 创建/重开/归档/授权/越权负例；服务端与数据库证据 | 未开始，需注册身份与设计门槛 |
| 3 | Yjs 房间、更新验证、可靠日志/快照、连接凭证、撤权 | 两浏览器并发编辑、持久 ACK、崩溃恢复、恶意更新拒绝 | 未开始；依赖轮2 |

## 不可替代的外部条件

- 目标组织真实 Miro 样板与授权、试点人员、会议室硬件和开源许可证决策不能凭空生成。
- 仓库要求注册 agent 身份与 coord-gateway 接入；当前任务未获身份指定，不冒用 `coord-main` 或其他 worker。
- 束级 UI/用例/API 及一致性复核由人类确认，agent 不把状态改为 confirmed。当前只有需求草案与第一轮 UI 材料，不能当成已签契约。

独立 issue/PR 按用户目标拆分；本轮追踪 [#3902](https://github.com/boardx/workspacex/issues/3902)，不把未来九轮提前标为 in_progress 或 passing。
