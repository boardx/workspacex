# Team3 界面证据（R9「看一眼」的留痕）

> 评分卡 `agent-team3-acceptance-rubric.md` 的 U5 维度只有一条判据：
> **有人真的看过一眼**。这个目录就是那一眼的留痕。
>
> 这些图不是装饰。2026-09-15 这一轮里，**三个真缺陷是靠看图发现的**，
> 而它们在 tsc / eslint / 单元测试下全部是绿的：

| # | 缺陷 | 为什么四层检查都抓不到 |
|---|---|---|
| 1 | mermaid 节点标签里的 `<br>` 原样显示成字面文本 | 没有任何一层会对一段它不认识的文本报错，它只是忠实地把字面量画出来 |
| 2 | 门②文案里的 markdown `**粗体**` 显示成两个星号 | 同上——JSX 不渲染 markdown，而"不渲染"不是错误 |
| 3 | 主确认按钮可点态与禁用态**完全同色** | Button 默认 variant 是灰色 secondary；类型正确、属性正确，只是看不出来 |

三条都已修复并补了回归断言。

## 一处**没有**看过的界面，如实记下

**审计栏（`ResearchAuditTrail`，含「Agent 曾 N 次试图跳过人工确认」那一行）没有截图。**

原因是我的截图脚手架喂不进它需要的数据（它自己发请求，而脚手架里的 fetch 替身
没能生效），不是它坏了。它由 `tests/ui/research-gate-panel.test.tsx` 的 24 条
真渲染测试覆盖，包括跳门次数那一行的正反两面。

按本仓「静态痕迹 ≠ 动态事实」的规矩，这一条**不计入 U5 得分**——
被测试覆盖和被人看过是两件事，不能互相顶替。
