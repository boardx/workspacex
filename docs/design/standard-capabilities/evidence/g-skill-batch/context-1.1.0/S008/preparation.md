## 4. 关键问题（需在会前或会中回答）

1. **样本代表性**：3 名样本的选取标准是什么？是否覆盖关键用户画像或使用场景？
2. **验证指标**：原型验证的成功/失败判定标准是什么？采用定性、定量还是混合方法？
3. **统计/置信度局限**：在 n=3 条件下，哪些结论可信、哪些仅作探索性参考？是否需要补充样本或改用案例研究框架？
4. **预算边界**：可用预算区间是多少？是否存在审批节点或资金到位时间约束？
5. **时间约束**：原型验证的最早启动时间与最晚完成时间分别是什么？与其他里程碑有无依赖？
6. **利益相关方**：除项目组外，是否有产品、合规、用户研究等角色需要参与决策？
7. **风险容忍度**：若验证结果因样本不足而无法得出强结论，团队的备选路径是什么（扩大样本 / 延长周期 / 调整验证范围）？
