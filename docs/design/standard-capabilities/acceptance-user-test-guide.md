# WorkspaceX 普通用户验收手册

> 本手册供不熟悉代码、数据库或自动化测试的业务用户使用。只需打开 WorkspaceX、按步骤操作并记录结果。开发和 QA 的技术矩阵见 [三维验收方案](acceptance-test-plan.md)。

## 1. 开始前

测试负责人应提供测试网址、版本 SHA、组织 A 和组织 B、组织 A 的管理员与普通成员账号、组织 B 普通成员账号、示例项目、组织知识库、只读示例数据库，以及以下合成附件：

- 中文 PDF、DOCX、XLSX、PPTX、PNG 和 CSV。
- 30 秒中英文音频、静音音频、损坏文件、密码保护 PDF。
- 所有文件必须是测试数据，不含真实客户资料、身份证件、密码或 API Key。

建议使用 Chrome。用普通窗口登录组织 A，用无痕窗口登录组织 B。每个场景开始前新建聊天，除非步骤明确要求沿用原线程。页面若要求普通用户输入系统密钥，立即停止并记为失败。

## 2. 记录方法

每个场景选择一个结论：

- **通过**：实际结果与“应该看到”全部一致。
- **失败**：结果错误、越权、数据丢失、重复执行、卡死或假成功。
- **受阻**：环境缺数据、模型或服务，尚未执行到功能判断。

复制以下表格填写：

| 项目 | 记录 |
|---|---|
| 场景编号 | UAT- |
| 测试账号和组织 | |
| 开始和结束时间 | |
| 结果 | 通过 / 失败 / 受阻 |
| 实际看到 | |
| 截图或下载文件 | |
| 错误提示 | |
| 刷新后是否复现 | |

截图应包含地址栏、主要结果和错误提示。下载文件保留原名，不要修改后充当系统产物。

## 3. 用户验收场景

### UAT-01 基础对话、连续对话和线程切换

1. 新建聊天，发送：“我正在准备一个面向大学生的阅读活动。请只回复三个活动目标。”
2. 回复结束后发送：“把刚才的第二个目标改写得更容易衡量，不要重复其他两个。”
3. 刷新浏览器。
4. 切换到另一个聊天，再切回来。

应该看到：第一轮持续出现回复；第二轮正确引用第一轮；刷新和切换后消息顺序、内容和状态不变；不会重复回复或永久停在运行中。

失败示例：忘记上一轮、刷新丢消息、切错线程、整页白屏。

覆盖：路径 P-A1/A2/A4/A5；WX-E001/E006、WX-T040。

### UAT-02 计划、补参和人工确认

1. 发送：“帮我制定下周客户研究计划。”
2. 在补参卡片填写目标客户“新注册用户”、访谈人数“5”、完成时间“下周五”。
3. 如果出现方案选择，选择第二个方案。
4. 如果出现工具授权，先选择“拒绝”，确认没有文件或外部动作；重新开始后选择“仅本次允许”。
5. 刷新页面，确认仍是同一个待处理请求或完成结果。
6. 新建聊天发送：“1+1 等于多少？”

应该看到：复杂任务允许修改假设和参数；后续使用修改后的值；拒绝后无副作用；第二个方案只执行方案 B；简单问题直接回答。

失败示例：拒绝后仍执行、刷新生成新的审批、选择 B 却执行 A、简单问题强制复杂计划。

覆盖：P-B1 至 P-B7；WX-T009/T011/T012/T013。

### UAT-03 附件、文件与隔离计算

1. 上传中文 TXT、PNG 和 CSV。
2. 发送：“列出我刚上传的文件，读取中文文本前五行，描述图片，计算 CSV 数值列总和，并把过程保存成 result.txt。”
3. 下载 result.txt，核对答案。
4. 发送：“把 result.txt 中的‘总和’替换为‘合计’，其他文字不要修改。”
5. 下载新版并比较。

应该看到：中文名完整；图片描述正确；总和与标准答案一致；第二版只改变目标词；文件可预览、下载并真实打开。

失败示例：访问未上传文件、乱码、修改无关内容、显示成功但文件为空或不能下载。

覆盖：WX-T001 至 WX-T008、WX-T018、WX-T020/T021。

### UAT-04 联网研究

1. 发送：“搜索今天可公开访问的三个 AI 行业来源，比较它们对同一趋势的看法。每个结论附可打开链接，并指出分歧。”
2. 打开每个引用并核对。
3. 由负责人启用“搜索服务失败”开关，再重复请求。

应该看到：链接可打开且支持结论；分歧被保留；服务失败时明确说明无法核实，不生成假来源。

失败示例：链接无关、失败时仍声称已搜索、访问本机或内网地址。

覆盖：P-A3；WX-T014/T015、WX-S002。

### UAT-05 组织知识和项目报告

1. 用组织 A 询问：“根据测试项目 Alpha 的资料，总结目标、进度和风险，每个关键结论附来源。”
2. 打开引用核对原文。
3. 让管理员撤销一篇测试资料的访问权限，再询问只存在于该资料中的事实。
4. 用组织 B 询问同一项目。

应该看到：回答与资料一致；未知字段明确标注；撤权后不再引用旧资料；组织 B 看不到名称、内容或项目是否存在。

覆盖：WX-T016/T017/T027/T028、WX-S001/S008/S014。

### UAT-06 文档解析与理解

依次上传 PDF、DOCX、XLSX、扫描图片、损坏文件和密码 PDF，发送：“分别给出标题、页数或工作表、关键表格，并标出所在页码或位置。无法读取的文件单独说明原因。”

应该看到：内容和表格与原件一致；扫描页标注 OCR 和不确定内容；损坏或加密文件明确失败；撤销附件权限后不能从旧缓存继续回答。

覆盖：WX-T018/T019、WX-S018。

### UAT-07 Word、Excel、PowerPoint 和 PDF

分别执行四个请求，每次都下载、关闭并重新打开产物：

1. Word：“生成两页中文 Word 报告，含标题、三段正文、三行表格和页眉。随后只修改第二段第一句。”
2. Excel：“生成销售和汇总两个工作表，汇总用公式求和。随后只改销售表第二行金额并重算。”
3. PowerPoint：“生成四页中文演示：封面、问题、方案、下一步。随后只改第三页标题。”
4. PDF：“生成三页 PDF，第二页含中文表格，第三页含可填写的验收人字段。”

应该看到：四类文件都能打开；中文不乱码、不裁切；页数或工作表正确；有限编辑只改变目标；Excel 公式正确；PDF 表单保存后重开仍有值。

失败示例：只验证文件大小、未知对象静默丢失、用覆盖矩形冒充安全脱敏。

覆盖：P-C6/C7；WX-T008/T019-T021、WX-S003 至 WX-S006。

### UAT-08 画布和 19 个内置模板

1. 管理员打开画布模板库，逐个确认：用户画像、PESTEL、SWOT、同理心地图、待完成工作、用户旅程、价值主张画布、价值主张宣言、商业模式、MVP 实验、戏剧结构金字塔、汉堡沟通、三地平线、HMW、黄金圈、三视角、故事板、AI 战略、AI 商业模型。
2. 任选五个版式不同的模板预览。
3. 将“用户画像”绑定到测试项目，在 chat 中要求填入三张便签。
4. 放大，移动一张便签并保存；刷新后重开。
5. 在另一个窗口同时编辑同一便签。
6. 创建组织模板，完成试跑、发布、采用、归档、恢复。
7. 用组织 B 检查其不可见。

应该看到：19 个名称无重复；标题、分区、便签和连线不遮挡；保存后对象 ID 和分区正确；并发冲突不静默覆盖；归档不破坏既有实例；组织 B 不可见。

覆盖：P-C1 至 P-C4；WX-T029/T030、WX-S012、AT-C001 至 AT-C027。

### UAT-09 网页产物与浏览器操作

1. 发送：“制作一个单页活动报名网页，包含姓名、邮箱、提交按钮和空状态，并适配手机。”
2. 打开预览，切换桌面和手机宽度。
3. 填写表单并提交。
4. 下载网页 bundle 并再次打开。

应该看到：按钮可用；手机无横向溢出；提交只发生一次；bundle 含真实 HTML。

失败示例：工具传输失败却显示完成、访问未授权内网、下载只有说明文字。

覆盖：WX-T022 至 WX-T026、WX-S013。

### UAT-10 个人记忆

1. 发送：“请记住：我偏好中文回复，日期格式为 YYYY-MM-DD。”
2. 新建聊天询问日期偏好。
3. 发送：“忘记我的日期格式偏好。”
4. 再新建聊天询问。
5. 用第二个用户询问第一个用户的偏好。

应该看到：明确保存后跨会话生效；删除后不再使用；第二个用户看不到。

覆盖：WX-T031 至 WX-T033。

### UAT-11 定时任务

1. 创建十分钟后执行的测试提醒。
2. 查看列表和下次执行时间。
3. 取消并重复取消。
4. 再创建两分钟后的任务并等待。

应该看到：时区正确；取消幂等且不会运行；未取消任务只产生一个 run；重启页面后仍可查。

覆盖：WX-E009、WX-T034 至 WX-T036。

### UAT-12 音频、纪要和图片

1. 上传测试音频，要求转录并生成纪要。
2. 核对中英文片段、时间范围、决定和行动项。
3. 上传静音和损坏音频。
4. 发送：“生成一张 16:9 中文活动海报，标题‘阅读周’，蓝色背景。”

应该看到：纪要可定位原句或时间；未知说话人不被命名；静音和损坏文件明确处理；图片可打开且尺寸、文字正确。

覆盖：P-E1/E2；WX-T037/T038、WX-S009/S016/S017。

### UAT-13 数据分析和图表

上传测试 CSV，发送：“分析各组平均值和缺失值，生成可重跑的计算脚本与柱状图。不要把相关性解释为因果。”

应该看到：数值与标准答案一致；缺失值策略写清；图表标签和颜色可辨；脚本重跑一致；缺失值没有被画成零。

覆盖：WX-S007/S020、WX-T008/T020。

### UAT-14 访谈研究和内部沟通

1. 上传三份访谈，其中两份重复。
2. 要求综合主题、反对证据、引用和后续研究计划。
3. 要求生成内部沟通草稿，但不要发送。

应该看到：重复记录不重复计数；每个主题有来源；不推断缺失的人口属性；沟通稿保持草稿，无外发副作用。

覆盖：WX-S010/S011/S019。

### UAT-15 创建和挂载 Skill

1. 发送：“创建个人 Skill 草稿：输入一组数字，输出数量和总和。包含 SKILL.md、示例和验证脚本。只保存草稿。”
2. 在 Skill 页面打开文件树，确认文件可读。
3. 试跑正确输入和非数字输入。
4. 临时挂载到当前聊天，刷新后再次使用。

应该看到：草稿未自动发布；正确输入准确；错误输入诚实失败；刷新后挂载一致；普通用户不能修改平台 Skill。

覆盖：P-D3/D4；WX-T039、WX-S015、WX-E004。

### UAT-16 后台子任务、产物与取消

1. 发送：“后台生成三份独立文件：摘要.txt、数据.csv、说明.pdf。主任务继续显示状态。”
2. 关闭聊天页再返回。
3. 等待完成并下载三个文件。
4. 重复一次，但在运行中取消。

应该看到：返回后仍是同一批任务；三个文件回到父会话并可打开；取消后子任务停止，不出现晚到文件。

失败示例：只在内存显示完成、刷新消失、文件挂到错误子任务、取消后继续发布。

覆盖：P-C8/D6/F5；WX-T010/T020/T021/T040 至 WX-T042。

### UAT-17 SQL 只读分析

1. 连接负责人提供的只读示例数据库。
2. 发送：“列出我可以访问的表，并说明 sales 表字段。”
3. 发送：“检查并执行查询：统计每个月销售总额。”
4. 发送：“把 sales 表所有金额改成 0。”
5. 用另一个账号重复列表。

应该看到：只列授权表；schema 和统计值正确；修改请求被拒；账号间范围隔离；页面和日志不显示连接密码。

覆盖：WX-T043 至 WX-T046。

### UAT-18 断线、并发、失败与性能感受

1. 同时打开两个聊天，各发送一个约一分钟的任务。
2. 第一个任务运行时断网十秒，再恢复。
3. 对第二个任务依次暂停、恢复、取消。
4. 由负责人启用模型断流测试。
5. 记录每步开始、结束时间和是否卡死。

应该看到：两个 run 的消息、轨迹和文件不串线；重连后从原 run 续上；控制动作真实生效；断流后出现可理解终态，输入框仍可用。

普通用户只记录时间和感受，不计算 p50/p95。系统按性能标准分析原始样本。

覆盖：P-E4、P-F1 至 P-F7、PERF-07 至 PERF-10。

## 4. 最终签收

测试负责人汇总：

- 18 个 UAT 场景分别通过、失败或受阻多少项。
- 37 条路径是否仍有未覆盖或当前红。
- 46 Tools、20 Skills、9 个前置和 19 个模板是否都有正向与反向证据。
- 文件是否被真实打开，而非只看到下载卡片。
- 是否发生跨用户、跨组织或撤权后仍可访问。
- 性能样本是否由系统生成并绑定同一个版本 SHA。

只要出现越权、凭据泄露、假成功、取消后继续产生副作用、文件无法打开任一问题，该版本不能签收。
