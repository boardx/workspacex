# 组织首页前台展示重设计

当前范围：只改前台展示。后台配置界面、字段、提交体、数据结构、API 与认证保持原基线。用户已明确要求“后台不要改，只改前段的展示，需要展示的更专业”。本 PR 已撤回此前引入的后台人物编辑界面改动、编辑 fixture 和保存闭环测试。

基线：origin/main `98168015c`。草稿 PR：https://github.com/boardx/workspacex/pull/5699。Refs #4634。

## 当前设计

- 数字人成为首页主要协作对象：完整人物形象、姓名、角色、既有配置的用途说明及明确“开始对话”入口。
- 使用现有第一方头像与插画，不臆造身份、在线状态、真实视频或新能力。未知头像保留首字母回落，以通用 AI 图形辅助。
- 品牌欢迎区更紧凑、标题层级清晰；Logo 在手机也可展示。原有 Logo 上传、自动主题提取及配置读取实现没有改动。
- 工具入口改为轻量中性面板，减少颜色噪音；网格按可用容器宽度排版，长文案完整换行。
- 链接保留现有 /chat?agent=，带姓名与角色的可访问名称、键盘焦点环和符合减少动效偏好的提示。

## 验证

- 74 项测试通过：既有首页/后台/主题/模型回归，加四项前台展示测试和三项开发 fixture 门禁测试。
- 前台展示测试验证读取既有配置、角色/用途/头像与 URL 编码、更新配置后无旧人物信息残留、空配置不编造人物、主题与焦点色绑定，不开发后台保存流程。
- Web typecheck、完整 Web lint、能力列表 lint 与 ui-wiring 均通过。
- 浏览器验证 375/768/1280px 首页布局无横向溢出，人物链接有明确名称和可见键盘焦点。
- 后台组件、表单模型、API 适配器、配置契约与原基线零差异；没有改权限、数据、生产或发布管线。

## 验证边界

只读确认本机没有运行中的 Docker 容器，也没有可用非生产 API/对象存储监听；Mac 浏览器只有正式应用页签，没有可确认的非生产会话。未读取密码令牌或使用生产写操作。

真实鉴权读取与数字人对话启动仍未实测。列表呈现与链接不是 Skill/Workflow 执行验收。后台保存与刷新闭环已从本次开发范围移除。
