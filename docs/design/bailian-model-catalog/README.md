# 百炼公共模型目录

Refs #5370。用户授权把百炼的公共模型与参数目录随代码发布，组织配置继续保留在现有数据库。

## 可观察的行为

模型管理保留默认的「组织模型池」，新增「百炼公共目录」。目录按模型 ID、原厂商或中文能力搜索，可组合能力与原厂商筛选，每页 12 项；详情展示输入输出、地域、规格适用范围和官方来源。返回组织模型池不会创建组织模型或改变准入状态。

本次快照记录 **297 个明确公开模型 ID、14 个官方来源、14 类能力**。包括当前使用的 `qwen3.8-max`、DeepSeek、智谱、Kimi、MiniMax、Xiaomi，以及公开指南明列的历史快照。带命名空间的 ID 原样保留。覆盖边界由 JSON 中 `coverage` 单源描述；不将其说成账号完整可用列表。

## 数据与权限边界

- JSON 是公共规格，不存密钥、组织状态、供应商账号、调用地址或准入记录。
- `availability` 固定 `unknown`，`adapterStatus` 固定需配置和验证，公共目录不能直接进入组织模型选择器。
- 规格为 `published-summary`，包含指南列出的短技术事实及其 scope，不能当作完整可执行 API 参数 schema。
- 未核验的上下文、地域、计费单位、价格以 null / unknown 明示；不得补成上下文 1、免费或零价。
- 价格全部 null。旧版 Qwen-TTS 的 Token 单位有明确官方资料，其余未核验计费单位保持 null。该目录不得成为费用预留的定价权威。
- 原厂商与百炼接入平台分开；上下文存在多个不同 scope 的值时保持 null，详细事实仍展示。
- 分类目录与组织池数据分开，组织接口故障不会被公共目录伪装为组织已配置模型。

## 单源与更新

`packages/contracts/src/catalogs/bailian.json` 是随代码发布的快照。输入输出只记逐行规格/明确支持矩阵，资料不足保持 unknown，并显示核验范围。严格校验来自 `provider-model-catalog.ts`；`bailian-model-catalog.ts` 导出解析后的模型。现有注册 API、模型类型、组织权限和 model candidate 契约保持兼容。

刷新脚本只读官方公开文档，不调用模型或账号接口：

```sh
python3 scripts/model-catalog/refresh-bailian.py \
  --fetch --sources /tmp/wsx-bailian-sources \
  --output packages/contracts/src/catalogs/bailian.json
```

不带 `--fetch` 时只从已有来源文件生成；`--observed-at` 可重放同一快照。模型表首列才产生模型 ID，迁移比较表里的 GPT / Claude 等不是百炼模型。明确列出的快照保持独立 ID。页面原文、长说明、示例和密钥均不写入 JSON，仅保留短技术事实、官方 URL、观察时间和内容 SHA256。更新通过 PR 审查后发布，不在运行时自动同步或自动注册。

## 验证及真实证据边界

- 公共契约测试：可信来源、重复 ID、密钥字段、未验证状态、地域与价格口径反例。
- Web 测试：搜索组合筛选、分页重置、空态、详情来源、未知上下文、返回组织模型池；已有组织模型池回归。
- 浏览器组件验收使用实际生产组件、实际 JSON 和现有设计系统，静态本地文件载入，无 Web/API/DB 服务、无账号、无模型调用。375 / 768 / 1280 三档无溢出，页面错误为空。
- 这组截图只证明公共目录组件，不证明已登录组织后台、组织模型准入或任何供应商调用可用。

组件浏览器验收可重放：`node scripts/model-catalog/verify-bailian-ui.cjs /tmp/wsx-bailian-ui-proof`。脚本只构建该组件的临时静态夹具，不构建或启动应用。

证据在本目录 `evidence/`；CI、最终 SHA 和草稿 PR 在上级交付记录补充。

## 后续接入缺口

账号/地域可用性、模型广场中未公开列出的全部历史版本、模型逐条完整 API 请求参数、地域阶梯定价与计费上界、真实适配器与组织准入，需要后续核验。Skills、空间与工作流继续按服务端已有模型准入选择，不因目录收录而放宽。
