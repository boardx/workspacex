# 五分钟云部署核心 Backlog

目标：在前置资源和不可变制品准备完成后，Starter、production 两档均可用一条 provision 命令启动，业务通过目标为 300 秒。执行环境转到本地只是开发方式，部署目标仍是阿里云。

## 两档固定拓扑

| 项目 | Starter | production |
|---|---|---|
| 应用 | ECS 上 Web、API、Agent、隔离 Sandbox | 同左，应用单副本 |
| 业务数据库 | ECS 持久卷 PostgreSQL 16 + pgvector | 同地域高可用 RDS PostgreSQL 16 |
| Agent 数据库 | 同 PG 实例的独立角色、独立数据库 | 独立数据库/角色的受保护连接引用 |
| Redis | ECS 持久卷 Redis 7，要求认证 | 同地域托管 Redis 7，高可用、认证、TLS |
| 文件 | 私有、从未启用版本控制的 OSS 桶 | 同左 |
| 入口 | 已配置 HTTPS 反代；/api 支持 WebSocket Upgrade | 同左 |

production 指当前支持的托管数据层配置，不承诺应用多副本或无中断接管。

## 核心交付包

| ID | 保留工作 | 验收条件 |
|---|---|---|
| CP-01 | 配置 Schema、两档示例、ECS/权限/数据库/证书预检 | 参数不泄密；资源漂移、错误证书、权限不足必须失败 |
| CP-02 | 固定 digest 制品、目标架构校验、预热、Compose | 目标机镜像已缓存；不在 provision 内编译、下载依赖或拉镜像；真实运行容器匹配 manifest |
| CP-03 | OSS 适配和桶策略校验 | putOnce/读回哈希/私有访问；不回退本地文件；物理清除保留独立授权路径 |
| CP-04 | 文件导出、上传下载、录音/头像/Agent 文件、合规撤回 | 真实 API 鉴权、租户隔离和字节校验；普通全量撤回真实清理关联，不能用 stub 当完成 |
| CP-05 | 252 迁移、稳定密钥、独立角色、管理员和默认 Agent | 全新初始化及并发/重跑一致；错误密码不轮换，不覆盖既有数据 |
| CP-06 | Agent/Sandbox 生产运行与基本恢复能力 | 真实 Agent 回复、隔离工具执行、持久状态恢复；Starter 备份恢复到新数据库；升级前备份和回滚边界明确 |
| CP-07 | 单一 provision 命令、总预算、锁、阶段报告、取消和真实业务探针 | 不跳过失败阶段；超时/不确定容器清理保留锁；不凭健康检查宣告业务成功 |
| CP-08 | 两档真实云计时、重跑和关键故障验收、安装说明 | 每档支持配置至少三次全新应用安装计时；保留失败尝试和受验 commit，不以本地/mock 代替云验收 |

当前状态、commit 和验收层级以 `cloud-provision-progress.md` 为单一进度来源。本表只定义范围；不自行改变 harness passing 状态。

## 简化掉的非核心工作

本轮不做计算巢公开上架、SAE/ACK 改造、跨地域灾备、应用自动扩缩、复杂监控大盘、账单优化平台、浏览器 OSS 直传/CDN、蓝绿平台、旧数据在线迁移。保留基本日志、备份恢复、安全隔离、失败诊断和重跑能力。**Starter / production 两档保留**，此前“删除双轨”的旧规划作废。

## 前置与计时边界

云资源创建、备案/DNS/证书签发、Docker/Compose 和 AppArmor 安装、镜像构建与预热在 prepare 阶段；应用迁移、管理员初始化、服务启动和业务验证仍在 provision 阶段。

编排器的 `durationMs` 记录动作及阶段报告完成时刻；终态报告只发布一次，避免先 passed 后 failed。终态 fsync 和超时后的安全清理可能使命令进程稍后返回，不能把该字段当作完整 CLI 墙钟时间。真实验收必须另外记录从命令提交到返回的墙钟总耗时，并同时满足 300 秒目标。当前尚无两档真实云计时通过证据。

缺少云配置只阻塞对应真实云验收，不阻塞代码、隔离数据库验证、镜像构建或故障测试。GitHub 外发审批和 Agent Server 许可选择分别列出，不用它们停止其他开发。
