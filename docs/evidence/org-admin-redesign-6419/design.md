# 组织后台右侧重构（#6419）

用户提供六张 UI 参考，明确保持现有左侧菜单。实现范围只包含真实业务路由的右侧内容：组织总览、成员、邀请、资料、工作流权限与成员配额。截图是视觉目标，不是线上数据或权限来源。

## 视觉约定

采用现有背景/卡片/文字/边框语义 token；白色内容、轻灰分区、黑色主操作，状态使用系统成功/警告/错误 token。统一页头（图标、标题、说明、右侧主操作），宽版内容（最大 screen-2xl），统计卡片，筛选工具栏，带表头/分页的列表，右侧详情抽屉。字号使用已有 text-30/24/16/14/13/12 档；间距以 4/6/8 为主。图标用既有 Lucide，头像/Logo 使用真实资源与已有回退，不生成虚构用户照片或新品牌标识。

## 六页信息结构

- 总览：真实组织指标、已有用量数据可支持的趋势、近期活动、必要的已有运维信息。没有时间序列时不把总量拼为趋势；没有同比/环比时不显示虚构增长率。
- 成员：搜索、角色/状态筛选，真实成员统计，头像+姓名+邮箱、角色、状态、实际可用时间字段与权限内操作。保留角色调整和审核职能，缺少 lastActiveAt 时明确使用加入时间。
- 邀请：统计、搜索/状态筛选、邀请记录表、邀请/重发/撤销及共享链接。空态只在无记录时显示，不能像参考图那样有表格却同时声称无记录。
- 资料：组织识别卡、基本信息表单、Logo、现有高级设置和底部保存区。仅提供后端已支持的设置，保留长期工具授权与记忆抽取设置；不伪造官网/公开加入等缺失字段。
- 权限：能力统计、筛选表、详情抽屉展示真实关联工作流与审计。授权与撤销沿用现有确认和服务端鉴权。
- 配额：Credit 成员统计/进度/表格和调整入口，Token 统计独立保留。企业总额不限制，默认每人每月 1000 credit（来自现有权威 API）；成员限额合计不能冒充企业总预算，不新增赠送或欠款规则。

## 状态与适配

保留 loading/error/empty/denied/success；失败不显示 0 伪装成功。数据刷新、角色限制、乐观锁和组织身份切换的隔离不改变。375/768/1280 宽度下页面不横溢，表格必要时局部横滚；弹窗/抽屉可滚动、关闭/提交始终可达，支持 Escape 和键盘焦点。所有新增文案支持中英切换，不让 locale 切换重复执行写入。

## 实施与验证计划

1. 共享右侧布局/页头/统计卡/区块组件，不修改 AdminNav/AppShell/主侧栏。
2. 成员、邀请、资料真实页面重构；保留现有操作并扩展回归。
3. 权限详情抽屉与 Credit/Token 配额展示重构；保留权限与账务边界。
4. 总览信息层级重构，复用真实指标/活动。
5. 跑 UI 回归、typecheck/lint；真实浏览器逐页截图和主要交互，覆盖三档宽度与失败/权限状态。
6. 一个 UI 重构 issue/PR，独立 review 与 CI；不混入计费政策、问卷或其他未实现功能。

实际数据能力与六张参考图有差异时，优先保留真实语义并在验证记录中说明。引用图片不上传 GitHub。
