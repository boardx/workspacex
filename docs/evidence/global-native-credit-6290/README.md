# Global native credit prices — #6290

User requirement: each provider/model/native unit has one canonical retail price for every personal and enterprise payer. New organizations inherit the same price without copied rows. ASR ×3 and image ×10 remain distinct product rules. Supplier region is cost metadata; an endpoint change cannot automatically change the approved retail price.

Implemented: global tariff and append-only global audit; gcd-normalized conflict-checking migration; explicit global platform contract/UI; global image activation helper; a tenant-filtered SELECT-only compatibility view for old runtime. Global price mutation requires the existing authoritative platform-operator guard. This reuses the current global consumption-settings DB grant/guard pattern rather than introducing unconfigured credentials; ordinary runtime performs SELECT only, but this is not a separately credentialed DB writer.
