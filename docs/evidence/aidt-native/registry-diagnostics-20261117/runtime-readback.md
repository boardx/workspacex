## Narrow optional projection

For the existing DevApp host-only probe, an exact immutable image tag in its existing `release` field and the existing `release_sha` provide optional selector hints. Other producer modes keep their semantic-release behavior. No new workflow input, permission, credential or server command is introduced.

The optional reader only matches running Docker-list entries carrying both exact OCI source and exact release-tag labels. Validated per-container GET inspection must rebind the selected identity, state, image ID and labels before projecting allowlisted metadata. It emits safe runtime image identity, API flag states and a strictly validated Web marker; it never emits raw environment, names, paths, policy, database content or exceptions. Missing/ambiguous/changed inputs stay UNKNOWN. When either selector hint is present, the historical AIDT project-based detail reader is skipped; without hints its implementation is unchanged. Existing infrastructure metadata and fixed permissions reporting remain. A semantic identifier supplied to the host-only workflow now fails closed as an invalid exact-release selector rather than falling back to inspecting a different API.

The operator compares returned application image IDs to the independently verified manifest. PostgreSQL is a build-set parity item; an application-only release does not require replacing the running database image. This probe does not add SQL/exec, inspect private native evidence or change any runtime.
