# V2 需求与当前实现差异

本轮依据用户消息中完整 Markdown，不依据不可见 PDF。状态是分支事实，不表示已发布、课程负责人签核或真实课堂验收。

| 条款 | 此轮处理 | 仍存在的差异 / 验收边界 |
| --- | --- | --- |
| FR01 | 复用原生项目成员与 AIDT 专用入口 | 小组依托受控项目；独立课程编排/班级管理未实现，不假装有新角色授权 |
| FR02、04 | 共享阶段稿、CAS冲突保护、重进回读与历史 | “编辑者确认”“服务器保存”“教学完成”分别表达；未规定课程锁步规则 |
| FR03 | 原生Chat+阶段Skill升级到1.3；旧会话pin不变 | 缺模型配置时不提供真实生成，规则文本和mock测试不等于模型行为验证 |
| FR05 | 复用附件与原有资料引用，保留上传失败边界 | 用户已决定访谈录音另排；不得用个人录音绕过真实访谈授权；语音房也未交付 |
| FR06 | 分开发现、引文、来源与AI建议，新增意外/反例记录 | 学生填写引用并不证明证据真实性；材料访问权仍由原生服务校验 |
| FR07 | 点子编辑/拟选择，三份不同图文描述单打印PDF，新增多标签分类 | 拟选不是多人票数；票规未定。浏览器打印请求不是服务器文件导出回执；图像生成依赖真实能力 |
| FR08 | 原生Design入口、制作说明与版本引用，新增验证问题确认门槛 | 静态生成质量/可支持类型需真实模型与Design测试；入口门槛不是独立后端生成政策 |
| FR09 | 固定本轮问题/旧版本，认识变化与返回1–5，保留历史 | 回前四步无需新原型；新版默认待测试，未实现跨阶段反向归因的新服务图谱 |
| FR10 | 可审阅报告/Markdown/打印，汇集V2学习记录 | 仅实际已读取内容；未读取的旧历史不自动整编为“全部过程”；教师点评无来源保留缺失 |
| FR11 | 全局成员文字聊天+单层话题、共享成果与冲突处理 | 约5秒增量拉取；无新增通话服务器。30人并发和实时共同光标未验收 |
| FR12–14 | 维持后续范围 | 教师评分/自动PPT/3D打印未交付，不作为P0完成项 |
| FR15 | 原始命题之后先填价值、多选来源及不确定性；修改撤确认；报告与访谈背景可见 | 猜测可作为起点，不是“问题已证实”；待真实模型行为与课堂检验 |
| FR16 | 画像前意外发现或暂无；有发现关联材料；none隐藏旧分支内容 | 已移除/未知卡片引用不得仅凭true显示确认；不能由一次例外推断全体 |
| FR17 | 学生多标签、理由、显式确认；空类别有效；与拟选分离 | 三类不是配额；跨类仍是同一点子，不能凑三份；多人投票规则仍待定 |
| FR18 | 原型前验证问题卡、前看法/依据/边界、显式确认；从已保存S5创建测试快照 | 自述原型引用不等于文件存在核验；静态意向不等于真实时间/付费行为 |
| FR19 | 前后认识、未变/不足、返回五步或未决定、理由行动；保存后导航与新轮草稿 | 返回来源保存在S6及页面上下文；原API只支持引用前序，未冒造Stage1→Stage6正式反向引用 |

## 真实验收分层

组件/单元：记录到 `verification.md` 的实际输出；隔离共享API：保留CAS/权限/归档边界；本地原生：必须构建、真实登录、保存、停止、重启、回读后才标连通。真实模型、访谈录音、外部参与者同意、30人课堂和生产发布分别待验，不互相替代。
