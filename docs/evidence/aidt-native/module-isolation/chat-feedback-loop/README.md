## 证据问题与修复

1. **原生 Shell 后续导航丢资源上下文。** `ProjectAidtChat.threadPath` 原先只生成 step/thread。原生 Shell 的真实 `handleThreadResolved` 等分支会调用这个回调更新 URL，导致 tool/resource 丢失。新增反例直接调用宿主交给 canonical Shell 的回调后发现 resource 消失；修复为仅在当前同项目、同阶段路径保留 tool/resource，不跨阶段猜资源。
2. **学生不能在 Chat 查看 AI 参考的保存文字。** 之前共享来源只有“第N步/V”的元数据。现在每份来源可折叠展开只读文字，复用当前阶段字段标签/现有摘要格式，旧格式或截断片段原样作为纯文本显示。保存、事实核实和小组确认仍分开；只读成功回读的当前组共享版本，不把未分享的私人草稿加入。
3. **图片瞬时故障没有实际重试入口。** 恢复引用校验失败、鉴权字节读取失败或图片解码失败，原先只有重试文案。现在 Preview 可点重试，重新校验授权来源并重挂原生取图组件；候选列表也可刷新缩略图。旧 scope 与已卸载图片不能将新图片标成 ready，坏图继续禁选和清除 PDF 源。
