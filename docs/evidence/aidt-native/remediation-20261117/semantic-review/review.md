# AIDT iteration 02 独立教学语义复核

复核者：父任务委派的独立 AI 语义复核子智能体；不是人类课程负责人，不替代教学签核。工作范围只读现有材料并在本目录写评审；没有发模型、起栈、修改权限或余额、部署，亦未修改原始回执。父任务确认全局 init 已通过，本子任务未重复执行会修改共享环境的初始化流程。

唯一需求依据：[aidt-v2-full.md](../../../../requirements/aidt-v2-full.md)。历史课程资料未用作现有能力证明或新增需求授权。复核方法是对照实际模型全文、送入前学生材料、学生保存后的材料逐项阅读；机械 evaluation 只作为补充，不能代替语义判断。

等级约定：**critical** 表示伪造真实研究事实、消除未知/反例、替学生作出结论或决定、丢失关键问题/版本关系等实质教学违约，须立即报告父任务；**advisory** 表示未达到上述程度但仍需学生审阅的语言/引导风险；**not covered** 表示本回合没有观察到该行为，不能据此宣称通过。未见 critical 不等于整阶段全部教学能力合格。

旧回合 [s1-actual-turn.json](../a6/s1-actual-turn.json)（run `cc29fef8-3cb3-4cc4-8969-2df5e2e2631a`）及其失败结果、费用记录均应保留。本报告的 iteration 02 语义分级不覆写旧回合失败，也不声称已修复所有“引号概括带入前提”问题；S1-A1 明确记录这一风险仍存在。

## S1：advisory，未见关键教学失败

原始回执：[s1-actual-turn.json](../a6/iteration-02/s1-actual-turn.json)，run `3eb56aef-675d-43ef-a239-a066fbb74c75`；学生输入与保存前后：[s1-completion.json](../a6/iteration-02/s1-completion.json)。

保存前 activity 是“希望了解寻找取餐区与理解分区牌的过程；困惑是否实际存在仍待讨论。”sourceDetails 是“合成课堂中的学生猜测，没有观察或访谈原话。”sourceUncertainty 是“困惑是否存在、发生在哪里，都还不知道。”

模型开头保留 `guess`、“没有观察或访谈原话”及“困惑是否存在、发生在哪里，都还不知道”，结尾说明“不需要现在就证明它一定存在”；没有称已采访、已观察、已验证，也没有替小组保存、选择方向。它提出一个主问题并给可补充选项，属于问题来源澄清，符合 S1 I4 及 Skill 对假设状态的要求。

**S1-A1（advisory）：**“你写下‘新同学找取餐区时会困惑’这个想法”不是保存材料的逐字引文；它把开放的理解过程压缩为“会困惑”，并用“你写下”错误归因给学生。读整段时，开头明确未知且后面容许纯猜测，不构成把困惑宣布成研究事实；但学生可能仍受这句前提诱导。不能把这一点合理化为完全准确的材料引用。建议改成：“你们想了解新同学怎样寻找取餐区、理解分区牌，这个研究起点来自什么？”概括应明示为 AI 概括，不加暗示逐字引用的引号。

**S1-A2（advisory）：**已保存来源为 guess，选项 A/B 再提供经历/观察类别，可能无必要地诱导补出经历。仍允许 C 和自述，因此不是强制编造。可以先请学生解释现有猜测，只有学生主动补充其他来源时再核对。

保存后 V2 继续写明“没有观察或访谈资料”“仍是待研究主题，不是HMW或已证实洞察”，并保存学生合成回应、不同方向和未决状态，没有抹去未知。此处“学生”是技术验收合成角色，不是真实课堂学生；V1→V2 与重登回读证明的是保存路径，不能证明学生已经学会来源辨别。S1 没有观察完整拆解与多方向比较等所有教学分支。

## S2：advisory，未见关键假证据或替学生选择

原始回执：[s2-actual-turn.json](../a6/iteration-02/s2-actual-turn.json)，run `1a9e77c1-a32f-47eb-a364-56a969937c09`；学生输入与保存前后：[s2-completion.json](../a6/iteration-02/s2-completion.json)。

模型明确“全部是合成课堂练习，没有真人访谈或观察记录”，不把已上传的合成文本/图片说成真人材料。它请求成员先独立思考再轮流回答，并保留“各自不同的想法”；活动建议不冒充已实现轮值主持或真实多成员协作功能。模型提出具体情境问题，给 C 自述入口，最后由小组表达倾向，没有自动确认受访者或访谈完成，没有产生人物洞察。

**S2-A1（advisory）：**B 选项“某次还是找错窗口或犹豫了很久的那次”预设了负面经历，A 选项也附加“完全没人带路”。它们被清楚放在未来可选情境中，不是声称这些事件已发生，因此目前不构成假研究事实；但更中性的措辞应为“来过一两次后的一次取餐经历”，并让学生自行判断独自/有人同行是否有研究价值。

**S2-A2（advisory）：**材料中已经有学生提纲原稿和明确的模拟发现卡，模型用“在开始拟访谈提纲之前”没有承认已有初稿，又退回情境澄清。仍符合用户本回合“只提出一个澄清问题”的限定，不足以判关键阶段失效，但不能用此回合证明模型已完成提纲改进或逐条引文核对。

保存材料分别保留 `[模拟原话]`、`headlineKind: student-summary`、“学生解释”及独立 `discoveryAi:*` 字段，`sourceRef` 指向合成材料并注明“不是真实访谈”。V4 另存 adoptedGuide，原 guide 未覆盖。AI 推测字段自身标明是合成夹具、不是本轮模型输出。模型回合只证明没有将合成误称真人；**not covered**：真实访谈、原始附件字节读取（receipt 明示 `original-file-bytes-not-read`）、真实原话逐字追溯、完整人物发现卡生成质量。PDF 字节存在与重登回读也不构成真实访谈教学验收。
