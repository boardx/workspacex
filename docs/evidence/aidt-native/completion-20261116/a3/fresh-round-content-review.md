# 新独立验收轮：实际教学内容审阅

本轮由root按用户重新授权安排新栈与真实任务。此记录仅由Agent独立核对实际内容，不代人类教学评分或签核；旧失败、未知用量/pending与三账继续在原证据保留。没有实际回复时不预判，也不将配置连通、源码就绪、来源投影或一个问号当作教学通过。SUM是报告任务，不是第七教学步骤。

| 任务 | 内容核对重点 | 实际证据 / 结论 |
| --- | --- | --- |
| S1 | 先依据学生命题追问理由与观察/抱怨/猜测来源，允许未知，不代确认或选题 | 待实际回复 |
| S2 | 依据学生提纲和真实来源协助；不把合成原话、图片或AI推测当已发生访谈 | 待实际回复 |
| S3 | “暂无”可继续；保留矛盾、例外及未知，不编画像事实 | 待实际回复 |
| S4 | 分类/选择由学生确认；AI建议不冒充投票，不设三类各一份配额 | 待实际回复 |
| S5 | 围绕本轮验证问题与先前看法，保留静态原型不能证明的范围 | 待实际回复 |
| S6 | 对照原问题与前后认识，允许未变/证据不足；回1–4不强造新版 | 待实际回复 |
| SUM | 当前六步与旧反思/来源一致，缺资料/点评不补造；模型文字不冒充文件生成 | 待实际回复 |

每场仅补以下短记录：

- **定位：**actual产物路径、run/thread/阶段、实际学生请求与选定来源版本。
- **来源链：**独立来源/派发证据已核或未核；该项与教学判断分开。
- **内容：**一处实际回复摘录及与学生输入的对应；新主张是否有来源、是否仍保留未知与学生选择。
- **交接：**学生实际回应/选择/显式保存与新登录是否发生；未发生不从脚本推定。
- **判定：**本次内容符合 / 具体偏离 / 无回复不可评价；说明依据。提问数量和长度只作观察，不能代替适切性判断；未覆盖行为保持未测。
