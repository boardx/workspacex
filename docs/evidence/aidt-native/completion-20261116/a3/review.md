# A3 历史学习报告追溯实现审阅

状态：本地实现待集成审阅。不是人类设计签核，不修改任何设计签核状态。

## 已有依据和范围

- 已读根AGENTS、`mod-project`和`execution-plan`，现有`aidt-report-preview.tsx`、共享阶段控制器与历史客户端。
- 复用`listAidtStageHistory`现有只读修订接口；请求使用当前项目与捕获的session token，原客户端继续验证项目/阶段作用域及递减游标。组织/账号/lifecycle变化由组件key隔离。
- 不改变后端或`SummaryReport`契约（每步至多一个当前来源版本）。历史多版本引用保留在报告正文，不能将现有保存回执误称覆盖全部历史引用。
- 无独立学习轮次数据库实体；按第6步共享V修订呈现学习记录、实际原问题引用和返回决定。保存多次不能推算完成多轮；未决定/尚未确认/来源缺口如实保留。

## 主动流程与约束

1. 用户展开“审阅历史学习并加入报告”，主动读取；不会在打开页面时请求全历史。
2. 读取第6步再读第1至5步，每步2页、每页5版；最多12次请求/60版，总预算20秒、单请求4秒，非协作transport也会超时/取消。
3. 展示只读章节，标明服务器历史、读取时间、保存者、修订、来源关系、材料缺失/失败/未读取/截断。单版最多1200字符，章最多85000字符。
4. 用户审阅并勾选后主动追加到**当时最新的当前正文**。读取期间继续编辑不丢失。追加长度超过现有100000字符契约则禁用，不裁掉用户稿。
5. 通过原有报告保存入口主动保存。历史读取/勾选/追加本身不发保存，不以localStorage充当共享。

取消/卸载/账号、项目、组织、token或lifecycle变化会abort并移除旧结果。权限拒绝401/403/404则丢弃本次所有历史；其他失败按阶段保留可用结果和缺口。只读降级清空旧审阅状态并禁用插入。


root负责父级`project-aidt.tsx`接线；本任务不改父级或Chat。无scope则没有历史入口，既有报告行为保留。真实Chat组件与交互未改。
