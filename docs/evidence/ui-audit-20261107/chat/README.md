# 撤回后的流式气泡缓存（#6342）

## 根因与修复

`assistant_message_replaced` 原先仅移除 SDK 当前消息数组中的气泡。`TEXT_MESSAGE_END` 保存的完成投影和流式捕获仍在；后续 `projectMessages` 会把已撤回的正文重新插入，而持久身份到达时还可能消费已作废的捕获。

撤回时同步清理对应的流式捕获及别名相交的完成投影。按协议消息身份清理，保留无关轮次，不按文本相似度去重。即使 SDK 快照已经清空也执行清理。

## 执行计划

1. 在既有替换协议测试中添加多气泡撤回回归，覆盖非空/空 SDK 快照、下一轮消息和无关轮次保留。
2. 观察新增两用例失败后修复缓存生命周期。
3. 运行身份、恢复及国际化相关测试、ESLint 和 TypeScript。
4. 提交独立 PR，经 CI 与独立 review 后合并；真实模型复测单独记录，不能用组件测试代替。

## 验证边界

原审计在中国站真实 Chrome 中观察到重复正文，刷新后消失。本回归定位并验证了可复现的撤回缓存缺陷，不声明所有线上重复现象均由该根因解释，也不声明已部署生产或已完成真实模型复测。

`red.log`：新增两用例均失败，旧计划和旧答案重新出现在投影。

`green.log`：身份替换、最终恢复和国际化三文件共 17 项通过。
