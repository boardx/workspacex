# 技能选择搜索（#6354）

## 目标与范围

手动打开技能选择器时可按名称或用途搜索；清除无匹配查询后恢复候选。mention 与手动入口复用同一可用池、权限与挂载命令，真实名称和身份不改写。文件维护说明移到折叠的技术说明，任务选项不再用长段源码说明冒充用途。数字人详情沿用同一个说明过滤函数，避免复制规则。

## 计划与验证

1. 新增手动搜索回归，覆盖描述匹配、不区分大小写、空态、清除和选中后命令身份。实现前失败：没有搜索框。
2. 新增技术说明回归。实现前失败：源码维护说明位于任务选择按钮正文。
3. 实现搜索、清除和高级说明，运行选择器及数字人详情相关测试、ESLint、TypeScript。
4. 独立 PR，按当前 SHA 的 CI/review 判定后合并。人工浏览器复测另行记录。

`search-red.log` 和 `details-red.log` 为两次失败证据。`green.log` 为最终相关回归结果。未新增技能分类、虚构技能职责或变更权限。
