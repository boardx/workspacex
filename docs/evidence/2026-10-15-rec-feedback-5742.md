## Behavior and root causes

- Keep the real microphone RMS meter; remove the redundant Radio icon / normal audio-receiving label. Keep exceptional connection, stopping, reconnection and slow-delivery state visible.
- Recording VAD endpointing defaults to 1200ms instead of 800ms. Chat remains 400ms, explicit overrides remain supported, interim delivery remains immediate, and final text is never rewritten or stripped of punctuation.
- Recording stop uses `session.finish` → `session.finished`. Qwen-ASR documents `input_audio_buffer.commit` as disabled under VAD; the old recording stop sent it anyway. Prior finals do not replace the terminal receipt. Silent recordings can stop with an explicit no-speech receipt.
- After PCM tail delivery and media track shutdown, a rejected browser AudioContext close must not prevent the server stop handshake.
- After stopping (the existing metadata API rejects active captures), double-click the title or focus its button and press Enter/Space to rename. Save persists through the existing metadata API, preserves tags and live content, and retains failed edits for retry; Escape cancels.
