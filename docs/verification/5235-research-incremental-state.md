# Research incremental state transport — #5235

首次进入与刷新通过 runtime GET 恢复完整持久化状态。正常命令、轮询与 SSE 使用页面内存快照的 SHA-256 字段指纹，只返回变化字段及身份/版本；显式 removed 清理已删除的可选字段。异常恢复仍可读取完整快照。

前端页面内存按会话和当前登录凭据隔离，最多保留三个会话，刷新后清空。步骤路由复用快照并用增量同步；更名成功后更新名称缓存。字段指纹仅为传输提示，不参与执行命令和幂等摘要，不影响服务端权限或持久化状态。

报告正文继续使用 report_delta，服务端更新已发送正文的指纹，后续 patch 不重复发送相同正文。轮询必须基于发起请求的快照合并，再与当前 SSE 快照比较，防止旧轮询覆盖较新的正文与 timeline。
