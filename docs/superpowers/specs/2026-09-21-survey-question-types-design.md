# 问卷完整题型与场景模板设计

状态：用户于 2026-09-21 在本任务回复“确认”，批准按本设计实施。实现与验证证据见 docs/evidence/survey-question-types-20260921/；PR/部署状态单独记录，不以本文替代验收。

## 覆盖基线

以问卷星和 SurveyMonkey 官方常规题型为核对基线；类型采用能力注册表，允许后续扩展。完整问卷模板和可组合题目模块分开，保留用户现有问卷、答卷和模板。

- 选择：单选、多选、下拉、图片单选、图片多选。
- 输入：单行文本、多行文本、多项填空、数字、日期、时间、日期时间、邮箱、手机、地址、级联选择。
- 评分：量表、星级评分、NPS、滑块。
- 矩阵：矩阵单选、多选、量表、填空、下拉。
- 比较：排序、比重分配（可配置固定合计）。
- 材料：文件上传、签名。
- 页面元素：说明文字/图片、分节与分页；不计为回答题目或参与统计。

共29种答题形式及页面元素。语义共用的题型复用基础能力，不用复制多套处理逻辑。手机/邮箱是输入的校验预设，评分是数值配置，矩阵使用共同行列模型。

## UI与交互

编辑器包含题目目录、配置面板、可折叠的桌面/手机实时预览。新增题目使用可搜索、按类别分组的卡片，每种展示示例及用途；常用类型优先，更多类型随时可达。先选择类型，再编辑合理默认题目。支持复制、移动、分节、批量粘贴选项、撤销删除。

基础设置默认展开，高级规则按需展开。切换题型涉及选项、行列或规则丢失时展示变更预览，保留取消入口。未保存修改在离开前提醒；发布后的题目仍保持已有版本锁定，不改变历史答案含义。

通用设置包括题干、说明、必答、选项“其他”与填写、互斥选项、多选数量、文本长度、数值范围/精度/单位、评分端点标签、图片替代文字。级联逐级选择；父项变更清空失效子项。排序同时支持拖动、键盘和上下移动按钮；未操作不默认为已答。滑块未触碰不提交中间值。多项与矩阵明确每行是否必填。比重分配实时显示已分配值与差额。

手机矩阵按行卡片展示，避免强制横向滚动；长问卷按页展示进度，错误定位至具体题目/行并保留已填内容。键盘可操作所有控件，字段有可访问名称，错误不是只靠颜色表示。材料上传展示进度、失败重试、删除；签名同时提供清除和可访问替代方式。

条件显隐与分页跳转为独立规则，支持前题答案触发、循环/失效引用校验；隐藏题不触发必答，不把隐藏的旧答案混入统计。选项随机顺序保持单次答题稳定，题目/选项用稳定ID绑定。

## 数据与API契约

现有 `single/multi/scale/open` 与历史 `string|string[]` 答案保持可读。新增版本化题目配置和结构化答案：标量、选项ID集合、有序ID列表、行列值、字段值集合、附件引用、签名引用。服务端按发布快照判定题型及规则，拒绝未知题目/选项/行列、重复ID、非法数值、错误排序和不符合合计的分配。

题型注册表成为展示名称、默认配置、配置校验、答题校验和支持统计的唯一来源。浏览器提示和服务器校验调用共享纯函数。报告模板的题目映射同时检查数据能力，不能把文本映射为数值。

附件/签名复用资产能力，需要读其权限和存储契约后实施。公开答卷上传必须绑定有效发布问卷、题目和一次提交会话，限制大小/数量/允许格式，由服务端验证真实文件类型；不能用任意URL或跨会话附件ID提交。附件访问遵循问卷权限，草稿/失败上传有过期回收。签名不宣称具有电子合同法律效力。

## 报告与完整模板

选择题生成数量与比例，数值/评分生成有效样本与均值分布，NPS使用推荐者占比减贬损者占比，排序展示平均名次与首选比例，矩阵按行统计，分配题按项目汇总。缺答不计为0；文字、日期、文件和签名按各自适用方式展示，不强行计算均值。小样本分组沿用现有保护规则。

建立6套独立内容的完整问卷：企业数字协作成熟度、团队健康度、项目复盘、工具满意度、会议反馈、知识治理。每套包括开场说明、章节、完整题目、适用规则和绑定实际题目的报告结构；题目数量由实际配置派生。保留6组原有题目模块用于组合。报告结论必须有答卷依据；模板示例和配置提示不进入正式报告或导出。

## 验收用例

每种答题形式均走编辑→保存→刷新→预览→发布→真实提交→查看答卷→生成报告→Word/PDF导出；不能只测渲染或下拉枚举。覆盖桌面与手机、键盘操作、可选空值、必答、边界值、篡改API输入、条件显隐、重复提交、上传失败、发布后锁定和旧问卷兼容。

每种类型记录可执行用例和证据。报告逐项核对样本数、公式、章节/区块顺序及导出内容；无模拟答卷和虚构结论。分成题型契约、编辑与答题、材料上传、完整模板四个可独立评审交付单元，只有整条链路通过的题型才进入正式题型选择器。
