# 引导式 Deep Research Skill 与逐步完成流程设计

## 背景与目标

当前 Deep Research 已具备主题、研究方向和报告大纲的创建与保存能力，但资料研究和研究报告仍是静态演示页；页面左侧在移除旧 Research Studio 二级导航后没有提供研究过程中的协作入口。用户需要参考访谈流程，在左侧加入可持续迭代当前内容的 AI Skill，并让一项研究能够按照既定步骤从创建一直走到报告。

本轮目标是完成可验证的前端交互与状态闭环：用户依次完成“确认主题 → 研究方向 → 报告大纲 → 资料研究 → 研究报告”，每一步刷新后可以恢复；资料研究与研究报告使用明确标注的演示数据。本轮不接入 F170 的真实 Web Search 运行态，也不接入 F171 的真实报告数据。

## 方案选择

采用“上下文 Skill + 顺序解锁 + 演示闭环”方案：

- 左侧新增约 320px 宽的“研究 Skill 助手”，复用访谈 Skill 助手的交互心智，不恢复旧的 Research Studio 导航。
- Skill 根据当前步骤给出不同快捷指令和确定性建议；建议只有显式应用后才修改当前研究内容，并支持撤销最近一次应用。
- 主流程仍以服务端保存的 session stage 为完成事实源，URL 只负责表达当前视图，不能绕过未完成步骤。
- 资料研究和报告阶段提供可操作、可恢复的演示闭环，并始终显示“演示数据/不作为真实研究证据”标识。

未采用的方案：

- 仅增加一个通用聊天框：开发量小，但无法安全地修改方向、大纲等结构化内容，也无法证明逐步完成。
- 本轮直接接真实搜索和报告运行时：最终体验更完整，但会把 F170/F171 的运行时、工具调用、证据与失败恢复范围合并进 F180，无法保持一个 feature 一个交付边界。

## 页面布局

- 保留产品全局主导航和组织顶栏。
- Research 页面内容区改为左右两栏：桌面端左侧固定 Skill 面板，右侧为原有步骤进度和当前步骤内容。
- Skill 面板不是导航，不展示旧的“研究 Studio 列表/计划详情”等入口。
- 1280px 以上左栏固定约 320px，主内容占剩余宽度；窄屏下 Skill 折叠为当前页面内可打开的抽屉或折叠区，主流程不被横向裁切。
- 首页没有正在编辑的 session 时不展示 Skill 面板；从主题步骤开始展示。

## 研究 Skill 助手

### 上下文与快捷指令

Skill 读取当前 session、当前步骤及当前步骤的可编辑内容，并按步骤展示快捷指令：

- 确认主题：优化研究主题、补全研究目标、检查范围是否过宽。
- 研究方向：补充研究方向、合并重复方向、检查方向覆盖。
- 报告大纲：优化章节结构、补充缺失章节、检查章节与方向映射。
- 资料研究：建议搜索关键词、检查来源类型、标记待验证结论。
- 研究报告：优化摘要、检查引用覆盖、补充风险与限制。

本轮 Skill 使用确定性演示回复，不调用真实模型。面板底部持续显示“演示 Skill · 不作为真实研究证据”。

### 建议应用规则

- 用户发送消息或点击快捷指令后，Skill 先生成建议卡片，不直接修改主内容。
- 建议卡片明确显示目标对象，例如主题、某个方向、某个章节或报告段落。
- 只有点击“应用建议”后才执行结构化修改；应用成功后主内容立即可见。
- 每次应用前保存当前步骤快照，允许撤销最近一次 Skill 修改。
- 同一条建议只能应用一次；输入为空不可发送。
- Skill 消息、待应用建议和撤销快照随当前研究 session 在浏览器本地保存；损坏内容回退为空助手状态，不影响研究主体数据。

## 顺序步骤与状态机

步骤顺序固定为：

1. 确认主题
2. 研究方向
3. 报告大纲
4. 资料研究
5. 研究报告

交互规则：

- 当前步骤和已经完成的步骤可点击；未来步骤显示锁定状态，不可点击。
- 每一步都有唯一主操作，成功保存后才推进 session stage 并解锁下一步。
- 浏览器刷新、重新打开历史研究或修改 URL 时，界面根据服务端 session stage 恢复到允许访问的最远步骤。
- 返回已完成步骤允许查看和修改；修改后需要重新确认。对可能影响后续结果的修改，界面提示后续演示结果将重新生成，并把最远可访问步骤收回到对应检查点。
- 未完成研究在首页显示“继续研究”，进入最远已确认步骤；完成研究显示“查看报告”。

### 资料研究演示闭环

- 点击“按此大纲开始研究”后进入资料研究。
- 页面按章节展示演示检索任务、搜索关键词、来源数量、采纳/排除状态和整体进度。
- 用户可以逐项触发演示检索，查看来源摘要并将来源标记为采纳或排除。
- 所有章节达到演示完成条件后，“生成研究报告”可用；点击后保存资料研究完成状态并进入报告。
- 页面显著显示“演示检索结果，不代表真实 Web Search”，不把演示来源伪装成真实证据。

### 研究报告演示闭环

- 报告由已确认的主题、方向、大纲和演示来源确定性组合，包含摘要、章节正文、引用列表、风险与限制。
- Skill 可以对摘要或结构提出演示建议，仍需显式应用。
- 报告页提供返回资料研究、查看目录和返回研究首页的入口。
- 点击“完成研究”后保存完成状态；首页卡片改为“已完成/查看报告”。
- 报告页显著显示“演示报告，不作为真实研究结论”。

## 数据与职责边界

- 研究 session 的名称、标签、主题、方向、大纲和完成阶段继续使用现有 API 与数据库仓储。
- 为完成 F180 的步骤闭环，只扩展最小阶段推进能力；不新增真实搜索工具调用、来源抓取、模型生成或证据可信度逻辑。
- Skill 对话与撤销快照属于 UI 辅助状态，使用带 session id 的 localStorage 键保存，并设置版本字段；不混入服务端研究证据。
- 演示检索与报告使用同一份确定性 fixture，避免刷新前后变化或测试不稳定。
- F170 接入真实 Web Search 时替换资料研究演示适配层；F171 接入真实报告时替换报告演示适配层，不改变本设计的步骤、Skill 应用规则和页面布局。

## 错误与恢复

- 服务端读取失败时保留明确重试入口，不展示虚假的空历史。
- 步骤保存失败时保持当前页面和用户编辑内容，显示可重试错误，不提前解锁下一步。
- localStorage Skill 状态损坏时只清理对应 session 的 Skill 状态，不删除研究 session。
- 用户访问未来步骤 URL 时回退到服务端允许的最远步骤，并给出轻量提示。
- 演示检索重复触发必须幂等，不重复增加来源或进度。

## 可访问性与视觉约束

- 步骤锁定、完成和当前状态同时使用图标、文字和颜色表达。
- Skill 建议、应用和撤销按钮具备可读的 accessible name；输入支持 Enter 发送。
- 键盘焦点在 Skill 折叠/展开、步骤切换和错误提示后保持可预测。
- 视觉继续使用现有绿色主色、浅灰边框和研究卡片密度，不引入新的设计系统或依赖。

## 验证与验收

- Research 首页：创建研究、名称必填、标签可选、未完成继续、完成后查看报告。
- 顺序门控：不能通过步骤栏或 URL 跳过未完成步骤；确认后只解锁下一步；刷新恢复正确。
- Skill：按步骤显示快捷指令；建议不自动生效；应用后目标内容改变；撤销恢复；不同 session 状态隔离。
- 方向与大纲：编辑、增删、排序/启用状态保持现有能力，Skill 修改不破坏人工编辑。
- 资料研究：演示任务可逐项完成，采纳/排除幂等，完成后解锁报告。
- 报告：展示确定性演示正文、引用与限制，完成后首页状态和入口更新。
- 视觉：桌面端左侧 Skill + 右侧主流程与参考图结构一致；1280px 和 1920px 不裁切；窄屏可折叠。
- 边界：所有 Skill、来源和报告演示内容都可见标注，不被测试或产品文案声称为真实 AI/Web Search 证据。
