## 两个渲染失败的样例（诚实错误态，不静默丢弃）

**样例一** —— 越界图类型：`xychart` 不在白名单（12 种）内，应落"不支持的图类型"错误态并回显原文：

```mermaid
xychart-beta
  title "补贴退坡曲线"
  x-axis [2024, 2025, 2026]
  y-axis "补贴强度" 0 --> 100
  line [80, 55, 30]
```

**样例二** —— 图类型在白名单（flowchart）但**语法错误**，mermaid.parse 抛错，应落"语法错误"错误态并回显原文：

```mermaid
flowchart TD
  A[开始] -->
  B{缺少目标节点与右括号
  A --> --> C
```

两者都不会让整条消息崩溃，其余 markdown 正常渲染。
