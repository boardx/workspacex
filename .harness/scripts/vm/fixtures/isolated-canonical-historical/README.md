# Historical, non-production test fixtures

These reduced fixtures contain canonical DDL, Python package distribution metadata and canvas audit catalog laws used by portable parser/validator counterexamples. They contain no user rows, account credentials or private key.

They are deliberately historical inputs. They cannot establish a current candidate runtime, restored ledger, provider identity or production readiness. Actual stage execution requires independently generated, protected and hash-bound source/runtime/extractor receipts for the frozen candidate. Tests mutate these fixtures only in memory or temporary files.
