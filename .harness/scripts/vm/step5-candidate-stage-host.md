# Source-owned retained stage host

Input is the existing approved HostTransport and same-identity durable Journal; no new client or connection. Native prepare consumes the fixed root `candidateComposeEmitter` profile, protected config/options refs and source/dependency/lockfile bundle sidecar. Options wrapper is exact `{projectName,runtimeDirectory,runtimeFiles,manifestRef,composeRef,networkRef}`; the native emitter receives only its ordinary two options. RuntimeFiles pins actual raw env and seccomp files. Manifest and Compose are independently root-approved refs; OCI labels are additional image checks, not build authority.

Every Docker invocation verifies the fixed `/usr/bin/docker` 0755 SHA, protected empty Docker config, root Unix socket exact device/inode/owner/mode, held lock and root profile stability. Both emitter and Docker are invoked via held protected parent FD paths. Only fixed image inspect, preexisting source-bound native external project-runtime bridge inspect, bounded full inventory, and exact offline create are allowed. No network creation/start/build/pull command is accepted. The durable same-binding intent is saved before create. Lost create response returns no completion proof; retry requires identical intent and unchanged source facts, with baseline excluded from candidate identity.

Full configuration readback merges actual pinned image Config Env with sealed raw native env files and explicit source environment. It verifies user, Entrypoint/Cmd/WorkingDir, capabilities/security, tmpfs/read-only, logging/resources, ports, mounts, networks and agent service alias. Extra privilege/host access or drift fails. Snapshot output contains actual full candidate plus baseline inspect records, binding, source-profile hash and manifest/Compose refs. It is written only to fixed native stage-snapshot.json, protected0600 with exclusive creation, file/directory fsync and source checks before/after. Raw sensitive inspect fields are never stdout; only refs leave the producer.

Current-epoch verification reads schema2 qualification input and source policy, checks root source hashes, invokes verify_existing_qualification to repeat all raw input and five publication proofs, binds the native qualified-current-epoch manifest raw SHA, and checks retained acceptance bytes plus hold/profile before and after. Old schema/missing refs fail closed. Retained runtime verification checks the actual bound HostTransport plan, six existing helper process identities/session bindings and unchanged runtime seal; it opens no clients.

Tests use mock source facts and commands only: FD request wiring, root refs/dependency/profile/network drift, durable intent, native config and raw env merge, privilege/mount/network/port/config failures, missing mutation authority, baseline and held identity drift. Actual production descriptor/profile/artifact generation and end-to-end factory wiring remain root integration work. No production execution, installation or SQL is authorized by these tests.

`observe_stage` returns the producer-safe candidate+baseline inspection with full Config hashes and source-verified Compose hash map. `observe_completion` requires the actual durable intent/receipt/events recorded by the existing retained server, reads the original flat `validated-production-migration-completion` witness unchanged, queries only the existing diagnostic migration-ledger, and checks fresh witness/count/native ledger hash. `publish_late_evidence` writes fixed safe stage-inspection.json/live-ledger.json0600 refs with file+directory fsync and late readback equality. These refs are actual source outputs rather than caller-referenced JSON.

`candidate_completion_contract.validate_completed(receipt, identity, ledger)` returns the actual native ledger hash only after strict flat witness/identity/count/freshness verification. Native hash serializes sorted rows with object fields in `{name,checksum}` order; generic sorted-key digest has a different value and must not be substituted.
