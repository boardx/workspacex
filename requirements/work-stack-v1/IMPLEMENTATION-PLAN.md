# Three-phase implementation plan

## Phase 1 — Foundation + first 10 DigitalHumans
Scope: S001–S060, W001–W015, D001–D010.

### Platform changes
1. Extend contracts with Work Skill dependency/provenance/locale/eval metadata.
2. Generalize digital-interview LangGraph persistence into a versioned Workflow Runtime.
3. Add DigitalHumanProfile linked 1:1 to existing Agent definition/version.
4. Add avatar metadata and Web/Board rendering.
5. Wire ContextPack, HITL, provenance, artifacts, sandbox and audit end-to-end.
6. Add Eval Runner gates for Skill/Workflow/DigitalHuman.

### Pilot order
Research & Knowledge Analyst → Product Manager → Sales Representative.

### Exit gate
Three realistic journeys pass G0–G6; writes have durable approval and effect receipts; no duplicate runtime/domain is introduced.

## Phase 2 — Scale to 140 / 40 / 30
- Add method experts and broad professional functions.
- Add connector/MCP category registry and live probes.
- Add CN/US professional overlays and profile onboarding.
- Add cross-agent handoff/delegation.
- Batch source ingestion with mandatory A0–A4 policy.

Exit: ≥100 Skills have comparative eval evidence; priority connectors are live-probed; 30 DigitalHumans have avatars and journey evals.

## Phase 3 — Complete 200 / 60 / 60
- Add industry depth and regulated-domain overlays.
- Add catalog/private org library, bump/deprecation lifecycle, usage feedback.
- Open community submissions only after provenance/security/eval gates are automated.

Exit: all 320 entities have owner, exact provenance, evals, release state, telemetry and maintenance path.
