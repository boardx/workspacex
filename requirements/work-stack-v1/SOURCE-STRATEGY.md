# Source and five-strategy policy

Every entity declares exactly one strategy.

## A0 — Direct Adopt
Exact artifact fit + license permits intended commercial modification/distribution. Pin exact revision; retain required NOTICE/attribution; add only WorkspaceX metadata/policy/eval/adapters.

## A1 — Best-of Merge
Multiple sources express the same job with complementary strengths. Build a practice matrix, select best pattern per stage, then author one WorkspaceX canonical artifact. Do not concatenate copied bodies.

## A2 — Clean-room Rewrite
Use when license is restrictive/unclear or semantics require a new implementation. Evidence reviewer outputs abstract workflow facts/requirements; implementation author works from the abstract spec, not protected expression.

## A3 — Cross-platform Rebuild
Use n8n/Activepieces/Dify/Coze/etc. as workflow/control-flow evidence. Rebuild Trigger → Gather → Reason/Transform → Human Gate → Act → Verify → Record with WorkspaceX Skills/Tools. External platform JSON is never the runtime SSOT.

## A4 — Reject / Archive
Unsafe, obsolete, low-value, duplicate-with-no-new-practice, out-of-ICP or legally unusable. Retain evidence only; never mount in active runtime.

## Required provenance
Repository, URL, exact path, commit/SHA/tag, artifact-level license, strategy, copied-or-not declaration, attribution/NOTICE, modification summary, verification date, eval evidence.

Repository visibility/stars are evidence, not permission. Unknown license defaults to reference-only.
