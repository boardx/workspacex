# Board workspace 正式集成验收矩阵

关联：[设计增量](./2026-09-26-library-bottom-dock.md)、[issue #4217](https://github.com/boardx/workspacex/issues/4217)、[设计 PR #4218](https://github.com/boardx/workspacex/pull/4218)、[交互预览 PR #4220](https://github.com/boardx/workspacex/pull/4220)。

本表是正式集成的验收计划，不是 feature 状态副本或通过声明。#4220 已由主 session 验收的范围是 mock 浏览页、全屏真实 Fabric 预览、底部触摸工具及页面内存草稿；预览刷新会重置，不证明生产 API、Yjs 或持久化已接通。正式 Fabric 路由已在待合并的 [#4213](https://github.com/boardx/workspacex/pull/4213)，实时协作 transport 已在待合并的 [#4212](https://github.com/boardx/workspacex/pull/4212)，应复用其实现与已有验收证据，并针对合并后的实际入口重验，不能描述为全部缺失。

所有下列真实浏览器、API、数据库、WebSocket 与全栈验收均由主 session 执行。子 agent 交付实现、组件/单元测试、精确 SHA 和复现步骤。证据必须关联实际验收 SHA、路由、角色、操作及观察结果；静态搜索或 mock 测试不能替代正式链路。

| 场景 | Given | When | Then | 主 session 必需证据 |
|---|---|---|---|---|
| Board 顶级入口 / list | 登录用户具有组织访问权，组织有多个 Board | 点击 Studio 的 Board 导航 | 首屏是浏览页，列出其有权访问的 Board；卡片与管理动作区分；加载、空列表、失败和无权限各有明确状态 | 浏览器导航录像/截图 + list 请求与角色范围核对 |
| 新建成功 | 用户有创建权限，输入合法名称 | 提交新建 | 提交中不可重复触发；服务器成功后列表只新增一项，并进入返回的真实 Board ID 对应编辑器；新画板为空，不混入预览样例 | create 响应 ID、list 回读与动态路由一致 |
| requestId 不确定失败重试 | 服务端可能已经成功创建但响应在网络中丢失 | 用户对同一创建意图重试 | 复用同一个 requestId；最终仅一个 Board，返回同一 ID；失败期间保留名称；新的创建意图使用新的 requestId | 注入响应丢失、两次请求 ID、服务端记录数量与 UI 结果 |
| 名称校验 / rename | 用户有修改权限，已有 Board | 提交空白/越界名称，随后提交合法新名称 | 非法值明确拒绝且不改已有名称；合法更新出现在列表和编辑器，刷新后保持；失败保留输入可重试 | 校验反馈、update 请求、刷新后读回 |
| 归档 / 恢复 | 用户有相应权限，Board 未归档/已归档 | 在管理菜单选择归档/恢复 | 明确使用“归档/恢复”文案和现有 archived 契约；状态与恢复入口可见；刷新后与服务端一致 | updateBoard archived 请求、列表筛选与恢复操作 |
| 真正删除的明确缺口 | 当前仅确认归档 API，没有已签核删除 API | 用户寻找删除入口或查看预览删除 | 不把归档伪装成删除；预览明确仅删演示列表。正式删除只有在删除类型、保留期、ACL、会话失效、blob 回收/恢复、审计契约确认后另行实现验收 | UI 文案/API 对照；未完成契约显式记录，不计删除通过 |
| 独立管理菜单 | 浏览页有可打开卡片与名称/成员/归档管理入口 | 点击卡片主动作，再返回点击管理入口 | 卡片直接进入编辑器；管理菜单不误触打开画板，键盘可达且焦点可返回触发器 | 指针与键盘两条浏览器流程 |
| 动态路由 / back | 存在有权访问的真实 Board ID，也有无权/不存在 ID | 打开卡片、复制 URL 新开页面、使用应用返回和浏览器返回 | /studio/board/:boardId 加载对应画板；返回回到浏览页；无权/不存在不泄露内容，不展示样例或另一张画板 | 多 ID/多角色直接访问与返回记录 |
| 全屏编辑器 | 从浏览页进入 Board，视口为 375/768/1280 及触摸屏尺寸 | 打开编辑器、缩放/调整窗口、展开下方选项 | 编辑器占满应用可用视口；header/dock 不遮挡初始内容；工具弹层不溢出，触摸目标至少 48px；减少动态效果设置生效 | 截图、视口尺寸、实际对象 bounds 和选项边界 |
| readonly | 只读用户进入有内容画板 | 尝试指针、快捷键、工具面板与 API 写入 | 内容可查看，所有变更入口受限；提示与权限一致；服务端拒绝越权，其他会话无变更 | readonly UI + 写请求拒绝 + 第二会话观察 |
| Sticky commands | 编辑者选择底部便利贴，另一会话在线 | 指针或键盘创建、输入中文、拖动、删除 | 创建后直接可编辑；纸面和文字是同一领域对象；一次编辑意图产生相应 canonical command；移动/删除不残留，远端一致 | command/Yjs 观察、中文输入、两会话截图与刷新回读 |
| Shape commands | 编辑者选择形状和颜色 | 创建、改样式、移动/resize | 图形类型与样式按领域命令更新，几何正确，远端/刷新一致；不是仅改 Fabric 本地对象 | 命令记录、对象数据与真实画布对照 |
| Draw commands | 编辑者选择颜色和笔宽 | 完成一笔绘制，取消另一笔 | 完成笔迹成为合法可协作对象；取消不留下半成品；颜色/笔宽与端点正确，刷新保持 | 指针轨迹、对象命令及第二会话/刷新结果 |
| Connector commands | 两个可连接对象已存在 | 从锚点创建箭头，移动/resize 端点对象、改样式/label，再删除端点 | 连接保持绑定；无效目标和取消按确认契约处理；远端删除端点不留下错误引用；自由线预览不算锚点功能通过 | 绑定 ID/commands、两会话移动与删除、刷新回读 |
| 协作与刷新 | 两名独立用户打开同一正式 Board | 分别编辑四类对象、返回列表再打开、刷新并重连 | 操作按 Yjs 契约收敛；服务端确认的内容可恢复；不同 Board 不串数据；刷新后不依赖页面内存草稿 | 两个独立会话、WS/持久化证据、同 Board 恢复与异 Board 隔离 |

验收顺序：先浏览入口与已有正式路由接通，再验权限及生命周期，随后整批四工具与协作恢复。删除契约仍缺失时必须作为单独未完成项保留，不能用归档通过或预览删除通过抵扣。签核与 feature 状态仍由原权威文件和门控维护，本表不修改或复制它们。
