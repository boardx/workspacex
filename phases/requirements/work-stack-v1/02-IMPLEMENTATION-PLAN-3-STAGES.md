# WorkspaceX Work Stack v1 — 三阶段实施计划

## Stage 1 — Foundation + Phase-1 Workforce
**目标**：不是“上 320 个条目”，而是让最小闭环真实可用。
- 50 个优先 Skill：Shared + Product + Sales + Support + Executive + 部分 Marketing。
- 20 个 Reference Workflow：Shared 10 + Sales 8 + Product 2。
- 10 个 Enterprise General Digital Human。
- Digital Human avatar pipeline / directory / picker / Chat+Board participant。
- WorkStackRegistry + DigitalHumanDefinition + WorkflowDefinition contracts。
- 复用 Phase 14/15/18/19；不重做 Skill version、Context 或 Board operation。
- Phase 1 Tools 优先：Web/files、Gmail/Outlook、Calendar、Slack/Teams/Feishu、Google/Microsoft docs、Jira/Linear、HubSpot/Salesforce、Zendesk、Postgres、GitHub。
- 所有 external writes 保持 HITL。

**Exit gate**
1. Research/Product/Sales 三条真实 journey 端到端通过；
2. 50 Skills 均有 baseline eval；
3. 20 Workflows 具备 durable state / reconnect / deny / retry / recovery 测试；
4. 10 Digital Humans 有 avatar、skill/workflow pins、role eval；
5. 越权和未授权副作用为 0。

## Stage 2 — Full Skill Library + Cross-functional Automation
**目标**：扩到 200 Skills、40 Workflows、30 Digital Humans。
- 完成所有功能型 Skill；
- CN/US locale overlays；
- Tool Registry provider adapters 和 category-level abstraction；
- Workflow scheduler / webhook / event triggers；
- multi-agent manager-as-tools + handoff；
- AI Capability Studio 支持 Workflows/Digital Humans 的 draft/trial/publish；
- Board Visual Work Graph 展示运行中的 stage/evidence/gates；
- Source refresh / license drift / upstream bump 自动化。

**Exit gate**
- 200 Skills 都完成 A0–A4 决策和 provenance；
- 至少 100 Skills Verified；
- 40 Workflows journey eval；
- 30 Digital Humans 有 ≥3 journey；
- CN Phase-1 connector pack 和 regulated overlays 可用。

## Stage 3 — Industry Digital Workforce + Production Governance
**目标**：60 Workflows、60 Digital Humans 完整产品化。
- 制造、供应链、零售、金融、保险、医疗运营、生命科学、教育、地产建设、能源、物流、公共服务等行业 overlay；
- 受监管角色 clean-room professional packs；
- org-private Digital Humans / Skill packs；
- verified badges / eval uplift / source health / runtime health；
- autonomy 分级与生产 SLO；
- marketplace/community ingestion 在 G0–G6 成熟后开放。

**Exit gate**
- 60 Digital Humans 全部有 avatar、owner、permission、journey eval；
- 60 Workflows 全部可回放；
- 关键生产 connectors live probe；
- 80% 目标按 task-family Level 3–5 coverage 实测，而非估算；
- source freshness >95%，重大 license/security drift 可自动下线。
