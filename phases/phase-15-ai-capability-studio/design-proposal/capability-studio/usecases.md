# 用户用例与失败边界

状态：待评审提案。每条 R12 为后续执行验证的可观察目标，尚未宣称通过。

## UC-S01 预览与确认来源

开发者输入 GitHub URL 或上传 ZIP。系统解析根目录/子目录/单文件/多 Skill 仓库，固定 commit 或 archive digest，展示文件、许可来源、兼容状态和依赖。用户确认选中项后产生可恢复导入任务。私库授权不足给出重连入口；普通仓库显示需适配。

R12：preview 与 confirm 使用同一快照；相同幂等键相同请求返回同任务，不同请求返回冲突；确认期间上游变化不混入；路径穿越、符号链接逃逸及超限输入被拒；未适配项目不进入可绑定池。

## UC-S02 恢复导入任务

关闭页面或进程重启后，用户重新打开能看到真实任务状态和逐项结果。失败项可重试，完成项不重复创建。取消只影响未提交项，并明确已发生的结果。

R12：重启后 job 状态可读；重试仍引用原快照；每个候选至多一个成功结果；没有无限 running 或虚假整体成功。

## UC-S03 开发多文件草稿

开发者创建、修改、重命名、删除文件并保存。每次修改有期望 revision，服务端原子提交，返回新 revision 和 digest。并发旧 revision 被拒并显示差异，用户选择重载或合并。

R12：连续保存多个文件不增加发布版本、不移动 Agent 绑定；试跑前可见保存状态；写入任一步失败时整个变更集不部分提交。旧两个自动发布 API 不得被新保存按钮调用。

## UC-S04 AI 修改与精确试跑

用户描述修改目的，AI 返回可审阅补丁；确认后才写入草稿。选择模型、MCP 工具与测试输入后启动异步试跑，运行固定当前 revision 和依赖快照。运行期间再修改形成新的草稿，不改变在途测试。

R12：未确认 AI 差异不落库；过期补丁提示冲突；测试产物记录 exact revision/digest/configuration；模型停用或 MCP 未授权在执行前拒绝，不能自动更换模型或扩大授权。

## UC-S05 显式发布与 Agent 绑定

有权限用户查看相同快照的验证结果并显式发布。发布后生成不可变版本，选择目标 Agent 并固定绑定；草稿或 trial snapshot 不可绑定。平台公共发布仍受现有审核规则约束。

R12：发布提交匹配测试证据及最新期望 revision；并发改动导致拒绝而非发布未测试内容；刷新后版本和绑定一致；Agent 资产 ID 与执行身份映射可追溯。

## UC-S06 上游更新与回滚

系统比较 base/local/upstream。无冲突生成新草稿，有冲突逐文件解决；测试通过后显式发布。回滚使用历史快照生成新发布版本，保留历史；绑定切换另行记录。

R12：未确认合并不移动当前发布头；冲突路径可定位；回滚不覆写历史、不暗示外部副作用已撤销；旧 run/产物始终可读取。

## UC-S07 模型治理

管理员接入、测试、启用、查询引用及停用模型。UI 展示真实持久化状态；模型池 ID 和 upstream ID 显式映射。停用选择对在途任务的策略并展示影响。

R12：刷新和另一管理员看到一致状态；新 run 在停用后零模型出站；测试结果绑定配置版本；凭据不会出现在任何输出、日志或导出包。

## UC-S08 MCP 治理

管理员预检连接，审阅发现工具并授权明确范围。运行逐次重检权限和 revision。凭据过期显示重连；重连明确保留/替换/清除凭据，工具权限不自动扩大。

R12：发现不等于授权；撤权后的工具调用被拒；401 有可恢复状态；clear 真正清除旧凭据；多租户隔离成立。

## UC-S09 真实使用与失败反馈

成员从产品入口选择已发布 Agent，在真实项目聊天中运行任务，下载可解析产物。失败消息包含可定位的运行记录，有权限开发者从记录回到工作台。

R12：同一 run 关联 Agent/Skill/Model/MCP 快照；下载字节与产物记录一致；失败归因由服务端推导，客户端不能伪造其他租户/版本；反馈修改形成新草稿并再走回归发布。
