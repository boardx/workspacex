# 跨域一致性评审提案

状态：提案，尚无人类签核。这里记录不变量及待核验点，不作为第二份 API schema。

## 必须串行确认的交界

1. 来源预览必须返回服务器固定的来源快照；确认导入提交预览引用，不重新解析可变 branch。网络重试不能把新上游内容混进已确认的任务。
2. 导入只产生开发草稿。未适配仓库只产生可编辑材料，不能写入可绑定能力池。保存草稿不得调用现有自动发布链路。
3. 草稿修改携带期望 revision，服务器一次性应用多文件变更并生成新 revision；失败不部分提交。冲突返回可定位的差异，不能静默最后写入覆盖。
4. 一次试跑固定草稿 revision、文件 digest、模型配置版本、MCP 授权工具集版本与测试输入。试跑开始后的编辑不改变该次试跑。
5. 发布必须匹配通过测试的同一草稿与依赖快照，并通过现有权限/审核门。编辑或影响执行的依赖变更后，之前测试结果不得替新快照背书。不能只由 UI 隐藏按钮保证这一点。
6. Agent 绑定必须引用不可变发布版本。后台资产列表 ID 与真实运行 Agent ID 的关系要有显式适配；同名、同标题不能作为联结依据。
7. 真实运行重新核验组织权限、Model 启用和 MCP 授权，不把过去测试通过等同于现在允许运行。MCP 重连不得隐式扩大可用工具，凭据变化不输出旧凭据。
8. 上游合并是 base/local/upstream 三方比较；冲突解决落新草稿。回滚发布生成新版本或恢复明确绑定，具体语义与现有版本归档不变量一致，不覆写历史内容。
9. 外部副作用不会因回滚版本而撤销；重试、取消、重复提交和失联恢复均需关联任务 ID 与幂等键，不宣称不可保证的 exactly-once。
10. 迁移保留旧 ID 与历史运行记录；在途 run 继续使用启动时已解析快照，新的安全撤权策略仍生效。数据库迁移、旧入口适配及特性开关先行，完整新体验统一开放。

## 待云端材料消解

- “Skill 单文件编辑”与“多文件编辑已实现”：按实际路由、组件及调用 API 区分，不能形成互斥结论。工作台能选多文件与单次保存只改一个文件可以同时成立。
