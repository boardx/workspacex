# UC-18.4 晋升到个人空间并跨会话召回

> 所属：Phase 18 · L0 → L1。

## R1 概览
- **名称**：把本会话里确认过的知识晋升到个人空间。之后在同一个人空间的任何新会话里，AI 都能召回它。
- **Actor**：会话所有者（也是个人空间的所有者）。
- **目标**：知识不再只活在一次对话里。这是外扩到项目 / 组织前的最小一跳。
- **系统边界**：晋升 API → 执行器 → L1 作用域的新行 + `derived_from` 边 → 召回（uc-18-2）。

## R2 前置条件 / 触发条件
- 前置：
  - 会话是**个人线程**（无项目、`private`，S0-2=A）；
  - 用户是该个人空间的所有者；
  - 待晋升的结论是 `accepted`。
- 触发：
  - 在知识视图里选中一条或多条结论，点「存入个人空间」；
  - 或者 AI 在会话结束时提名「这些值得记住」，由人勾选确认。

## R3 主流程
1. 用户选中结论，点「存入个人空间」。
2. 系统逐条检查：
   - 是否 `accepted`；
   - 证据锚点是否仍然有效；
   - L1 中是否已有同义结论（去重：向量 + 实体重合）。
3. 对通过检查的结论：
   - 在 L1 作用域新建一条结论（`created_by=human`），并用 `derived_from` 边连回 L0 原结论；
   - 相关实体在 L1 做实体解析：已有则合并，没有则新建。
4. L1 中已有同义结论时，由用户选择：
   - 「合并」：把新证据追加到已有结论；
   - 「并存」：两条都保留，标适用差异。
5. 返回逐条结果：成功 / 已存在已合并 / 被拒原因。
6. 此后在该个人空间的任何会话里提问，uc-18-2 的 L1 召回都包含这些内容，并标「来自个人空间知识」。

## R4 备选与异常
- **A1 AI 提名**：会话结束或空闲时，AI 列出候选，**只是提名**，必须由人勾选后才执行 R3。
- **E1 结论不是 accepted**：拒绝（`KG_PROMOTE_REQUIRES_ACCEPTED`），提示先确认。
- **E2 会话不属于个人空间**：入口不渲染；直接调 API 得 `KG_SCOPE_NOT_PERSONAL`。
- **E3 证据源已被删除**：拒绝（`KG_EVIDENCE_REVOKED`）。
- **E4 部分成功**：逐条返回，不整批回滚（与 promote-partial-success 先例一致）。
- **E5 contested 结论**：拒绝，先解决冲突。

## R5 权限与可见性
- 只有个人空间所有者可以晋升，也只有他能召回 L1。
- 会话里的其他成员（如果有）**不能**通过本会话读到所有者的 L1。
- L1 → L2 / L3（项目 / 组织）**不在本阶段**，入口不存在。

## R6 后置条件 / 不包含
- 后置：L1 有新结论，`derived_from` 可回溯到 L0 原结论与原消息；L0 原行不改作用域。
- 不包含：晋升到项目 / 组织；D-32 准入；脱敏闸门（phase-03）。

## R7 业务规则
1. 晋升是**复制 + 连边**，不是移动。来源链不断（uc-7-4 L121 精神）。
2. 只有 `accepted` 可晋升；AI 只能提名。
3. L0 原结论被删除 / 撤回时，L1 副本随之失效（uc-18-5）。

## R8 界面线索
- 知识视图里：多选 + 「存入个人空间」；
- 会话结束时的「值得记住」提名卡片；
- 新会话回答里带「来自个人空间知识」标签（截图待 ui-prototyper 产出）。

## R9 非功能约束
- 单次最多 50 条；逐条结果 < 5 秒返回。

## R10 依赖
- uc-18-1 / uc-18-2 / uc-18-3；「个人空间」= 同一用户全部个人线程（S0-2=A）。

## R11 切分提示
- ① 晋升 API + 去重
- ② L1 召回接入
- ③ AI 提名卡片

## R12 AI Ready 验收线索
- V1 会话 A 确认并晋升「客户 A 要求 v2 下周一上线」→ 同一个人空间里的新会话 B 问「客户 A 有什么要求」→ 召回并标「来自个人空间知识」，引用能点回会话 A 的原消息。
- V2 另一个用户的个人空间里问同样问题 → 零召回。
- V3 晋升 proposed 结论 → `KG_PROMOTE_REQUIRES_ACCEPTED`。
- V4 删除会话 A 的原消息 → 会话 B 不再召回该结论（≤ 5 分钟）。
