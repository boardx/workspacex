# UC-18.2 会话内图谱与向量召回

> 所属：Phase 18 · L0 / L1。扩展 `chat-context-engine` 束的 L3 召回来源；检索策略沿用 context-engine §四（hybrid）。

## R1 概览
- **名称**：回答问题时，AI 同时走图关系和语义相似去找本会话（及已确认的个人空间）里的知识，答案带引用。
- **Actor**：会话参与者（提问的人）、对话 Agent。
- **目标**：「上次说过的那个决定是谁拍的、依据是什么」这类问题能答对，而且每一句都说得出出处。
- **系统边界**：Context API → Retrieval Planner（FTS / 向量 / AGE 图 / metadata / claim 五路）→ RRF 融合 → Context Pack → 模型。

## R2 前置条件 / 触发条件
- 前置：会话存在；提问者对会话有读权限。
- 触发：用户在会话里发出新消息，Agent 开始一轮 run。

## R3 主流程
1. Context API 按 actor 与会话确定可见作用域：L0 = 本会话；L1 = 该用户同一个人空间内**已确认晋升**的知识（uc-18-4）。
2. Planner 对问题做实体解析，得到 `graphSeeds`（命中的 `ontology_objects`）。
3. 五路并行召回：
   - **FTS**：原话、编号、人名；
   - **向量**：`segment_embeddings` + `object_embeddings`，HNSW + 迭代扫描，并做权限过滤；
   - **图**：以种子出发在 AGE 上做 k 跳（默认 2）邻域 / 路径查询，**只返回 id**；
   - **metadata**；
   - **claim**：已确认优先，proposed 标注「未确认」。
4. RRF 融合 + rerank。图路只给加分，不单独决定结果（ADR-114 决策 6）。
5. Context Pack 组装：
   - 每条 item 带 `retrievalReasons`（例如「图：张三 —decided→ 上线 v2」「向量 0.82」）、锚点和 `permissionDecisionId`；
   - 冲突结论成对放入；
   - 未能召回的原因写进 `omissions`。
6. 模型基于 Context Pack 回答。答案里的引用可以点回原消息或原文件位置。

## R4 备选与异常
- **A1 问题里没有可解析的实体**：图路不运行，`omissions` 记「无图种子」，其余四路照常。
- **A2 命中的是 proposed 结论**：可以用，但回答必须标「（未确认）」。
- **A3 命中 contested 结论**：双方都给，回答不得只取一边。
- **E1 AGE 不可用**：图路失败，`omissions` 记「图检索不可用」，界面在回答下方可见。**不静默降级。**
- **E2 向量服务不可用**：同 E1，记「向量检索不可用」。
- **E3 五路全空**：回答说明「本会话里没有找到相关内容」，不得编造。
- **E4 召回内容的源已被删除 / 撤回**：不得出现在 Context Pack 中（uc-18-5）。

## R5 权限与可见性
- 召回范围 = actor 可见的会话（L0）∪ actor 本人的个人空间中已晋升内容（L1）。**永不跨用户、跨组织。**
- 会话其他成员提问时，只能召回 L0 内容，**看不到会话所有者的 L1**。
- 权限判定只在 PG RLS 一处。AGE 返回的 id 必须回 canonical 表按 RLS 读取。

## R6 后置条件 / 不包含
- 后置：本轮 run 的 Context Pack 已落库，可重放（context-pack 束 V6）。
- 不包含：项目、组织层召回；跨会话召回非晋升内容。

## R7 业务规则
1. 引用完整性：Context Pack 里每条 item 必有可定位锚点。
2. 图不决定结果：只给加分；把图路关掉后结果集仍须合理（测试对拍）。
3. 反对证据强制保留（I-12）。
4. `omissions` 与界面上显示的「未能检索」必须同源。

## R8 界面线索
- 回答下方的「引用」chip 可以点回消息或文件；「为什么召回」展开后显示 `retrievalReasons`，含图路径。
- 图或向量不可用时，回答下方有一行可见提示（截图待 ui-prototyper 产出）。

## R9 非功能约束
- 召回阶段 P95 < 1.5 秒（门槛待 S0-4）。
- 带权限过滤的向量召回率 ≥ 0.9（基于现有 `pgvector-permission-recall.test.ts` 改造，门槛待 S0-4）。

## R10 依赖
- uc-18-1（有数据可召回）、uc-18-4（L1）、context-pack 束、`chat-context-engine` 束、ADR-114。

## R11 切分提示
- ① 实体解析 → graphSeeds
- ② AGE 图路接入 `retrieveCandidates`
- ③ 向量 HNSW + 权限召回率门
- ④ Context Pack 的 retrievalReasons / omissions 展示

## R12 AI Ready 验收线索
- V1 会话前文说「张三决定下周一上线 v2，因为客户 A 要求」→ 20 轮后问「上线 v2 是谁定的、为什么」→ 回答含张三与客户 A，两处引用都能点回原消息。
- V2 另一用户的会话里说过同样的事 → 本会话召回为空（零越权）。
- V3 停掉 AGE → 回答下方出现「图检索不可用」，其余路仍有结果。
- V4 关系类评测集：hybrid 的正确召回率 > 纯向量（阈值 S0-4）。
