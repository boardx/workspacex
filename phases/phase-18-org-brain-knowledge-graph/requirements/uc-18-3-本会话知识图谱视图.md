# UC-18.3 本会话知识图谱视图

> 所属：Phase 18 · L0。

## R1 概览
- **名称**：在会话侧栏里看本会话抽出的实体、结论和关系，并能确认、纠正、删除、标冲突。
- **Actor**：会话所有者（可编辑）、会话其他可见成员（只读）。
- **目标**：让人看见 AI「记住了什么」，并能把错的改掉。确认过的内容才有资格晋升（uc-18-4）。
- **系统边界**：web 侧栏面板 → knowledge-graph API → `ontology_actions` 执行器。

## R2 前置条件 / 触发条件
- 前置：会话存在；用户对会话有读权限。
- 触发：用户点开会话的「知识」入口。

## R3 主流程
1. 系统展示两种视图，可切换：
   - **列表**：结论按类型分组，显示状态徽标（待确认 / 已确认 / 冲突）、来源消息、证据数；
   - **图**：用 `@xyflow/react` 画实体与关系，默认只画本会话，最多 200 个节点，超出折叠。
2. 点任一节点或结论，展开来源：原消息片段、附件锚点、谁 / 何时 / 哪个 pipeline 版本抽的。
3. 会话所有者可以对结论执行：
   - **确认**（proposed → accepted）；
   - **改写**（生成新结论并 supersede 旧的）；
   - **删除**（→ superseded + `revoked_at`，保留审计）；
   - **标冲突**（两条结论 → contested）。
4. 会话所有者可以对实体执行：**合并**（两个实体是同一个）、**拆分**、**改名**。
5. 每个动作都是一条 `ontology_actions`，由执行器落表并投影到 AGE。界面在 2 秒内反映。

## R4 备选与异常
- **A1 本会话还没有任何知识**：空态，提示「对话中提到的人、决定和事实会出现在这里」，并提供「整理本会话」按钮。
- **A2 整理中**：显示进度；失败的条目可以单独重试。
- **E1 并发编辑**（两个标签页同时改同一条）：后到者得 `KG_REVISION_CHANGED`，界面提示刷新。
- **E2 非所有者尝试编辑**：按钮不渲染；直接调 API 返回 `KG_NOT_OWNER`。
- **E3 对 contested 结论点「确认」**：拒绝（`KG_CONTESTED_NEEDS_RESOLUTION`），要求先选择保留哪条，或标注两条并存的条件。
- **E4 图渲染节点超限**：折叠为簇并提示，不卡死页面。

## R5 权限与可见性
- 会话所有者：读 + 全部编辑动作。
- 会话其他可见成员：只读，看不到编辑按钮。
- Agent：不能执行确认、改写、删除、合并（这些是人的动作）。可以提交新候选（uc-18-1）。

## R6 后置条件 / 不包含
- 后置：canonical、AGE、向量三处一致；审计里能查到每个动作的执行人。
- 不包含：项目或组织图谱视图、决策树七态（phase-02）、五态机（phase-03）。

## R7 业务规则
1. L0 只用三态展示（待确认 / 已确认 / 冲突），映射见提案 §3.5：
   - `proposed` / `reviewed` → 待确认
   - `accepted` → 已确认
   - `contested` → 冲突
   - `superseded` 不渲染
2. 删除不是物理删除：`superseded` + `revoked_at`，反对证据仍保留。
3. 确认、改写、删除、合并只能由人执行，`created_by=human`，`reviewed_by=<user>`。

## R8 界面线索
- 会话右侧栏新增「知识」tab，包含列表 / 图切换、结论卡片、来源抽屉、编辑菜单（截图待 ui-prototyper 产出）。
- 七态规范：空 / 加载 / 部分失败 / 错误 / 只读 / 正常 / 超限。

## R9 非功能约束
- 200 节点内首屏渲染 < 1 秒；编辑动作反映到界面 < 2 秒。

## R10 依赖
- uc-18-1、`chat` 束（会话可见性）、ADR-114。

## R11 切分提示
- ① 列表视图 + 来源抽屉
- ② 编辑动作 API + 执行器
- ③ 图视图（xyflow）

## R12 AI Ready 验收线索
- V1 所有者确认一条结论 → 徽标变为「已确认」；DB `status=accepted`，`reviewed_by` 为本人。
- V2 非所有者看不到编辑按钮；直接调 API 得 `KG_NOT_OWNER`。
- V3 删除一条结论 → 列表消失，审计可查，DB 行仍在（`superseded` + `revoked_at`）。
- V4 合并两个实体 → 两者的边全部挂到保留实体上，AGE 同步。
