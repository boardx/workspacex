# UC-18.6 对话里说「记住 / 忘掉」，以及矛盾提醒

> 所属：Phase 18 · L0 / L1。来源：`06-user-experience.md` U-4、U-5（人类 2026-09-24「容易使用，获得价值」）。
> 元数据：估点 **8**（与 `../feature_list.json` 中 spec_ref 指向本文件的 feature 点数之和对账，由 validate-fl 核对）。

## R1 概览
- **名称**：不打开任何面板，直接在对话里管理记忆；出现前后矛盾时被轻提醒。
- **Actor**：会话所有者；对话 Agent（只生成确认卡，不执行）。
- **目标**：
  - 让「管住 AI 记什么」和平常说话一样简单；
  - 让「前后说法矛盾」在发生的那一刻就被看见（价值时刻 M3、M4）。
- **系统边界**：对话 Agent 的意图识别 → 行内确认卡 → 人点确认 → 复用 `applyHumanAction` / `promoteToPersonal`。矛盾检测接在入图（uc-18-1）之后。

## R2 前置条件 / 触发条件
- 前置：调用者是会话所有者。
- 触发（任一）：
  - 用户说「记住：…」「把这个记下来」「这个很重要」；
  - 用户说「忘掉 …」「别再提 …」「刚才那个说错了」；
  - 用户问「你记得关于 X 的什么」；
  - 入图时发现新结论与「你确认过」的结论冲突。

## R3 主流程

**A. 记住**
1. Agent 识别出「记住」意图，在回答里放一张确认卡：「要记到你的长期记忆吗？」，卡上附要记的内容（可以改字）。
2. 用户点「记住」→ 系统以**用户本人**的身份执行：先确认该条，再晋升到个人空间（U-3，同一个动作）。
3. 卡片变成「已记住 · 撤销」。

**B. 忘掉**
1. Agent 找出匹配的记忆条目（可能多条），放一张确认卡，逐条列出，默认全选。
2. 用户点「忘掉」→ 对选中的条目执行 `revokeClaim`。L1 副本同时失效（uc-18-5 I-10）。
3. 下一轮对话就不再召回这些条目。

**C. 你记得什么**
1. Agent 走一次召回（uc-18-2），按「你确认过 / AI 记下的」分两组回答，每条带出处。
2. 末尾附一个「管理记忆」链接，打开面板。

**D. 矛盾提醒**
1. 入图时，新结论与一条「你确认过」的结论冲突（执行器判定：同一对实体，关系语义互斥，或同一指标、不同数值）。
2. 系统把两条标为 `contested`，并在**当前这条回答**下方放一张提醒卡：「这和你 9/20 说的『9/29 上线』不一致」，给三个选项：
   - 以新的为准：旧的被新的取代；
   - 两条都留：各自写一句适用条件；
   - 忽略：保持冲突标记，不再提醒。
3. 用户选择 → 执行对应的人工动作。选「忽略」后，同一对冲突**不再弹出**。

## R4 备选与异常
- **A1 意图不确定**（例如「这个挺重要的吧？」）：不出卡片，照常回答。宁可漏，不可误。
- **A2「忘掉」匹配到 0 条**：回答「没找到相关的记忆」，不出卡片。
- **E1 用户不是会话所有者**：不出卡片；如果 Agent 误出，点击时返回 `KG_NOT_OWNER`，卡片显示「只有对话创建者能管理记忆」。
- **E2 卡片过期**（期间该条已被改）：点击时返回 `KG_REVISION_CHANGED`，卡片提示「内容已变化」并刷新。
- **E3 一轮内有多处冲突**：只出**一张**卡，列最重要的一处，其余进面板（E8 不打扰）。

## R5 权限与可见性
- 卡片只对会话所有者渲染操作按钮；其他成员看到的是只读文本。
- **Agent 永远不直接执行**：卡片上的每个动作都要人点击，执行时的身份是点击的人（I-15 不变）。

## R6 后置条件 / 不包含
- 后置：动作结果与面板里手工操作完全一致（同一个执行器、同一条审计）。
- 不包含：团队层的冲突裁决（phase-02 / 03）。

## R7 业务规则
1. 对话里的「记住 / 忘掉」**只生成卡片，不直接生效**。
2. 同一对冲突被「忽略」后永不再提醒，直到其中一条被改。
3. 一轮对话最多一张主动卡片（E8）。

## R8 界面线索
- 回答气泡下方的行内卡片，三种：记住、忘掉、矛盾。卡片可折叠，不遮正文。

## R9 非功能约束
- 意图识别误触发率 ≤ 2%（体验评测集 E8 的一条）。

## R10 依赖
- uc-18-1（入图与冲突判定）、uc-18-3（人工动作）、uc-18-4（晋升）、`06-user-experience.md`。

## R11 切分提示
- ① 冲突检测 + 提醒卡
- ② 记住 / 忘掉意图 + 确认卡

## R12 AI Ready 验收线索
- V1 说「记住：客户 A 的对接人是王经理」→ 出卡片 → 点「记住」→ 新的个人会话里问「客户 A 找谁」答得出，并标出处。
- V2 说「忘掉王经理那条」→ 点「忘掉」→ 下一轮问同样的问题不再召回。
- V3 先确认「9/29 上线」，再说「上线改到 10/1」→ 当轮回答下出现矛盾卡；选「以新的为准」后，旧条目为 superseded。
- V4 选「忽略」后，再提一次 10/1，不再出卡。
