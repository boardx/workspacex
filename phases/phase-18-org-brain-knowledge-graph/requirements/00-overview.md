## R1 概览

- **名称**：组织大脑的最小闭环——chat session 里的知识图谱与向量检索。
- **Actor**：对话发起人（会话所有者）、会话其他可见成员、Agent（只提交候选，不直写）。
- **目标**：在一次对话里说过、传过的事实，AI 之后能**通过图关系 + 语义相似**找回来，并**给出能点回原消息 / 原文件的引用**；
  人确认过的知识可以带到同一个人项目的下一次对话里。
- **系统边界**：chat（`mod-chat`）、Context Engine（检索 / Context Pack）、本体存储（PG canonical + AGE 投影 + pgvector）。
  **不含**：项目现场图谱（phase-02 09-kg）、组织大脑五态机（phase-03 14-brain）、平台大脑。

## R3 北极星与成功标准

- **北极星**：「上次聊过的事，这次 AI 记得，而且说得出出处」。
- **S1 引用可定位**：会话召回的每一条图谱 / 向量内容，100% 带可点回原消息或原文件锚点的引用。
- **S2 零越权**：跨会话、跨用户、跨组织召回泄漏测试为 0。
- **S3 幂等**：同一消息重复处理，不产生重复实体 / 结论 / 边。
- **S4 删除必失效**：删消息 / 附件 / 会话后，对应的图节点、边、向量、晋升副本在 5 分钟内退出召回（与 uc-22-4 同 SLA）。
- **S5 图真的在起作用**：固定评测集上，hybrid（含图）比纯向量在「关系类问题」上的正确召回率更高（门槛在 05 S0-4 由人定）。
- **S6 AGE 不可用可见**：AGE 挂掉时回答里明确说「图检索不可用」，不假装没事。

## R4 硬边界（任何实现都不许越过）

1. **模型不直写本体表**。抽取结果只作为 `ontology_actions` 提交，由服务端执行器校验后落表。
2. **canonical 是 PG 关系表 + RLS**。AGE 和向量都是可重建投影；AGE 查询只返回 id，内容回 canonical 表按 RLS 读取。
3. **反对证据不可删**（沿用 context-pack I-12）。冲突的两条结论并存、成对召回，系统不自动择一。
4. **L0 → L1 晋升必须人点确认**。AI 可以提名，不可以自己晋升。
5. **不静默降级**：AGE / 向量任一路不可用，都要进 Context Pack 的 `omissions`，并在界面上可见。
