# 03 · 投后报告标准、风险判据、交叉验证规则与出处链要求

> 本文件是**投后分析标准的唯一事实源**。Skill 提示词、UI 文案、测试用例一律**引用本文件条目编号**，
> 不复述条目正文（本仓已五次因"同一事实声明在两处"漂移）。

## A. 材料类目清单（Agent 在第 1 步用来判"材料齐没齐"）

编号规则 `PI-M-<序号>`。每类产出三态：`已提供` / `部分提供` / `缺失`（缺失须说明它影响哪几条分析）。

| 编号 | 类目 | 缺了会影响什么 |
|---|---|---|
| PI-M-1 | 财务报表 / 财务报表摘要（当期 + 至少一个可比期间） | B 节全部指标、C-1 全部判据 |
| PI-M-2 | 审计报告（含附注与或有事项） | C-1-6、D-3；附注常是深层风险唯一出处 |
| PI-M-3 | 经营简报 / 业务进展报告 | C-2 业务风险、趋势解释 |
| PI-M-4 | 核心客户与供应商合同条款摘录 | C-2-1 集中度、C-2-2 续约与终止权 |
| PI-M-5 | 关联交易与关联方清单 | C-1-5 定价公允性 |
| PI-M-6 | 股东协议 / 投资协议关键条款（回购、清算优先、反稀释、对赌） | C-4 退出与触发条款、风险窗口时间轴 |
| PI-M-7 | 研发 / 临床 / 项目进展报告 | C-3 里程碑滞后 |
| PI-M-8 | 知识产权清单 | C-3-4 保护期与商业化窗口错配 |
| PI-M-9 | 行业政策与市场研究材料（可由 Agent 外部检索补足） | E 节对标与政策风险 |

## B. 财务指标集（Agent 必须抽取并算出的量，**代码算不是模型算**）

编号 `PI-F-<序号>`。每项输出：数值 + 期间 + 出处（文件/页/单元格）+ 同比/环比 + 算式（若为派生指标）。

| 编号 | 指标 | 派生算式 |
|---|---|---|
| PI-F-1 | 营业收入 | 同比 = (本期−上年同期)/上年同期 |
| PI-F-2 | 净利润 / 利润总额 | 同比；与 PI-F-1 增速差 |
| PI-F-3 | 毛利率 | (营收−营业成本)/营收；与上期差 |
| PI-F-4 | 经营性现金流净额 | 与 PI-F-2 的背离额 |
| PI-F-5 | 应收账款与周转天数 | 周转天数 = 应收平均余额×天数/营收 |
| PI-F-6 | 存货与同比增幅 | 同比；与营收增幅之差 |
| PI-F-7 | 研发支出与资本化率 | 资本化额/研发支出总额 |
| PI-F-8 | 政府补助及占利润总额比 | 补助/利润总额；扣非利润 = 利润总额−补助（税后口径需说明） |
| PI-F-9 | 客户集中度 | 前一大 / 前五大占营收比；须与明细加总核对 |
| PI-F-10 | 关联方采购金额与均价 | 与第三方均价的价差率 |
| PI-F-11 | 货币资金与月均净流出、现金跑道 | 跑道月数 = 货币资金 / 月均经营净流出 |
| PI-F-12 | 有息负债与短期偿付压力 | 短期借款 / 货币资金 |

## C. 风险判据（命中即必须进风险清单）

编号 `PI-R-<类>-<序号>`。每条风险输出四列：**编号 / 问题是什么 / 为什么属于问题 / 在材料中如何体现（可回跳）**，
另加两个字段：`类型 ∈ {显性, 隐性, 跨文件关联}`、`风险窗口时点`（无明确时点填"持续"）。

### C-1 财务类
| 编号 | 判据 |
|---|---|
| C-1-1 | 增收不增利：营收同比为正而净利润同比为负，或两者增速差 > 20pct |
| C-1-2 | 利润与现金背离：净利润为正而经营性现金流为负，或现金流由正转负 |
| C-1-3 | 应收异常：周转天数环比上升 > 20%，或应收增幅显著高于营收增幅 |
| C-1-4 | 存货异常：存货同比增幅显著高于营收增幅，且下游需求有收缩证据时未计提跌价 |
| C-1-5 | 关联交易定价存疑：关联方采购/销售价格与第三方价差 > 10% 且无合理解释 |
| C-1-6 | 会计处理美化利润：研发资本化率超行业区间、折旧年限偏长、收入确认政策变更 |
| C-1-7 | 补助依赖：政府补助占利润总额 > 30%，或扣非后盈利能力显著弱于表观 |
| C-1-8 | 现金跑道不足：跑道月数 < 下一关键里程碑所需月数（须给出缺口月数） |

### C-2 业务类
| 编号 | 判据 |
|---|---|
| C-2-1 | 客户集中度高：第一大客户占比 > 30% 或前五大 > 60% |
| C-2-2 | 合同不确定性：核心合同即将到期未续签，或对方持单方终止权/无违约成本退出权 |
| C-2-3 | 产能/良率/交付未达计划，且未说明原因 |
| C-2-4 | 供应链或关联方依赖：核心原料/服务单一来源 |
| C-2-5 | 里程碑滞后：研发/临床/建设进度完成率低于计划 30% 以上，或未解释滞后原因 |
| C-2-6 | 竞争格局恶化：竞品已获批/上市/进医保/降价，形成先发或价格挤压 |

### C-3 行业与合规类
| 编号 | 判据 |
|---|---|
| C-3-1 | 政策退坡/补贴调整影响当期或次年业绩，且公司未做预案 |
| C-3-2 | 新监管标准将生效而公司现有产线/资质未达标，改造成本未在财报体现 |
| C-3-3 | 涉诉、行政处罚、股权质押、工商异常等外部公开信息与材料陈述不一致 |
| C-3-4 | 专利/授权保护期与商业化窗口错配，独占期被压缩 |

### C-4 条款与退出类
| 编号 | 判据 |
|---|---|
| C-4-1 | 回购/对赌条款触发日临近而触发条件难以满足 |
| C-4-2 | 优先清算权、反稀释等条款在下一轮低估值融资时的稀释与偿付影响 |
| C-4-3 | 退出前置条件未满足：须列出"还缺什么"而非给退出结论（见 `00` 硬边界） |

### C-5 材料自身问题（**不许沿用，必须指出**）
| 编号 | 判据 |
|---|---|
| C-5-1 | 同一事实在材料内部自相矛盾（如台账登记日期与附件原文不一致）→ 列冲突双方出处，进需核实清单 |
| C-5-2 | 关键数据缺期间标签、单位不明、口径未定义 → 回问，不猜 |

## D. 交叉验证规则（跨文件才能发现的问题，**验收必考**）

| 编号 | 规则 |
|---|---|
| D-1 | 财务数字 × 明细表加总：集中度、关联方金额、客户明细必须与汇总数勾稽，不符即报 |
| D-2 | 财务数字 × 合同条款：收入依赖的合同是否到期、是否有单方终止权、最低采购额是否兑现 |
| D-3 | 财务数字 × 审计附注/或有事项：附注披露的变更、解约、补充协议是否解释了报表上的异常 |
| D-4 | 财务数字 × 行业政策：存货/产能/补助/售价的变化方向是否与政策方向矛盾 |
| D-5 | 进度报告 × 资金状况：里程碑所需月数 vs 现金跑道月数，算缺口 |
| D-6 | 进度报告 × 条款时点：里程碑能否支撑回购/IPO/对赌截止日 |
| D-7 | 知识产权 × 上市时点：保护期届满日 vs 预计获批日，算独占期 |
| D-8 | 材料内事实 × 外部公开信息：工商/涉诉/竞品/政策与材料陈述是否一致 |

## E. 外部信息与对标的出处要求

| 编号 | 要求 |
|---|---|
| E-1 | 每条外部事实带：来源标题、URL、发布日期、获取时间；缺任一项即不得进入结论区 |
| E-2 | 外部事实与材料内事实**分栏呈现**，永不混排 |
| E-3 | 可比公司对比须给：公司选取理由、口径年度、指标定义、本司值 / 行业区间 / 偏离幅度 |
| E-4 | 渠道不可达、需登录或仅拿到二手摘录时，降级为"未取证的常识判断"并进需核实清单 |
| E-5 | 任何结论不得引用模型记忆中的数字充当外部数据 |

## F. 报告章节结构（最终产出物的唯一模板来源）

| 编号 | 章节 | 内容 |
|---|---|---|
| F-1 | 报告头 | Agent 版本 / Skill 版本 / 模型 ID / 权限快照 / 材料包哈希清单 / 生成时间 |
| F-2 | 项目与本期概览 | 标的、投资轮次与时间、本期期间、材料清单与 `PI-M-*` 齐备状态 |
| F-3 | 财务分析 | `PI-F-*` 指标表（数值+算式+出处）+ 趋势结论 |
| F-4 | 业务与经营进展 | 产品/客户/产能/里程碑，含未达计划项 |
| F-5 | 行业与对标 | 政策、竞争格局、可比公司（E 节口径，分栏） |
| F-6 | 风险清单 | C 节四列 + 类型 + 风险窗口时点，按等级排序 |
| F-7 | 风险窗口时间轴 | 未来 12 个月的关键时点与触发条件 |
| F-8 | 需核实清单 | 存疑项、降级为未取证项、C-5 冲突项 |
| F-9 | 建议追问清单 | 给被投企业的问题清单，逐条指向某风险编号 |
| F-10 | 退出前置条件 | 只列条件与缺口，**不给退出结论** |
| F-11 | 附录 | 数据来源清单（每个数字 → 出处）、未能解析清单、人工裁决留痕 |

## G. 出处链要求（S5/S6 的机械判据）

| 编号 | 要求 |
|---|---|
| G-1 | 进入 F-3…F-7 的每个数字都能点开定位到文件 + 页/章节/单元格，或外部 URL |
| G-2 | 解析失败的文件必须出现在 F-11 未能解析清单，不得静默跳过 |
| G-3 | "我没读到"与"材料里没有"必须区分呈现，混为一谈判失败 |
| G-4 | 人工驳回/补充/存疑全部留痕（谁、何时、理由），随报告归档 |
| G-5 | 报告头四要素 `agentVersion` / `skillVersion` / `modelId` / `permissionSnapshot` 缺一即判审计不完整 |
