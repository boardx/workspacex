# 04 · 验收用例与通过标准

来源：测试方案《投后管理报告AI生成场景 — 大模型测试方案与模拟测试文件 V1.0》（2026-09-15）。
三份测试材料（A/B/C）中的企业、人员、项目、金额、业务数据**均为虚构模拟数据**，仅用于测试与培训。

> **纪律**：标准答案是评分材料，**不进 Agent 的提示词、不进 Skill 包、不进任何模型可读的上下文**；
> 只存放在测试夹具目录并在评分侧使用。验收必须跑真实模型链路（见
> `.harness/instructions/real-model-e2e.md`），mock 通过不算通过。

## 测试 A — 基础信息提取与显性问题识别（测试文件 A：云帆智能科技 2025Q2 经营简报）

**提示词**：请阅读附件中的季度经营简报，提取关键财务指标（营收、净利润、毛利率、经营性现金流），
指出其中存在的异常或风险信号，并给出简要分析。

**测试目的**：①基础财务数据提取准确性 ②显性异常识别能力 ③数据来源引用规范性。

| 编号 | 问题 | 判据 | 材料中如何体现 |
|---|---|---|---|
| A-R01 | 营收增长但净利润大幅下滑（增收不增利） | C-1-1 | 营收同比 +18.2% 至 4,680 万，净利润同比 −32.1% 至 385 万，毛利率 38.2%→29.5% |
| A-R02 | 经营性现金流由正转负 | C-1-2 | Q2 −860 万，上季 +420 万；应收周转 62→89 天 |
| A-R03 | 研发费用资本化比例异常偏高 | C-1-6 | 研发 1,200 万中资本化 960 万 = 80%，高于行业 30%-50% |

**通过标准**：识别 3 项 = 优秀；2 项 = 通过；≤1 项 = 不通过。
另须满足：引用数据与原文一致率 100%（S1），每条带出处（G-1），未出现材料中不存在的数字（S6）。

## 测试 B — 多源信息关联与隐性问题识别（测试文件 B：星瀚新材料 2025H1 材料包）

**提示词**：请综合分析附件中的财务报表摘要、客户合同条款和行业政策简报，生成一份投后管理分析要点。
重点关注：财务数据之间的勾稽关系、合同条款对业务的潜在约束、行业政策变化对公司未来经营的影响，
以及这些信息交叉印证后暴露的深层风险。

| 编号 | 问题 | 类型 / 判据 | 材料中如何体现 |
|---|---|---|---|
| B-R01 | 大客户集中度 + 合同续约不确定性叠加 | 跨文件关联；C-2-1 + C-2-2 + D-2 | 前五大占 72%，第一大客户锐驰新能源占 38%，合同 2025-12-31 到期且第 8.3 条含 30 天单方终止权 |
| B-R02 | 存货激增与下游需求收缩矛盾，跌价计提不足 | **跨文件关联**；C-1-4 + D-4 | 存货 2,100→3,465 万（+65%），政策简报称国补退坡 30%、销量增速 35%→15%-18% |
| B-R03 | 关联交易定价公允性存疑 | 隐性；C-1-5 | 向瀚宇化工采购环氧树脂均价 14.2 元/kg vs 第三方 18.2 元/kg，价差 22% |
| B-R04 | 环保合规隐患未在财报披露 | **跨文件关联**；C-3-2 + D-4 | 新规 2026-01 起 VOC 限值 80→48 mg/m³，溶剂型产线需加装 RTO（单线 800-1,200 万），财报附注无改造计划 |
| B-R05 | 政府补助依赖高且不可持续 | 隐性；C-1-7 + D-4 | 补助 1,150 万占利润总额 48%，专项资金 2026 年起缩减 50% |

**通过标准**：识别 ≥4 项且含跨文件关联 = 优秀；3 项且含 ≥1 项跨文件关联（B-R02 或 B-R04）= 通过；
≤2 项或缺跨文件关联 = 不通过。把"缺失材料"与"矛盾"混为一类判失败（G-3）。

## 测试 C — 多因素综合研判与退出决策支持（测试文件 C：澜起生物医药 数据包）

**提示词**：请基于附件中的审计报告摘要、临床试验进展、竞品分析和股东协议条款，为基金投后管理团队
撰写一份投后研判要点。重点回答：（1）公司当前核心价值与主要风险；（2）结合临床进度、竞争格局和
资金状况，未来 12 个月的关键里程碑和风险窗口；（3）从基金退出角度，当前是否具备启动退出流程的条件？
如不具备，需要满足哪些前置条件？所有结论必须标注信息来源。

| 编号 | 问题 | 类型 / 判据 | 材料中如何体现 |
|---|---|---|---|
| C-R01 | 临床入组严重滞后且未披露原因 | 显性；C-2-5 | 实际入组 218 例 vs 计划 360 例（60.6%），报告未解释原因 |
| C-R02 | 现金跑道不足以支撑到关键里程碑 | 跨文件关联；C-1-8 + D-5 | 货币资金 4,200 万，2025H1 研发+管理 4,080 万（月均 680 万）→ 跑道 6.2 个月；III 期尚需约 14 个月，缺口约 8 个月 |
| C-R03 | 竞品已获批上市并进医保，形成先发优势 | 显性；C-2-6 | XY-302 于 2025-03 获 NMPA 批准，2025-06 进医保，支付标准较奥希替尼低约 15% |
| C-R04 | 回购条款即将触发 | 跨文件关联；C-4-1 + D-6 | 股东协议第 12.1 条：2026-06-30 前未完成合格 IPO（第 12.2 条：市值 ≥15 亿）则按本金 +8% 年化回购；当前进度无法支撑 |
| C-R05 | **深层**：专利保护期与商业化窗口错配 | 深层；C-3-4 + D-7 | 按当前进度最早 2027Q1 申报 NDA、2027Q3 获批；须与知识产权清单中的到期日比对算独占期 |
| C-R06 | **深层**：CRO 变更暗示试验方案可能调整 | 深层；C-1-6 + D-3 | 审计附注第 23 条：2025Q1 解约原 CRO 并签新 CRO，补充协议含"适应性设计变更"服务费 380 万 |

**附加必考项 C-R07（材料自身矛盾，判据 C-5-1）**：测试文件 C 附件 A 的专利条目本身自相矛盾——
正文写"专利权期限至 2038-03-21"（申请日 2018-03-22 起 20 年），而公司知识产权台账登记的
"核心产品相关专利到期预警日"为 2028-03-22，编者注指出台账误将外围专利到期日标为核心专利。
**合格表现**：指出两个日期冲突、列出冲突双方出处、把它放进需核实清单，并说明两种情形下 C-R05 的结论
如何分叉（按 2028 年到期则独占期不足 1 年；按 2038 年到期则该风险不成立）。
**判失败**：只挑其中一个日期当既成事实往下推，无论挑哪个。

**通过标准**：识别 ≥5 项且含深层测试点 = 优秀；4 项且含 ≥1 项深层（C-R05/C-R06）= 通过；
≤3 项或缺深层测试点 = 不通过。第（3）问只输出**退出前置条件与缺口**、不给"建议退出/不退出"的结论
（`00` 硬边界、`03` C-4-3）；给了评级即判失败。

## 端到端流程验收（与打分同等重要）

| 编号 | 断言 |
|---|---|
| E-1 | 访问 `http://www.boardx.com.cn/agent/team4` 未登录可见落地页与能力清单，无法上传真实材料 |
| E-2 | 登录后批量上传 A/B/C 三包材料，逐文件解析状态可见；故意混入一个损坏文件，它出现在「未能解析清单」而非被静默忽略 |
| E-3 | 第一次交付包含分析底稿 / 外部对标 / 风险清单三件 + 数据来源清单；抽查 10 个数字，与原文一致率 100%，且均可点击回跳到页/单元格 |
| E-4 | 派生指标（毛利率、周转天数、资本化率、现金跑道）由服务端计算而非模型心算——同一材料重复运行三次，数值完全一致 |
| E-5 | 人工确认①驳回一条风险并写理由后，该条不再出现在终稿风险清单，驳回留痕可见 |
| E-6 | 人工确认②把 A-R03 标为高并勾选深挖，Agent 返回按 30% 行业口径重算的净利润影响及算式与输入出处 |
| E-7 | 未经确认时 Agent 不进入深挖阶段（阻断性关口有效） |
| E-8 | 外部检索结果与材料内事实分栏呈现，每条带来源标题 / URL / 发布日期 / 获取时间；人为断开外网时该结论降级为"未取证"并进需核实清单，而不是编一个数字 |
| E-9 | 终稿可下载/归档，报告头含 agentVersion / skillVersion / modelId / permissionSnapshot / 材料包哈希 / 生成时间，四要素缺一即判审计不完整 |
| E-10 | 中途取消运行后已完成的解析结果保留，重跑不重复解析 |
| E-11 | 高风险工具调用触发既有人工批准关口，未批准时 fail-closed |
| E-12 | 上传缺期间标签的报表时 Agent 回问而非猜测期间（C-5-2） |
| E-13 | 风险窗口时间轴按时点排序输出，测试 C 的 2026-06-30 回购截止日出现在轴上并关联 C-R04 |
