## 错误主线 · 后台画布模板编辑器整屏未画，且被报成「原型里根本不存在」

- **v1 做了什么**：`canvas/README.md` 抬头写「其余四屏…此前在原型里根本不存在或只是空按钮」；
  §五.7 把模板「新建（和 AI 聊出分区结构）」「试跑选项目」标为**原型待补**（按钮在、对话面板未渲染）。
  机械核对 `components/canvas/`（11 文件）+ `lib/mock/canvas.ts`：
  `版本历史` / `设计对话` / `双向同步` / `分区属性` / `便签上限` / `填充率` / `允许 AI`
  **七个词全部 0 命中**——整块 30KB 的编辑器一行都没有。
- **为什么错**：原型里它是**成熟的一整屏**（`isAdCvEdit`，偏移 15800335，编辑器覆盖 15800878–15829400）。
- **v2 修正**：按原型四大块逐字复原（下四条）。

### 块 ① 设计对话（原型 15802822–15807464）

- **原型原文**：`回答几个问题，或直接把已有的画布文件丢进来`，4 轮真实对话——
  `这张画布填完，要让人看见哪几类信息？` → 用户答「这个人是谁、他想达成什么、卡在哪、平时怎么做事、谁能影响他」 →
  `切成 信息栏 ＋ 5 个分区 了` → 用户丢 A0 大图 → `persona-A0-2024.canvas.md 已解析 · 6 个二级标题 → 6 区 · 已套用`
  → `按大图补了「动机」区，共 6 区`；带 `↥ 上传画布文件 .md / .canvas / .mmd / 大图照片`。
- **v2**：`DESIGN_DIALOG`（5 条对话，含 A0 大图解析）+ 上传条 + 两个快捷追问（`哪一区大家最填不出来` / `用真实材料试填`）。见 `-default` / `-empty` 图。

### 块 ② 画布 fabric.js ⇄ Markdown 双向同步（原型 15808189–15814733）

- **原型原文**：`画布 · fabric.js` / `Markdown` / `⇄ 双向同步 · 3 秒前`；
  `mermaid 围栏里的节点＝分区，缩进＝层级，画布里的改动写回同一段围栏`；
  `一份 Markdown 两种用法：现场用 fabric.js 渲染成能贴便签的画布，写进报告时按 mermaid 出图。不各自维护两套`。
- **v2**：`CANVAS_MARKDOWN_SYNC`（同步状态 + mermaid 围栏预览 + `从 Markdown 重建画布` + 两条说明）。

### 块 ③ 结构检查器：分区属性含**每区 AI 权限**（原型 15815266–15823987）

- **原型原文**：`信息栏字段 · 5`（姓名/年龄/区域/职位/行业）；`分区（导出为 ## 段落）`；`布局 2/3/4 列`；
  分区属性 `段落标题 / 导出为 / 引导提问 / 便签上限 / 便签颜色 / 必填（空着不能提交产出）`；
  **每分区的 AI 权限**：`AI 能不能动这一区` → `允许 AI 补便签` / `允许 AI 改人写的便签`（15823358–15823987）。
- **为什么这块最关键**：这是**模板级的 AI 权限位**，与 `ai-draft` 屏的留白语义直接相关——
  v1 把 canvas 自列的「AI 能不能动这一区」当待裁决，而原型在模板层就答死了。
- **v2**：`TEMPLATE_ZONES`（6 区，每区 `aiAddSticky` / `aiEditHuman` 两个只读开关）+ 分区属性面板。
  见 `-zone-influence` 图（选中「影响因素」区：`允许 AI 改人写的便签` 为开）。

### 块 ④ 版本历史 + 使用填充率 + 诊断（原型 15824817–15829400）

- **原型原文**：`v4 未发布 / v3 当前发布版·11 个项目在用 / v2 已归档·3 个历史画布仍引用`；`对比`；`回滚到此版`；
  `使用情况 · 近 6 场项目 填充率`：`痛点和挑战 96% / 目标和需求 88% / 行为与偏好 61% / 影响因素 17%`；
  诊断：`「影响因素」6 场里 5 场是空的——大概率不是用户没想法，是提问太抽象。Ava 建议改成「谁能否决他的采购决定？」，这条改动已经放进 v4 草稿`。
- **v2**：`TEMPLATE_VERSIONS`（v4/v3/v2 + 回滚仅对未发布草稿）+ `TEMPLATE_USAGE`（填充率条 + 诊断）。
  **发布 v4 / 回滚**做成危险动作二次确认 + 影响范围（历史画布锁版、发布不可逆）。见 `-publish-confirm` 图。
