## 错误 1 · 16 个面板只渲染了 1 个，其余 15 个标「未探明」

- **v1 做了什么**：`designer-screen.tsx` 的 `CurrentPanel` 对**任何**选中的配置项都只渲染一个占位旗标，
  截图上原文「此项打开后的具体编辑器 —— 二级 sign-off，未探明」。README §G-5 自认「15 个配置项各自打开后
  的编辑器面板均未画……补抽取原型之前不得自行设计其内部交互」。
- **为什么错**：这 15 个面板在原型里**不是未探明，是成品**——它们不在左栏能力域导航上，而在蓝本设计器
  内部的配置目录里，`Read` 整份 17MB 点不到，必须 grep JS 数据区才看得见。v1 没 grep，就把「我没点到」
  当成了「原型没做」。
- **原型证据**（每个面板都有整屏文案，摘要）：
  - 主题与背景（16539281）：`主题句式 / AI 按这个句式从洞察里生成候选 / 必须含时间约束 · 必须可证伪 · ≤30字`
  - 流程 Agenda（16545213）：`没写产出物的环节不能保存 / 抓左侧握把拖动：环节可跨半场 / AI 已核对过节奏……平均超时 22 分钟`
  - 分组规则（16556882）：`场景清单是这里最值钱的部分 / 业主首次评估 · 采购比选 · 并网审批 · 运营期归因`（四场景清单表）
  - 角色与权限（16563250）：`角色权限默认值` 矩阵 `能力｜引导｜组长｜组员｜观察者`，含灰色硬约束 `灰色项不可在蓝本里放开`
  - 项目材料（16588998）：`物料清单 · 9 件` 逐行（便签/马克笔/A0/桌牌/录音设备…按 4 组 16 人换算）
  - 分组打印素材（16594763）：`A0 · HMW 画布 / A3 · 组长手册 / A5 · 洞察卡 / A4 · 进组指引` ＋ `二维码……便签级 OCR 按分区归位，保留在原图中的位置`
  - Skill 绑定（16616349）：`绑定的 Skill · 11 / 亲和图自动聚类 v2……满意度跌到 62% 已降级。发布 v5 前必须替换或解绑`
  - 报告模板（16627026）：`客户交付版 · 18 页骨架 / 一页纸结论 必须人写 / 方法与样本 AI 起草`（18 页骨架）
- **v2 修正**：16 个面板全部落成真实组件（`components/tpl/designer-panels.tsx`），内容逐字来自上述偏移。
  截图 `uc-2-1-panel-01-基本配置` … `uc-2-1-panel-16-报告模板`，一屏一面板。

## 错误 2 · 把「基本配置」降格成分组标题 ⇒ 16 项数成 15，污染完成度分母

- **v1 做了什么**：`CONFIG_GROUPS` 用「基本配置」当第一个**分组标题**，`CONFIG_ITEMS` 只有 **15 项**
  （主题与背景…报告模板），`configTotal()` 返回 15。完成度显示 `13/15`。
- **为什么错**：原型的「基本配置」是**第 1 个面板**（`isBpBasic`，16529477），是一个总览面板——里面装着
  时长档位/形式语言/模型策略/配额/初始化六类，不是一个分组名。左栏结构是「标题『设计环节 16/16』→
  16 个面板 → 中间夹 4 个分组小标题（会前输入/现场/AI 能力/产出）」，**第一段没有小标题**。
  v1 把总览面板误读成第一段的标题，于是少数了一个，`I-5` 的分母从 16 变成 15。
- **原型证据**：目录头 `设计环节` ＋ 绿色 `16 / 16`（偏移 16521552）；其下首个列表项就是有完整内容的
  `基本配置`（决定这个蓝本能被套用到什么场合 / 时长档位最关键 / 套用后会初始化什么…），**它有面板内容，
  不是光秃秃一个分组名**。四个真正的分组小标题 `会前输入 / 现场 / AI 能力 / 产出` 各带 `padding:14px 10px 6px`
  的 section-header 样式，`基本配置` 用的是**列表项**样式。
- **v2 修正**：`CONFIG_ITEMS` 恢复为 **16 项**，第 1 项 `basic-overview`（基本配置）是面板；`CONFIG_GROUPS`
  首段 `divider:false`（不画小标题，与原型一致）。分母恒读 `configTotal()`=16，界面显示 `16 / 16`。

## 错误 3 · 把原型逐字给出的规则报成「待裁决」

- **v1 做了什么**：基本配置/档位区挂了一个红色「与原型冲突 · 待裁」旗标（D-8），旗标文案：
  「原型只说『环节表随之变化』，没有可选/必留之分，也没有压缩时间……此处换档位仅重算数字」。
- **为什么错**：原型在偏移 **16530146** 逐字写着 **`同一套骨架按档位伸缩：可选环节自动增删，必留环节只压缩时间`**。
  这句话原型给了答案，不是待裁——v1 报成 D-8 冲突是把「我没读到」当成「原型没说」。这正是审计说的
  第三次「已有答案却在被重新裁决」。
- **原型证据**：`isBpBasic` 面板正文（16530146）：`时长档位最关键 / 同一套骨架按档位伸缩：可选环节自动增删，
  必留环节只压缩时间`；档位四档旁 `套用时先选档，环节表随之变化`。两句并存，前者就是「可选/必留」规则。
- **v2 修正**：把这句作为**确认内容**加粗渲染在基本配置面板（`uc-2-1-panel-01-基本配置`），**移除** D-8「与原型
  冲突」旗标。换档位增删动画的「演示」层面仍未做（G-3 缩小版），但规则本身不再被当作未决。
