## 建屏时的硬约束（每个 agent 都要遵守）

1. **一律用内核**：`AppShell` / `StateShell` / `components/ui/*` / 设计 token。
   不新建布局、不新建色值、不新建字号档位。
2. **七态全给**：每屏都要能用 `?state=` 走完七种状态。异常态是原型最缺的东西。
3. **每个可交互元素与关键展示区带 `data-testid`**，小写 kebab-case，不含业务数据。
4. **mock 数据照上面的密度做**——一屏三行假数据看不出信息密度问题。
5. 跑 `pnpm --filter web run lint:design` 与 `typecheck` 必须过。
6. 你替 UC 做的、UC 没写明的设计决定，写进 `ui-preview/README.md` 的待确认清单。
