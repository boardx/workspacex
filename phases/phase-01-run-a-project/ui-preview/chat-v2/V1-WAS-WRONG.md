## 错误 2 · 三条「权限模型待裁决」——原型全部答死

v1 在 `uc-8-4-preset-default.png` 右栏渲染了三张「待裁决（UC 未写死）」卡，并在 README §六列为
「本束唯一的权限模型空洞…请在此拍板，别让它漏进 feature_list」。**三条原型都有答案：**

| v1 的「待裁决」 | 原型的答案 | 出处偏移 |
|---|---|---|
| ① 谁能给谁下发预设？组长能不能给本组下发？ | **引导师下发给组长 / 组员**。屏本身只在引导师视角的工作坊详情下出现 | 弹层标题 `新建预设对话（下发给组长 / 组员）` · **16836655** |
| ② 被下发者能不能改预设？ | **能改**。技能是「引导师已配好，可增减」 | `预设技能 · 引导师已配好，可增减` · **15574080** |
| ③ 被下发者能不能拒 / 忽略？推送还是上架？ | **上架供取用**。下发只给入口、出现在「点开即用」区，用不用由本人决定 | `下发只给入口，不代替对话` **15448694** + newChatFoot「点开即用」**16837179** |

- **v2 修正**：右栏三张「待裁决」卡换成**「权限模型：原型已答」**三卡，每卡带答案 + 出处偏移（见 `-default` 图）。
  denied 态（#15）也据此写成「谁能下发=引导师」的原型口径，不再声明为待裁决。

## 错误 3 · 下发对象模型被换成「组范围」，原型主模型是「角色范围」

- **v1 做了什么**：`target: {kind:"all-hands"|"groups"|"roles"}`，截图三档 `全场 / 指定组 / 指定角色`；
  scope-violation 屏建在「下发给第 5 组」上。
- **原型证据**：`to` 字段三取值 = **角色范围** `全部组长 + 组员` / `全部组长` / `全部组员`
  （16974741 起）；编辑器 `下发对象` 是两项角色范围 + **一个可选组覆盖** `只给第 4 组`（15576491 附近）。
  **没有「指定组」作为一等三档**。
- **v2 修正**：`DispatchTargetKind` = `leads-and-members` / `leads` / `members`（角色范围）；
  编辑器叠一个可选 `只给第 4 组` 组覆盖。scope-violation 改为「勾选只给第 4 组 + 预设含仅『能源组』可见的
  『证据检索』→ 越界即拒」（`err-preset-scope`）。

## 错误 4 · 预设语料被换成战略咨询团队，原型是现场小组工具

- **v1 的 3 个预设**：`假设梳理开局`（进入策略拆 4 组假设）/ `访谈速记与提要` / `收益测算模板`，
  agent 是 `Ava 战略分析师 / Scout 同行情报 / Echo 访谈综合 / Ledger 收益测算`——这是 `/chat` 主屏的顾问团队语料。
- **原型的 4 个预设**：`补齐产出缺口`（对着本组画布找缺什么）/ `唱反调` / `事实核查` / `汇报稿三句话`，
  skill 是 `读本组画布 / 缺口检测 / 生成便签 / 反例检索 / 汇报稿`——**全是组员在某个环节现场用的小工具**（16974471）。
- **v2 修正**：`PRESETS` 换成原型 4 条现场小组工具，skill 换成原型 skill。
