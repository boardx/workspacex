## 错误 1 · 「试跑」被降格成一个四行面板——原型是整屏（`isSkRun`，偏移 15728257）

- **v1 做了什么**：`skill-library.tsx` 的 `TryRunPanel` 只有 `input / output`（成功给一行 output，失败给一行 reason+log）——
  四行。`回归用例` 一词在 `apps/web` 命中 **0**。
- **为什么错**：原型的试跑是**整屏两栏**：
  左（测试场景 3 个 / 输入材料 / 运行参数 / 运行一次 · 跑全部用例），右（执行轨迹 / 输出 / **自动校验 4 条** / **存为回归用例** · 重跑）。
  自动校验与回归用例是试跑的**核心**（把「这次跑对了」固化成每次改都会重跑的断言），不是可选装饰。
- **原型证据**（`试跑 · MECE 假设拆解`，`isSkRun`，偏移 15728257 起）：
  - 标题 `试跑 · MECE 假设拆解` / tag `mece-decomposition` / `改动未发布，只影响这次试跑`
  - 测试场景 3 个：`远洋·欧洲进入策略（真实项目材料，3 份访谈＋成本样本）` / `空材料压力测试（看它会不会硬编结论）` /
    `只有反面证据（验证「必须留反对意见」是否生效）`
  - 输入材料 + `↥ 换一批材料`；运行参数：`模型 claude-sonnet-4.6 / 上下文 48k·200k / 组织大脑检索 开·仅已验证 / 温度 0.3`
  - 底部：`运行一次` + `跑全部用例`
  - 运行结果头：`4.2s · 11.8k tokens · ￥0.11`
  - **执行轨迹**（偏移 15700573 附近，skill 版）：`读取 SKILL.md 与 references/output-schema.md` / `按价值链维度切分，得到 4 个分支` /
    `检索证据：本项目 9 条，组织层 3 条` / `按 schema 输出并自检`
  - 输出（pre）：`## 命题 / ## 假设树 / ## 建议下一步`（含致命度·验证成本·证据条数）
  - **自动校验 4 条**（偏移 15704042 附近）：`PASS 必需的三个段落齐全` / `PASS 无证据分支未给置信度（0 处违规）` /
    `PASS 反对证据被保留（1 条）` / `PASS 引用的组织层知识标了有效期（1/1）`
  - 底部（偏移 15706645 附近）：`跑得对的这一次可以钉成回归用例，以后每次改都会重跑` + `存为回归用例` + `重跑`
- **v2 修正**：`skill-tryrun.tsx` + `skill.ts` 的 `TRYRUN_*`，成为独立屏 `?screen=tryrun`。截图 `uc-3-1-tryrun-*`。
  两栏整屏逐字还原；自动校验 4 条 PASS、存为回归用例 / 跑全部用例入口齐备。

## 错误 2 · 误以为 D-06（无沙箱）挡掉了整块试跑

- **v1 的隐含判断**：phase-1 的 skill 是声明式契约、不做沙箱（D-06），于是把试跑做成「样例输入→样例输出」的最小占位。
- **为什么错**：**D-06 挡不住这条**。自动校验（结构段落齐全 / 无证据处不编造 / 未越权调用工具 / 结论未自动写库）
  与回归用例（钉住一次跑对的输入×输出、每次改都重跑并比对）都是对**声明式契约输出**的断言——
  它们不执行任意代码、不需要沙箱，纯前端可呈现，后端可用同一份断言在契约层跑。
- **v2 修正**：右栏「本屏关键约束」显式写明「自动校验与回归用例都不需要沙箱（D-06 挡不住），是对契约输出的断言」；
  屏内 `试跑不落库` 说明「用当前未发布的契约跑，不影响线上」。

## 界面上无法自洽的点（交人类裁决）

1. **试跑归属哪一屏**：原型里试跑既有 **agent 版**（`试跑 · Ava`，`isAgRun`，偏移 15694415）也有 **skill 版**
   （`试跑 · MECE 假设拆解`，`isSkRun`，偏移 15728257）——两者结构几乎一致，只是被试跑对象不同（agent 整体 vs 单个 skill）。
   v2 本轮画的是 **skill 版**（任务点名的是 skill 试跑屏）。**agent 版试跑**（含 `装载 AGENT.md＋prompts/system.md`、
   `拦截越权调用 crm_customer_records`）尚未画——若产品要 agent 级试跑，应在 agent-runtime 域另补一屏，或把本屏做成「被试对象=agent|skill」两态。
2. **自动校验四条 vs 五条**：skill 版原型是 4 条断言（段落/置信度/反对证据/有效期）；agent 版原型是另 4 条
   （先给反方/无证据不编造/未越权/结论未自动写库）。两套断言集不同，v2 按 skill 版复刻。若要统一断言集需产品定标。
