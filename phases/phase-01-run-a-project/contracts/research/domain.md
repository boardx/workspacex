## 零、本束的边界判据（**先读这一节**）

本束管的是 **「研究这个实体，以及它的证据出口」**，不是「研究产出的下游用途」。
判据一句话，可机械执行：

> **这条规则在「研究结论离开研究 Studio」这一刻之前还是之后？**
> **之前（含那一刻的门槛）⇒ 归本束。之后 ⇒ 归下游束。**

| 例 | 判据 | 归属 |
|---|---|---|
| 「结论必须挂着外部来源才能进洞察库」 | **就是那一刻的门槛** | **本束** |
| 「低置信必须标出而不是丢弃」 | 之前（生成时） | **本束** |
| 「冲突先标不确定再上台讨论」 | 之前 | **本束** |
| 「洞察在组织大脑里的五态机与晋升」 | 之后 | phase-03 `14-brain`（**不在本 phase**）|
| 「报告取材范围勾选与成文」 | 之后 | phase-02 `10-report`（**不在本 phase**）|
| 「证据进图谱后的决策推演」 | 之后 | phase-02 `09-kg`（**不在本 phase**）|
| 「研究任务汇入待办看板」 | 之后 | phase-02 `11-board`（**不在本 phase**）|

⚠ **为什么这一节必须在最前面**：D-20 的立论逐字是「它是 **09-kg 证据的主要生产者**、
**10-report 取材范围里「研究」那一项的实体**」——两句都指向下游。
若不先划这条线，本束会顺手把两个 phase-02 模块的形状也定了，
而那两个模块**已经各自有完整 UC 与 feature**（`09-kg` 9 个 / `10-report` 11 个）。
那是「同一事实声明在两处」的教科书形状，本仓已栽六次。

## 二、不变量（每条都可写成机械断言）

| # | 不变量 | 出处 | 违反的后果 |
|---|---|---|---|
| **N-1** | 结论进洞察库 ⟹ 至少挂一条外部来源 | `[原型 @15,326,937B]` 逐字 | 洞察库出现无出处结论，D-20 的立论（证据生产者）作废 |
| **N-2** | 「争议 / 不确定」段的条目**永不**入洞察库 | `[原型 @15,344,827B` 段内`]` | 同上 |
| **N-3** | 低置信来源**必须保留并标注**，不得在任何层过滤 | `[原型 @16,781,061B]` | 「标出而不是丢弃」被实现成「丢弃」 |
| **N-4** | 检索来源 ⊆ `sourcePrefs` | `[原型 @16,906,509B]` 逐字「来源**限定**在」 | 配置沦为装饰，隐私边界失守（`本场转写` 未勾却被读）|
| **N-5** | 冲突项在被**人**判定前，两条结论都停在「争议 / 不确定」 | `[原型 @15,499,042B]` 逐字 | 系统替人拍板 |
| **N-6** | agent 的「建议」不得预选、不得倒计时自动执行 | `uc-24-5` R7.3 | 同上 |
| **N-7** | 研究**只归档不删除**；被引用的证据在归档后不失效 | `[原型 @16,907,049B]` 逐字「已**归档**」 | 引用方凭空断链 |
| **N-8** | 计数是派生值，缺失渲染为 `—` 而非 `0` | `uc-24-3` R7.1 / E1 | 「目标 0，已超额完成」的误读 |
| **N-9** | 提出方（组 / 引导师）必须留痕 | `[原型 @15,330,698B]` / `uc-24-5` R3.3 | 现场复盘与审计断链 |
| **N-10** | 观察者的出口动作集合 = **空集** | `[原型 @16,943,050B]` `roleNow==="obs" ? [] : …` | 只读角色能改全场口径 |
| **N-11** | 入库是**候选**洞察，不是已采信结论 | `[原型 @16,944,170B]`「待入定题池」 | 下游把候选当结论用 |
| **N-12** | 七项配置是执行契约，创建后固化 | `uc-24-1` R6 | 预览句承诺的与实际跑的不是一回事 |

⚠ **N-10 的断言必须打在行为上，不是 `disabled` 属性上**（`uc-24-4` R12.1）。
灰按钮在 API 层挡不住任何东西 —— 这是本仓已确立的判据。

## 四、本束**不**定义什么（防止越界）

- **不定义**洞察库本身（三层记忆、五态机、晋升门槛）—— `14-brain`，phase-03，**已有 21 个 feature**。
- **不定义**知识图谱的节点与推演 —— `09-kg`，phase-02，**已有 9 个 feature**。
- **不定义**报告的取材与成文 —— `10-report`，phase-02，**已有 11 个 feature**。
- **不定义**待办/看板 —— `11-board`，phase-02，**已有 10 个 feature**。
- **不定义**任何新的角色。本束用 `project` 的两层角色（引导师 / 组长 / 组员 / 观察者）原样。
- **不定义**「综合 Studio」（X-D / Q-11）。

⚠ 上面四条**都不是「以后再说」，是「别的地方已经有了」**。
在本束里再写一份 = 第二份声明。这一节的存在就是为了让它在写的时候被挡住。
