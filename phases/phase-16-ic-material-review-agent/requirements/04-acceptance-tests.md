# 04 · 验收用例与通过标准

来源：测试方案 PDF《上会材料智能审阅助手 — 大模型测试方案与模拟测试文件 V1.0》。
三份测试材料（A/B/C）均为**虚构模拟数据**，仅用于测试与培训。

> **纪律**：标准答案是评分材料，**不进 Agent 的提示词、不进 Skill 包、不进任何模型可读的上下文**；
> 只存放在测试夹具目录并在评分侧使用。验收必须跑真实模型链路（见
> `.harness/instructions/real-model-e2e.md`），mock 通过不算通过。

## 测试 A — 基础资料完整性检查（测试文件 A：锐恒精密制造）
**提示词**：请阅读这份上会材料，按照集团上会标准模板逐项检查：1）材料是否覆盖所有必填章节；
2）各章节内容是否完整；3）输出结构化资料汇总提纲和缺失项清单。

**测试目的**：①正确读取归纳多章节材料 ②对照 `03` 的 IC-1…IC-8 判断已满足/未满足并给出材料中相应表述
③输出结构化提纲 + 清单。

**期望输出要点（评分项）**：
- A-1 **投后整合（IC-5 全类）缺失**——材料仅称"后续整合事宜将在投决通过后另行制定"，属空头承诺非满足。
- A-2 **核心竞争力为无支撑形容词**——"技术领先/客户优质/团队稳定"未给专利、客户名单、留任安排，
  IC-2-1 / IC-2-2 / IC-2-4 判部分满足或缺失。
- A-3 **估值与交易条款不完整（IC-3-8/IC-3-9/IC-3-10/IC-3-11）**——只给 DCF 结论与 PE 区间，
  缺敏感性分析、商誉减值压力测试、溢价来源、竞价分析、SPA 条款、IRR/ROIC/回收期、退出机制。
- A-4 **项目主人与投后机制（IC-4 / IC-6 / IC-7 / IC-8）整类缺失**——无责任主体、无五年目标、
  无激励与复盘机制、无决策事项清单与见证性材料。
- 另须正确归纳已满足部分（IC-1-2 市场分析、IC-2-3 财务表现有数据支撑）并附出处。

**通过标准**：四项评分项命中 ≥3 项且**无编造**（未出现材料中不存在的"已满足"判定）；
结论句正确给出"不具备上会条件 + 阻断性缺失编号"。

## 测试 B — 跨文档交叉验证与隐性矛盾识别（测试文件 B：VisionEdge）
**提示词**：同时阅读尽调报告与财务数据摘录，完成：1）项目背景摘要；2）交叉比对找出矛盾或不一致；
3）结合行业知识判断财务数据合理性并标注异常；4）列出需核实的问题清单。

| 编号 | 问题 | 类型 | 材料中如何体现 |
|---|---|---|---|
| B-1 | 收入确认口径不一致：尽调称"现场验收确认"，财务附注 2 写"发货并取得签收凭证确认" | 显性 | 尽调 §3.1 vs 财务附注 2 |
| B-2 | 大客户集中度冲突：尽调称前五占比 42%，财务客户明细加总 58.1% | 显性 | 尽调 §2.2 vs 客户销售明细表 |
| B-3 | 毛利率逆势上升无解释：38%→45%→52%，同期行业龙头下降，无技术突破说明 | 隐性 | 三年毛利率 + 行业常识；尽调未解释 |
| B-4 | 应收周转恶化未入风险章节：62→78→118 天（+90%），风险因素只列技术/客户集中/汇率 | 关联遗漏 | 财务应收数据 + 尽调 §4 遗漏 |
| B-5 | 研发资本化率 65%（878/1350）远超行业 20-30%，全部费用化则亏损显著扩大 | 隐性+关联 | 财务附注 5 + 行业会计惯例 |

**标准答案要义**：B-5 若按 30% 口径重算，净亏损扩至约 2,100 万新元 —— Agent 给重算结论时
必须附算式与输入出处（`03` D 节）。

**通过标准**：命中 ≥3 项且含 ≥1 项隐性（B-3/B-5）为通过；命中 ≥4 项且四列（问题/原因/材料中如何体现/建议追问）
齐全为优秀；把"缺失"与"矛盾"混为一类判失败。

## 测试 C — 深层业务逻辑判断与多源信息关联（测试文件 C：云桥数据）
**提示词**：完整阅读三份材料，完成：1）交易商业实质与核心资产范围；2）收入可持续性与质量；
3）识别可能的关联交易或非公允定价；4）指出未充分披露但对投决有重大影响的事项。注意关键信息分散在不同文件不同位置。

| 编号 | 问题 | 类型 | 材料中如何体现 |
|---|---|---|---|
| C-1 | 云服务转售实为资金通道：占收入 35% 但毛利仅 3%，上下游同受实控人张伟控制，且被排除出重组范围 → 应剔除出估值口径 | 深层 | 情况说明 §2.2 + 附注 3 关联方 + 重组方案范围 |
| C-2 | 会计政策变更恰逢承诺期首季：IDC 收入确认自 2025-04-01 由直线法改为按实际使用量，未来适用法不追溯，变更后 Q2 环比 +22%，承诺期自交割日起算且覆盖 2025Q2 | 深层 | 附注 1 + 情况说明业绩承诺 + 季度数据 |
| C-3 | 运维外包 ~78% 收入来自实控人关联方（8,200+4,500+3,680 万 / 21,000 万），情况说明仅称"客户关系总体稳定"，重组方案无续约保障 | 关联 | 附注 3.1 + 情况说明 §4.1 + 重组方案 |
| C-4 | 设备折旧年限与实际役龄不匹配：机架式服务器按 10 年计提，相当部分购置于 2016-2018 已用 7 年+，剩余可用年限被高估、未来 CapEx 被低估 | 关联+隐性 | 重组方案资产清单 + 附注 2 折旧政策 |

**通过标准**：命中 ≥3 项且含 ≥1 项深层（C-1/C-2）为优秀；命中 2 项为通过；≤1 项需调整提示词或换模型。

## 端到端流程验收（与打分同等重要）
| 编号 | 断言 |
|---|---|
| E-1 | 访问 `http://www.boardx.com.cn/agent/team1` 未登录可见落地页与能力清单，无法上传真实材料 |
| E-2 | 登录后批量上传 A/B/C 三包材料，逐文件解析状态可见；故意混入一个损坏文件，它出现在「未能解析清单」而非被静默忽略 |
| E-3 | 第一次交付包含提纲/缺失清单/风险标注三件，且每条风险四列齐全、出处可点击回跳到页与位置 |
| E-4 | 人工确认①驳回一条缺失项并写理由后，该条不再出现在最终报告的缺失清单，驳回留痕可见 |
| E-5 | 人工确认②把 B-5 标为高并勾选深挖，Agent 返回按 30% 口径重算的净亏损及算式与输入出处 |
| E-6 | 未经确认时 Agent 不进入深挖阶段（阻断性关口有效） |
| E-7 | 最终报告可下载/归档，报告头含 agentVersion / skillVersion / modelId / permissionSnapshot / 材料包哈希 / 生成时间，四要素缺一即判审计不完整 |
| E-8 | 中途取消运行后已完成的解析结果保留，重跑不重复解析 |
| E-9 | 外部检索得到的行业基准与材料内事实分栏呈现，且带来源 URL 与获取时间 |
| E-10 | 高风险工具调用触发既有人工批准关口，未批准时 fail-closed |
