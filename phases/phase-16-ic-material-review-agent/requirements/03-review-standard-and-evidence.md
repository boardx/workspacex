# 03 · 上会标准清单、判据与出处链要求

> 本文件是**上会标准的唯一事实源**。Skill 提示词、UI 文案、测试用例一律**引用本文件条目编号**，
> 不复述条目正文（本仓已五次因"同一事实声明在两处"漂移）。
> 清单正文逐字来自测试方案 PDF 第一部分「上集团会所需要具备的条件」。

## A. 结构化清单（Agent 逐条比对的对象）

条目编号规则：`IC-<大类号>-<序号>`。每条产出四态之一：`满足` / `部分满足` / `缺失` / `不适用`。

### IC-1 战略逻辑：为什么必须买
| 编号 | 条目 |
|---|---|
| IC-1-1 | 战略定位：明确对应集团战略方向与业务布局 |
| IC-1-2 | 市场分析：规模与增速、竞争格局及驱动成功的关键因素 |
| IC-1-3 | 并购必要性：与自建等替代方案比较 |
| IC-1-4 | 并购目的：技术/市场/客户/品牌/渠道/资源或能力等核心目标 |
| IC-1-5 | 战略协同：与集团现有产业、业务、能力的协同价值 |
| IC-1-6 | 时间窗口：为什么当前是最佳时点 |

### IC-2 标的价值：为什么选择它
| 编号 | 条目 |
|---|---|
| IC-2-1 | 核心价值：最核心资产（技术/人才/客户/品牌/渠道/数据/制造能力等） |
| IC-2-2 | 竞争优势：行业地位、技术壁垒、商业模式及成长潜力 |
| IC-2-3 | 财务表现：收入成长性、盈利质量、资产质量、现金流质量 |
| IC-2-4 | 团队能力：核心管理团队、关键人才及留任安排 |
| IC-2-5 | 不可替代性：相较其他方案及其他标的的优势 |
| IC-2-6 | 标的风险评估：①战略风险（市场/技术路线/竞争/政策）②经营风险（客户集中/盈利能力/供应链） |

### IC-3 交易合理性：是否值得买
| 编号 | 条目 |
|---|---|
| IC-3-1 | 业务尽调：市场调研与上下游头部客户访谈，验证行业天花板与真实市占率 |
| IC-3-2 | 财税尽调：盈利质量、资产真实性、表外负债、关联交易，逐项解决方法与底稿支撑 |
| IC-3-3 | 法务尽调：合规、知识产权权属、核心专利/商标纠纷、重大合同及应对策略 |
| IC-3-4 | 人力尽调：核心管理层评分、组织架构与薪酬激励合理性、文化相容性、关键人才流失风险 |
| IC-3-5 | 其他尽调：IT（数据安全与隐私合规、数据出海）、环境（潜在修复责任）等 |
| IC-3-6 | 关键利益方：创始团队、现有股东、核心客户/供应商、债权人 |
| IC-3-7 | 交易架构：交易方式/范围/支付方式/控制权安排/监管审批/资金方案 |
| IC-3-8 | 价格合理性：估值方法与依据；须有 DCF（或 DCF 交叉验证）+ 敏感性分析 + 商誉减值压力测试 + 溢价来源 + 其他潜在买家竞价分析 |
| IC-3-9 | 交易条款：SPA / SHA / 战略协同合同 / 技术转让授权协议等核心条款摘要、影响与预案 |
| IC-3-10 | 投资回报：IRR、ROIC、投资回收周期 |
| IC-3-11 | 退出机制：极端情况下的退出方案 |

### IC-4 项目主人：谁对交易和整合负责
| 编号 | 条目 |
|---|---|
| IC-4-1 | 交易责任主体：交易团队与业务主人的分工；对尽调数据真实性完整性、交易价格与架构合理性负责 |
| IC-4-2 | 投后责任主体：资产归属哪个业务体系、经营第一责任人及其经营目标 |

### IC-5 投后整合方案
| 编号 | 条目 |
|---|---|
| IC-5-1 | 过渡期安排：交割前置条件清单（审批/核心人员留任/关键客户续约/TSA 及费用/数据上平台）、支付节奏挂钩、签约到交割计划 |
| IC-5-2 | 百日整合：交割后百日详细计划（组织调整、客户沟通等）；含剥离则须事前完整剥离预算 |
| IC-5-3 | 治理体系：独立运营 / 深度融合 / 控股赋能及原因 |
| IC-5-4 | 价值兑现：第一责任人的价值创造计划、路径拆解、关键里程碑、链群合约 |

### IC-6 投后发展目标（未来五年）
| 编号 | 条目 |
|---|---|
| IC-6-1 | 战略目标：3-5 年业务定位、行业地位 |
| IC-6-2 | 财务目标：标的收入/利润/利润率/市值/现金流（≥5 年）+ 对收购主体 ROIC/市值/分红/商誉影响 |
| IC-6-3 | 能力目标：技术平台、研发、生态、全球化 |
| IC-6-4 | 组织目标：团队建设、人才结构、组织能力 |

### IC-7 投后经营机制
| 编号 | 条目 |
|---|---|
| IC-7-1 | 正负向激励：薪酬激励、增量分红、股权/期权、跟投、创业赋能；以及未达标/人才流失/整合滞后/风险失控的追责与纠偏 |
| IC-7-2 | 经营复盘：月度/季度复盘、预警、动态调整机制 |
| IC-7-3 | 资源保障：资金、技术、渠道、供应链、品牌等资源支撑 |

### IC-8 决策事项与见证性材料
| 编号 | 条目 |
|---|---|
| IC-8-1 | 决策事项清单：提请投委会审批的全部决策点（估值金额、交易架构、核心条款、业绩目标等） |
| IC-8-2 | 见证性材料：完整尽调报告、SPA、估值模型底稿、领域投决会决议、立项风险提示的闭环跟踪 |

> **总判据**：不能完整、系统地回答以上条目 → **不具备上会条件**。Agent 须在报告首屏给出
> 「阻断性缺失 N 条」的结论句，并列出这 N 条编号。

## B. 四态判据（不许含糊）
| 态 | 判据 | 必须附带 |
|---|---|---|
| 满足 | 材料中存在**可定位的**直接表述，且覆盖该条目全部要点 | 原文摘录 + 文件/页/位置 |
| 部分满足 | 有表述但要点不全（如只给估值结论未给 DCF 假设与敏感性分析） | 已有部分的出处 + 缺口的逐点列举 |
| 缺失 | 通篇无相关表述，或只有"后续另行制定"这类空头承诺 | 说明缺什么、为什么它阻断上会 |
| 不适用 | 该条目对本交易类型确不适用 | 必须写理由，不得默认 |

**反例（测试文件 A 已埋）**：「后续整合事宜将在投决通过后另行制定详细方案讨论」——
这不是 IC-5 满足，是 IC-5 全类缺失；「技术领先 / 客户优质 / 团队稳定」是无支撑的形容词，
不构成 IC-2-1/IC-2-2/IC-2-4 的满足。

## C. 交叉验证规则集（三分类）
| 类 | 定义 | 检测方法 |
|---|---|---|
| 显性矛盾 | 同一事实在两处材料口径不同 | 抽取"同名事实"（收入确认政策、客户集中度、期间数值、口径定义）逐对比 |
| 隐性异常 | 单份材料内部或与行业常识冲突且**无解释** | 趋势校验（多期指标方向）、结构校验（明细加总 vs 汇总）、行业基准校验（外检索取证） |
| 关联遗漏 | 数据已显示恶化/异常，但风险章节或披露未覆盖 | 指标异常集合 ⟂ 风险章节覆盖集合，取差集 |

必检项（最小规则集，实现时作为可并行子任务）：
1. **口径一致性**：收入确认、客户口径、期间、币种、合并范围。
2. **明细加总 = 汇总**：客户明细、分部信息、关联方金额、资产清单。
3. **多期趋势合理性**：毛利率、净利率、周转天数、上架率；逆势变动须有解释。
4. **会计政策变更**：变更时点 vs 业绩承诺期/交割日；变更后首期环比跳变。
5. **资本化与折旧**：研发资本化率 vs 行业区间；折旧年限 vs 设备实际役龄。
6. **关联方**：销售/采购占比、上下游是否同受一方控制（通道业务判定）、合同到期与续约保障。
7. **风险章节覆盖度**：把 3-6 得到的异常逐条对照风险章节，缺的进"关联遗漏"。
8. **重组范围**：被排除出重组范围的业务是否仍计入估值口径。

## D. 出处链要求（S4 的机械判据）
每条结论的 `evidence` 必须是结构化引用，而不是自然语言描述：
- `fileId` + `fileName` + `sha256`
- 定位：PDF → `pageNumber` + `bbox`；DOCX → 段落/表格行列；PPTX → 幻灯片 + 元素；XLSX → sheet + 单元格地址
- `quote`：原文片段（不得改写）
- 若为外部事实：`sourceUrl` + `sourceTitle` + `retrievedAt`，并标 `external: true`
- 若为重算结论：`formula` + 每个输入项各自的上述引用

缺任一项 → 该条结论在 UI 上标"出处不完整"，且**不得进入最终报告的"已满足"一栏**。
