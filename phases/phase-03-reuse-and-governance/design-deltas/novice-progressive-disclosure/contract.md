# design-delta · novice-progressive-disclosure（详情页渐进披露）

> 普通用户评测集（`apps/web/e2e/novice-eval/`，#4332）量出设计详情页首屏 **57** 个可操作控件（预算 15），
> 外加「页面结构 / 纵向布局 / 节点 / 代码 / 批注 / 方案 / 推送到收件箱」这类第一次来的人看不懂的词。
> 人类裁决（2026-09-27）：**渐进披露**（不加模式开关；备选「简单/专业两种模式」「只换词不减控件」未采纳）；
> 用户范围 = 不懂设计的 PM / 运营。

## §1 第一步（已合入，#4342，人类原话「可以不需要右边的 panel」）
右侧「页面结构」树默认不摊开；没选中时右栏只有一句「点画布上的任意一处，这里会出现能改的地方」；
选中元素 / 开历史 / 代码 / 批注时照旧。右栏**位置不动**（避免选中时画布重排、双击改字落空）。57 → 34。

## §2 第二步：一个「更多」菜单

首屏保留（以 4 页项目为例 15 个）：

| 区域 | 保留 |
|---|---|
| 顶栏 | 工作台、分享 |
| 对话 | 照着一张图画、输入框（发送在空时禁用）、再发一次 |
| 工具栏 | 预览 ↔ 回到编辑（一个开关）、撤销、历史、画板、单页、更多 |
| 缩放 | 缩小、百分比（点它回到 100%）、放大、适应画板 |

收进「更多」（Radix 菜单，菜单项沿用原按钮 testid）：

| 分组 | 项 | 改名 |
|---|---|---|
| 画布 | 批注、外观、多出几版对比、演示、重做、显示/收起页面结构 | 方案 → 「这一页多出几版对比」 |
| 这一页 | 改名、加一页、复制、删掉 | — |
| 项目 | 需求说明与验收标准、导出、交给开发排期、从一段已有对话导入背景、给开发看的代码 | 推送到收件箱 → 「交给开发排期」；代码 → 「给开发看的代码」 |

其余：
- 画板视图不再显示页签条（每页上方已有「1 · 首页」标题，点它聚焦）；单页视图照旧有页签。画板上当前页标 `aria-current="page"`。
- 「原型画布 / 说明与验收标准」两个常驻页签去掉；说明页从「更多」进，进去后顶部一颗「← 回到原型画布」。
- 缩放里与「百分比」重复的「实际大小」图标删掉。
- 外观、导出两个组件加受控 `open / onOpenChange / hideTrigger`（不传 ⇒ 行为逐字不变），由菜单项打开。

## §3 不改的
API、数据库、错误码不动；所有动作一个没删，只是换了位置与叫法。
