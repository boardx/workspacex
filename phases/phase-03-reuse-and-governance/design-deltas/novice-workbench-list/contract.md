# design-delta · novice-workbench-list（工作台列表页减负）

> 普通用户评测集（`apps/web/e2e/novice-eval/`）量出工作台列表页首屏 11 个可操作控件（预算 8），
> 以及「线框图」「方案」两个术语。人类指示（2026-09-27）：「继续做工作台列表页」。
> 沿用 `novice-progressive-disclosure` 的裁决：渐进披露、用户范围 = 不懂设计的 PM / 运营。

## §1 改动
| | 原来 | 现在 |
|---|---|---|
| 卡片动作 | 每张卡常驻「编辑」「删除」两颗图标按钮 | 每张卡一个「⋯」（Radix 菜单）：「改名字和标签」「删除这个设计」；菜单项沿用原 testid；读屏名「「项目名」的更多操作」 |
| 模板展示名 | 线框图 | 草图（只改展示名，存储值仍是 `wireframe`；唯一来源 `PROJECT_TEMPLATE_LABEL`） |
| 页头说明 | ……深化成方案，再推回排期 | ……深化成设计稿，再交给开发排期（与详情页「交给开发排期」同一个叫法） |

## §2 不改的
API、数据库不动；删除仍先二次确认（既有行为）。
