# 原型画布「接近 Claude Design」保真评分卡（10 分制）

> 适用范围：`/platform-admin/design-workbench/<id>` 设计详情的**原型画布闭环**（对话 → 画布 → 编辑 → 历史 → 导出）。
> 参照物不是一张图，是 Claude Design 的产品行为（人类 2026-09-06 指令：「迭代到 9 分 / 10 分，接近 Claude Design」）。
> 被评对象：`ui-preview/design-prototype/` 的 11 张截图（真组件 + 夹具）+ `apps/web/e2e/design-prototype-loop.spec.ts`
> 在真浏览器里的行为 + 契约/测试。**打分只由 `rev-uiux` 角色做，实现者不得给自己打分。**
> 合格门槛：**≥ 9**（人类原话）。

## 硬门（不满足总分判 0）
| 门 | 判据 |
|---|---|
| H1 真组件 | 截图必须由 `shot-feedback-design-loop.mjs` 渲染生产同一份组件拍出，不接受手绘/外部图 |
| H2 无回归 | contracts / api design-workbench / web design-loop 三套单测绿；`lint-design`、`lint-ui-material`、`harness doctor --phase 03` 绿 |
| H3 单一事实源 | 原语闭集、容器闭集、字段元数据、设备尺寸、起手模板各只声明一处（有机械门控的以门控为准） |

## 十维（每维 0 或 1 分）
每一维必须点名截图/测试/契约的具体位置作为理由。

| # | 维度 | 给 1 分的判据 | 对应迭代 |
|---|---|---|---|
| D1 | **对话驱动生成** | 一句话 ⇒ 整页原型；模型输出是结构化组件树且过契约；失败退路如实标记 | 0 |
| D2 | **增量修改** | 小改用 patch（setProps/replace/insert/remove），节点 id 稳定；整页/局部两条路互不冲突 | 1 / 7 |
| D3 | **点选即上下文** | 画布点选（含键盘）⇒ 焦点 chip + 路径；发送带 `focusNodeId`；整页重生成后清空 | 2 |
| D4 | **版本历史** | append-only 快照与写回同事务；列表 / 预览横幅 / 恢复（恢复也是一版） | 3 |
| D5 | **画板** | 多页并排、平移缩放（指针中心）、拖拽、适应、聚焦；单页视图保留且不裁切 | 4 |
| D6 | **直接编辑** | 属性面板字段来自契约单源；`null` 删键；拒绝原因闭集回前端并给人话 | 5 |
| D7 | **原语表达力** | ≥ 20 种原语覆盖导航/表单/数据/反馈类；设备尺寸随模板；渲染表穷举 | 6 |
| D8 | **生成体验** | 纠偏 + 一轮修复；可取消（草稿保留）/ 可重试 / 已等待时长与阶段文案 | 7 |
| D9 | **交付** | 每页交互说明；导出 .md / .json / PNG / 复制；文档里说明先于大纲 | 8 |
| D10 | **对话质量与引导** | 设计原则 + few-shot 进 prompt；起手模板；建议 chips 点一下即发 | 9 |

## 明确不计分（与 Claude Design 的已知差距，登记不掩盖）
- 流式生成（token 级）：单次补全 + 修复轮，没有 SSE；进度是按时长估的。
- 画布主题（light/dark 切换）：globals.css 无 `.light`，不另造 token。
- 节点拖拽重排 / 多选 / 复制粘贴：下一轮。
- 像素级样式（颜色/字体自定义）：原语闭集刻意不做。

## 输出格式（rev-uiux 逐字照此输出）
```
硬门：H1 ✓/✗  H2 ✓/✗  H3 ✓/✗
D1 … D10：每维 0/1 + 一句理由（点名截图文件名 / 测试名 / 契约符号）
总分：N/10
未得分项修法：逐条
```
