# Use Cases — Survey

## UC1 — 浏览与创建

- 输入：用户打开问卷列表，选择空白、AI 导入或问卷模板，填写名称及可选标签。
- 输出：空白／模板获得独立草稿并直接进入设计；AI 进入导入内容与 Markdown 校对。
- 前置：用户具有现有问卷创建权限；模板复制内容，不共享可变题目对象。
- 失败：列表／模板加载失败、名称无效、创建失败须保留输入并可重试。

## UC2 — AI 导入与校对（条件步骤）

- 输入：文字、受支持文件或用户自己的已保存录音；可修改生成的 Markdown。
- 输出：可预览、可重新生成的提案；用户确认应用后才生成／更新问卷草稿并进入设计。
- 前置：提案经过现有 Markdown 解析与版本校验；不自动发布。
- 失败：文件过大／类型不支持、模型失败、Markdown 解析失败、版本冲突均不覆盖已有内容。

## UC3 — 设计问卷

- 输入：空白／模板草稿，或已确认应用的 AI 提案；题目及设置编辑动作。
- 输出：保存到 canonical Markdown 的草稿，能刷新恢复；封面、章节、题目及选项一致。
- 前置：已发布版本不可静默覆写；离开未保存页面需提示，合格草稿可自动保存。
- 失败：无效题型／选项、保存失败、版本冲突须显式提示且可恢复。

## UC4 — 发布与回收

- 输入：可发布草稿、截止时间、匿名／限答设置、成功页 Markdown。
- 输出：不可变发布快照、分享链接／二维码、真实回收统计与最近动态。
- 前置：服务端执行发布门禁；同浏览器一次的限制由服务端执行，不承诺跨设备唯一。
- 失败：发布门禁、过期、重复提交、网络失败和停止回收均须有明确状态。

## UC5 — 查看答卷

- 输入：搜索、筛选、分页、选择答卷、有效性处理和导出动作。
- 输出：真实答卷列表／详情与 Markdown 导出；零答卷有空状态。
- 前置：匿名和组织权限边界不变；报告只读取当前发布版本的有效答卷。
- 失败：答卷不存在、无权限、处理冲突和导出失败须显式展示。

## UC6 — 可选模板与分析报告

- 输入：按需选择问卷模板、设计报告模板或生成分析报告。
- 输出：独立模板草稿或基于有效答卷的报告；不阻塞 UC3–UC5。
- 失败：无有效样本、模板或生成失败须可重试，不篡改已发布问卷。
