## 新原型待验收界面与路由

| 界面 | 路由／入口 | 必须核对的行为 |
| --- | --- | --- |
| 问卷列表 | `/studio/survey` | 二级菜单为问卷列表／问卷模板／报告模板；标签、卡片和创建弹窗；无状态筛选、无右上角导入 Markdown。 |
| AI 导入与 Markdown 校对 | `/studio/survey/new/import`，仅 AI 创建 | 文字、文件、录音输入；可编辑、渲染预览、重新生成、确认应用；确认前不改动问卷。 |
| 设计问卷 | `/studio/survey/:id/design`，空白／模板创建直达 | 题型工具箱、封面、章节／题目卡、右侧题目设置；添加、排序、复制、删除、选项、必答；不展示 AI 生成卡或原始问卷内容编辑区。 |
| 发布与回收 | `/studio/survey/:id/publish` | 真实状态、截止时间、匿名／同浏览器一次、成功页、链接／二维码、统计与最近动态。 |
| 查看答卷 | `/studio/survey/:id/responses` 与 `.../responses/:responseId` | 搜索、筛选、分页、详情、有效性处理、导出；零数据和错误状态。 |
| 可选模板／报告 | 问卷模板、报告模板及 `/studio/survey/:id/report` | 不插入设计→发布回收→查看答卷三步主流程，也不阻挡发布。 |

旧 `?step=design|publish|responses` 链接需兼容跳转，并保留 `projectId`。选中题目、弹窗等瞬时状态不是独立路由。桌面和移动端都需真实浏览器截图与 API／数据库链路证据。
