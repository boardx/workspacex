# 问卷需求

估点 **35**

> **2026-09-28 新原型修订：** 下方 R3–R8 是阶段建立时的历史输入，含“五步工作台”和现场投票，并非本轮问卷重构的验收范围。本轮经用户确认的目标以 R9–R15、`docs/superpowers/specs/2026-09-28-survey-prototype-routes-design.md` 及 `contracts/survey/` 为准。当前 `feature_list.json` 只列本轮 F08–F14；旧 F01–F07 定义可由 Git 历史追溯，不再进入当前验收清单。

## R1 模块独立
问卷是独立 phase。后续问卷新增能力、契约修订、UI 调整都在本阶段维护。

## R2 参考来源
问卷直接参考 boardx-dev-template 的问卷系统；在当前仓库中，以已落地的 `/studio/survey` 资源库、`packages/contracts/src/survey.ts`、`phases/phase-02-visible-outcomes/design-deltas/survey-resource-library/contract.md` 和 `survey-continuous-document/contract.md` 作为可追溯细化依据。

## R3 资源库
访问 `/studio/survey` 时停留在问卷与模板资源库；左侧只有问卷列表和模板列表两个一级入口；问卷卡进入 `/studio/survey/:surveyId?step=design`，模板卡进入 `/studio/survey/templates/:templateId`。

## R4 创建与模板
用户可新建空白问卷、从模板新建问卷、新建模板、编辑模板；名称与标签是创建入口的必填可见信息；模板保留分类、题目数、报告章节数和使用次数。

## R5 五步工作台
问卷工作台包含 design、template、publish、responses、report 五步；题目连续渲染，报告章节连续渲染；章节 output 支持 text/chart/image，chart 时必须选择 chartType。

## R6 发布回收
发布前服务端执行质量门禁；发布后生成链接并进入回收状态；回收进度、未交催填、截止、匿名/实名约束和 responses.csv + schema.json 物化可验证。

## R7 分析报告与投票
分析报告按章节输出，保留样本量、题目来源和图表类型；现场快速投票作为问卷的轻量派发形态，支持倒计时、匿名口径、回流报告和证据角标。

## R8 异常流程
非法 step 回落到 design；匿名问卷禁止个人反查；模板和问卷返回路径保持 URL 一致；loading、empty、error 都有稳定可见状态。

## R9 新原型首页与创建
用户打开 `/studio/survey` 时看到问卷列表、问卷模板、报告模板三个二级入口，以及真实问卷卡片、标签筛选、搜索和创建弹窗；不显示状态筛选或右上角“导入 Markdown”。选择空白或模板时，带名称与可选标签创建独立草稿并直接进入 `/studio/survey/:id/design`；直接打开、刷新和返回均保留有效页面，旧 `?step=` 链接兼容跳转并保留 `projectId`。加载失败应显示错误而非示例数据。

## R10 条件式 AI 导入与校对
只有选择 AI 导入创建才进入 `/studio/survey/new/import`。用户可用文字、文件或已获授权的录音输入需求，经真实服务生成 Markdown 提案；可编辑、渲染预览和重新生成。确认前不得将提案应用为问卷，确认后才创建／更新草稿并进入设计；刷新、解析失败、版本冲突时不得静默丢失已校对内容。

## R11 三栏问卷设计器
设计页展示题型工具箱、封面、章节／题目卡和所选题目的设置面板；用户可添加、编辑、排序、复制、删除题目，配置选项与必答。移动端按需打开工具箱和设置。保存使用现有版本校验和 canonical Markdown source，发布后的题目快照不能被草稿编辑覆盖；设计页不显示 AI 生成表单或原始 Markdown 编辑区。

## R12 发布与回收
主流程第二步展示真实发布状态、截止时间、匿名及同一浏览器一次填写、成功页、分享链接／二维码、回收统计和最近动态。发布、停止与恢复经服务端质量门禁和持久化处理，公开填写使用冻结的发布版本；零答卷时统计显示零，不生成示例活动。

## R13 查看答卷
主流程第三步展示真实答卷的搜索、筛选、分页及相邻详情；用户可处理有效性并导出 Markdown。详情具有可直接访问的 URL；无答卷、接口失败和权限不足各有正确状态，不以伪造答卷填充列表。

## R14 可选模板与分析报告
问卷模板、报告模板和分析报告由独立入口访问，不插入三步主流程，也不阻塞发布或查看答卷。模板复用产生独立草稿；报告仅使用对应发布版本的有效答卷，可生成、查看与导出，并明确空数据或失败状态。

## R15 横向验收
空白、模板与 AI 三条创建路径都须经过真实浏览器、API 与数据库完成设计、发布、公开填写、答卷查看；逐屏核对桌面／移动端原型，验证 canonical Markdown 的导入、编辑、保存、发布快照和报告传递。测试或模拟说明不得出现在产品用户界面中；每个可验收工作包单独关联 issue 与 PR。
