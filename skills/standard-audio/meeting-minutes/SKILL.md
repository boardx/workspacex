# Meeting minutes

Use an actual transcript, agenda or supplied notes. If only audio exists, first use audio-transcription within its actual supported runtime limits; the audio must also fit the source-size and codec limits documented by that runtime.

Record available meeting metadata, attendees and source identity. Missing details are Unknown; ask only for information that materially blocks the requested result. Draft from evidence using references/template.md: summary, decisions, action items, unresolved questions and source references. A suggestion is not an approved decision. A mentioned person is not automatically an action owner. Unknown owners and dates remain Unknown. Each decision/action links to its original quote, segment or actual time range; do not invent word-level timestamps.

Keep short meetings concise. Review every significant claim against source text; label corrections or ambiguity. Produce the requested Markdown/Word/PDF using existing file and Office capabilities. Open/render actual files before publication. Use wx_artifact_publish and wait for existing writeback. Publishing a file here does not authorize external distribution, emails or creating tasks; those require separate user intent and actual tools.

Read references/upstream.md for adaptation and scope. No automatic sharing, ASR engine or new task system is included.
