WorkspaceX uses its existing configured realtime ASR provider, not the upstream OpenAI CLI/model or runtime installation instructions. The adapter accepts authorized WAV or MP3 up to 60 minutes, under the existing 8MiB original input limit. Installed offline FFmpeg decodes to mono16k PCM; at most four existing ASR sessions process thirty-second chunks concurrently. Language is detected by the provider; explicit language forcing and speaker diarization are unsupported. Thirty-second source chunks are real sample ranges, not phonetic alignment. The complete tool has a 240-second deadline; slow or unknown remote outcomes fail without automatic resubmission. All chunks must complete before the final transcript is confirmed. Long compressed recordings above the original byte limit remain unsupported. Local deterministic ASR fixtures verify transport and orchestration, not external model recognition accuracy. Missing configuration fails unavailable. No new transcript entity is created; use actual JSON hash and source hash, followed by existing artifact publication.
