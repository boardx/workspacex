# 文档理解检查

1. 记录原始文件名、实际只读路径、MIME、sourceHash；后续请求来源改变或权限失效时，不继续读取旧缓存。
2. 记录解析状态、textPath、textHash、warnings和实际已读取范围。失败文件与空文本不能标为已解析。
3. 每条关键答案附真实章节标题、原文短句或表格行标识；没有定位依据就写“无法定位”，不编页码。
4. 表格检查列名、行数、合并单元格语义、空值、合计与单位。跨页拼接没有证据时保留断裂并说明。
5. 比较原文口径与答案，明确直接事实、计算和推断。原文未出现的字段输出缺失，不补合理猜测。
6. 输出文件必须读回；修改后的Office原件需对应技能的结构/渲染QA。Markdown解析不能证明原始版式正确。
