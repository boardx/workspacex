# 数据分析

先读 references/runtime.md，再复用 upstream/data/skills/analyze/source.md 的问题澄清、计算、质量检查与结果表达流程。该参考为固定版本的 Anthropic Apache-2.0 开源技能，来源见 PROVENANCE.json 与 upstream/LICENSE；本入口是 WorkspaceX 的运行适配。

本包仅处理当前会话已经授权且可读取的文件或已授权查询结果。不调用上游 CONNECTORS.md 中示例服务器，不把列举的 SQL、notebook 或 MCP 当作已接入工具。使用当前真实可调用的文件与 execute 工具；能力缺失时说明阻断，不猜工具名、不要求运行时安装依赖。

1. 记录输入文件名、SHA256、格式、行数、字段类型与分析问题。对 JSON 明确记录数组路径；对 XLSX 明确工作表及公式缓存状态，不把缺失公式缓存当作零。
2. 先报告空值、重复行、数值转换失败和时间范围，再明确过滤、去重及缺失值处理策略。保留原始文件；清洗后的文件写入新路径。重复记录是否删除需依据数据语义，不能默认丢弃。
3. 复用 pandas/numpy 做分组、聚合、比较和描述性统计。记录分母与单位，空集合/零分母输出未知并说明，不用零冒充缺失。相关性不得写成因果，样本结论不得无依据推广到总体。
4. 保存本次实际执行的 Python 代码、参数、依赖版本、清洗计数及结果表，重跑核对已知总量/分组汇总。仅可复现的计算结果进入结论；推测和数据局限另行标明。
5. 需要图表时复用 data-visualization 包与同一份清洗数据。输出代码、结果、来源和局限；只有真实生成并读取校验过的文件才能宣称已交付。
