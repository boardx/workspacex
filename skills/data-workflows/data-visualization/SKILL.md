# 数据可视化

先读 references/runtime.md，再复用 upstream/data/skills/data-visualization/source.md 中图型选择、matplotlib/seaborn 示例与视觉准确性检查。来源见 PROVENANCE.json 与 upstream/LICENSE。本入口明确本次离线运行子集；上游 Plotly、fig.show、交互 dashboard 或在线配色检查不是本包已提供能力。

与 data-analysis 共用已授权文件、清洗口径、预装依赖和输出路径，不建立独立数据入口或图表服务。只有当前工具列表中的 execute/文件接口才可调用；没有真实产物读取能力时不宣称图表已完成。

1. 明确比较问题及输入摘要。趋势用折线、类别比较用条形、分布用直方图；相关图必须注明相关性不代表因果。记录指标单位、时间范围、分母和数据源。
2. 数字来自同一份实际计算结果，不能为了图形美观修改数据。缺失值保留缺口或明确标注，绝不自动填零。类别条形图从零起；不同面板比较保持同一尺度。
3. 使用 matplotlib Agg 和预装中文字体，保存 PNG/PDF 与可读数据表；不调用浏览器或运行时安装 Plotly。输出脚本中保留全部参数及已锁依赖版本。seaborn 可用于不要求额外 SciPy 的基础图型；未安装的统计功能停止并说明。
4. 实际打开每张 PNG，检查中文缺字、标签裁切、图例遮挡、颜色/线型可辨、轴/单位完整。将图中值与结果表逐项核对。渲染成功只是图像生成事实，不是自动通过视觉检查。
5. 给出图表简述与数据表替代，区别缺失、零值、异常点、估计值和不确定性。未完成视觉检查或文件读取校验时明确标记未验证，不交付虚假成功链接。
