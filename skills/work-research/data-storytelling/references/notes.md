## 专业方法摘要

1. 读者画像定型。从 `audience` 取四个量：决策层级（`exec` / `manager` / `practitioner` / `external`）、数字素养（`low`/`high`）、读完可用时间（`60s` / `5min` / `deep`）、已知前情（`priorBeliefs[]`，如"大家以为是定价问题"）。时间预算决定节拍数上限：60s → 主旨 + ≤2 节拍；5min → ≤4；deep → ≤5 + 附录。
