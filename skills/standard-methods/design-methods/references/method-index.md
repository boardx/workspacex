# 设计方法索引

先用本表选方法，再只读取「卡片」列那一个文件里对应编号的卡片。编号全局唯一，卡片里的「衔接」引用的就是这些编号。

「来源」列：**通用** = 业界长期通用、无单一权利人的做法；有明确提出者的写提出者，仅作出处说明，不表示关联或授权。全部说明文字为本项目自写。
