# 可审阅研究计划模板

决策与背景：要决定什么；已有证据来源；仍待验证的假设。
目标表：目标ID｜研究问题｜现有证据｜缺口｜方法｜预期可观察证据｜局限。
招募表：纳入/排除条件｜分层理由｜可达渠道｜偏差风险｜建议样本与依据（非实际人数）。
提纲表：问题ID｜对应目标ID｜中立问题｜追问｜敏感性｜必要性/可跳过。
执行表：试访｜招募｜收集｜综合｜复核｜负责人待定｜日期待定。

问题修订例：“你是不是也觉得流程很方便？”改为“请回忆最近一次完成这项任务的过程。哪一步需要额外处理？”避免把待验证结论塞进问题。

敏感问题例：若目标只关心任务流程，删除收入询问；若研究支付能力确需区间，说明用途、最小必要范围及跳过选择。不把答案外推为身份判断。

验收：每个提纲问题对应真实目标ID；每个敏感问题有必要性和跳过选择；样本数不是已招募人数；不出现编造受访者/发现；缺预算或访问权限明确；参考资料可追溯；预期结果均用将来或待验证语气。
