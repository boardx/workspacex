# 视觉内容制作

先确定作品用途、受众、实际尺寸、必须准确的文案、已有素材的来源与授权。用简短设计说明记录空间层次、配色、文字与主体关系；用户没有要求时不要额外输出长篇设计宣言。让构图服务真实意图，重要文字不能为了风格被改写。

需要生成式配图时调用 `wx_image_generate`，prompt描述主体、构图、背景、色彩和用途。当前sizeProfile只支持square（1024×1024）。为同一生成意图保留一个idempotencyKey；未知结果后不能换key自动再发。工具会在收费提交之前持久化意图，不能把长时间未返回当成没有提交。

当前供应商不支持编辑。referenceAttachmentIds只可选当前运行真实可见原件；传入参考图会先检查权限，再明确拒绝不支持的编辑，不会悄悄忽略参考图。不要用文字声称已经修改原图。无权素材、未配置服务和未知结果均应明确失败。

文字必须精确、需要其他尺寸或静态PDF时，可复用现有离线Pillow/Matplotlib或PDF技能，用实际安装的字体排版；不要安装运行时依赖或下载字体。先复制原件到 `/workspace`，保留 `/inputs` 不变。离线排版路径与生成式图片是不同选择，不假称供应商支持编辑或任意尺寸。检查方法见 `references/quality.md`。

生成工具返回generated和实际workspacePath、mime、尺寸、sha256、模型与任务信息。这个状态不是用户已获得图片；用 `wx_artifact_publish` 发布同一路径和真实MIME，等待staged之后的正式writeback回执。不要返回供应商短效URL或虚构ready artifactId。失败时不拼凑可点击但不可打开的链接。

最终检查实际文件，确认文字、留白、对齐、主体完整和素材来源。严格区分机器检查和实际图像查看：完整解码、像素数量、非背景比例、字体文件存在只证明文件或绘制操作，不能证明中文字形正确、没有豆腐块/乱码或文字未裁切。若实际图像查看工具可用，必须打开最终图片核对；工具不可用时明确字形和排版未检查，报告中也不得把像素统计包装成目视验证。不要只根据文件存在或PNG文件头声称视觉质量合格。对生成式图片里的准确金额、日期、名称或中文文案，应实际查看核对；无法看图时如实记录视觉检查未完成，不推断通过。真实部署限制见 `references/runtime.md`。
