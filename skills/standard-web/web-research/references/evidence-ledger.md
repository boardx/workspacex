# 来源与主张表

来源列：sourceId｜URL｜标题｜retrievedAt｜contentHash｜search-snippet / extracted-text｜是否截断｜来源独立性｜读取失败原因。
主张列：主张｜支持来源及原文定位/短摘录｜反对来源｜适用范围｜事实或推论｜尚缺信息。

例如：两份报道均转述同一官方公告，仅计一个原始来源。抓取返回的 retrievedAt 只证明读取时刻；若正文未写发布时间，就不用于“最近一月发布”的判断。若已读文章支持 A、另一份文章支持 B，应保留不同样本/时期/定义，无法消解时明确冲突。

交付检查：每个关键结论有实际读取的来源；引用可回到返回正文；摘要未冒充全文；哈希与来源记录来自工具；不同结论未混用样本；缺页/截断/访问失败已说明；预算统计包括失败；文件交付状态依据真实回执。

最低失败行为：没有任何可用来源时交付“研究受阻”与已尝试范围，不写看似完成的研究结论。只有部分证据时，只报告已证范围和待核实假设。
