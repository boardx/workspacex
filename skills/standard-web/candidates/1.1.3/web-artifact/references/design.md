# 网页产物视觉适配

设计判据唯一来源为仓库 `.agents/skills/frontend-design/SKILL.md`。
本包的 `references/frontend-design.md` 是构建脚本直接读取该文件生成的字节投影，
不是另一份可编辑判据；原许可证一并投影为 `references/frontend-design.LICENSE.txt`。
构建与验证会对照源文件字节和摘要。先完整阅读该原文的 subject matter、
design principles、process 和 writing 四节，再开始创建文件。

本技能与原文的适配差异：

- 只使用本地、已锁定依赖和运行环境现有字体；原文的字体与素材选择不授予网络访问、远程字体或安装权限。
- 用户已给题材、用途或视觉偏好时直接遵循；信息不足时先记录合理假设与方向，不为一般设计选择中断执行。方向选择仍须能追溯到题材与用户任务。
- 原文的计划与自我批评合并进本技能有界执行计划，不增加无界重做或工具调用。
- 将 `design` 加入 test-record.json，记录题材、受众、主要任务、所选方向、原文判据逐项检查结果和对应截图证据。不要把未查看的截图、像素统计或结构快照算成视觉通过。
- 桌面与移动端各实际查看截图，记录排版层级、文案与主要操作是否满足已选方向；缺乏视觉读取时填写 not_tested 与具体限制，不能称 G-SKILL 已通过。

视觉原文不改变权限、浏览器网络边界、HTML 下载 MIME 或发布回执要求。
