## 一、显性矛盾

### 矛盾 1：收入确认政策两份材料口径不一致（设备销售 + 技术服务）

- **问题**：同一标的的收入确认政策，两份材料给出三处不同表述。
  - 设备销售：尽调报告 §3.1「设备销售按客户**现场验收**确认后确认收入」 vs 财务摘录 附注 2「设备销售在**产品发出并取得物流签收凭证**时确认收入」。
  - 技术服务：尽调报告 §3.1「技术服务按**服务期间分期**确认」 vs 财务摘录 附注 2「技术服务按**完工百分比法**确认」。
  - 软件许可两处一致（交付密钥时点）。
- **原因**（可能，需项目组确认）：① 尽调团队描述的是政策应然、财务摘录反映的是实际账务处理；② 期间内发生过会计政策变更而未披露变更时点与影响；③ 其中一份文件表述有误。

- **对数字的影响方向**：「发出并签收即确认」比「现场验收后确认」**更早**确认收入。机器视觉检测设备需现场安装调试，验收周期通常长于物流签收——**（前提未取证：设备类产品验收周期长于发货，属未取证的常识判断，不作为其他推论的唯一依据）**。若实际按发货确认，FY2025 收入 3,920 万新元中可能包含尚未验收的在途/待验收设备，存在收入提前确认与后续退回风险。这与应收账款周转天数从 62 天升至 118 天在方向上一致（见隐性异常 2）。

### 矛盾 2：前五大客户收入占比 42% vs 明细加总 58.1%

- **问题**：尽调报告称「前五大客户收入占比约 42%」，但财务摘录客户明细逐户加总为 58.1%，差异 16.1 个百分点。
- **原因**（可能）：尽调报告误将明细表最后一行「其他 1,642 万新元，41.9%」当作前五大合计读取（41.9% ≈ "约 42%"），即口径读反。
- **材料中如何体现**：
  - 尽调报告 §2.2：「前五大客户收入占比约 42%」。
  - 财务摘录「主要客户销售明细（FY2025）」：706 / 548 / 432 / 352 / 240，其他 1,642，合计 3,920。
- **机械核算（逐项出处均为上表）**：
  - 前五大合计 = 706 + 548 + 432 + 352 + 240 = **2,278 万新元**
  - 占比 = 2,278 ÷ 3,920 = **58.11%**
  - 明细百分比加总 = 18.0% + 14.0% + 11.0% + 9.0% + 6.1% = **58.1%**（与金额法一致）
  - 其他 = 3,920 − 2,278 = 1,642 万新元 → 1,642 ÷ 3,920 = **41.89% ≈ 41.9%**（与表内"其他"一致，也与尽调报告的"约 42%"一致）
  - 交叉校验：最大客户 706 ÷ 3,920 = 18.01%，与尽调报告「最大客户……约 18%」一致 → 说明两份材料用的是同一套底表，差异来自读数错误而非数据源不同。
- **影响**：客户集中度实际显著高于尽调报告披露水平。58.1% 属高集中度，且前两大客户（18.0% + 14.0% = 32.0%）均为半导体封测客户，行业周期同向。这直接影响 IC-2-6 风险评估与 IC-3-1 业务尽调的结论强度。
- **建议追问**：请项目组更正尽调报告 §2.2 的集中度表述，并补充 FY2023、FY2024 前五大客户明细以判断集中度趋势；补充前五大客户的合同期限、是否独家、有无最低采购量承诺、近 12 个月续约情况。

## 二、隐性异常

### 异常 1：研发资本化率三年单向大幅上升（30.9% → 52.2% → 65.0%），且恰好托住亏损

- **问题**：资本化比例逐年抬升，无任何解释；若还原费用化，亏损幅度显著扩大。
- **材料中如何体现**：财务摘录「研发费用 680 / 920 / 1,350，其中：资本化金额 210 / 480 / 878」；附注 5「资本化率 65%」。
- **机械核算（输入项均取自上述两行）**：
  - FY2023 资本化率 = 210 ÷ 680 = **30.88%**
  - FY2024 = 480 ÷ 920 = **52.17%**
  - FY2025 = 878 ÷ 1,350 = **65.04%**（与附注 5 自述 65% 一致）
  - 若三年均按 FY2023 的 30.88% 资本化，FY2025 应资本化 = 1,350 × 30.88% = 416.9 万新元，较实际 878 少 **461.1 万新元** → FY2025 净利润将由 −1,200 变为 **−1,661.1 万新元**（−1,200 − 461.1）。
  - 若研发全部费用化，FY2025 净利润 = −1,200 − 878 = **−2,078 万新元**；FY2024 = −850 − 480 = −1,330；FY2023 = −580 − 210 = −790。即全费用化口径下亏损为 790 → 1,330 → 2,078，扩大 2.6 倍，而非账面的 580 → 850 → 1,200。
- **常识基准标注**：「65% 的开发支出资本化率高于软件/算法类企业的通常水平」属**未取证的常识判断**，本次材料未提供同行数据。**（前提未取证）** 因此上面的量化重算只依赖材料自身数字（用标的自己 FY2023 的比率作基准），不依赖外部基准。
- **原因**（可能）：① VisioNet 平台在 FY2024-25 进入开发阶段，符合资本化条件的支出确实增加；② 为控制账面亏损而放宽"研究/开发阶段"划分。两者在材料中无法区分——附注 5 只给了结果，没给划分标准。
- **建议追问**：请提供 ①研究阶段与开发阶段的划分标准与判断依据文档；②资本化开发支出的项目清单、起止时点、技术可行性证据；③已资本化无形资产的账面余额、摊销政策与起始摊销时点（材料中完全未披露）；④是否做过减值测试。

### 异常 2：应收账款增速远超收入增速，周转天数近乎翻倍

- **问题**：收入增长 46.3% 的同期，应收账款增长 120.7%，周转天数由 62 天升至 118 天，材料未作任何解释。
- **材料中如何体现**：财务摘录「营业收入 1,850 / 2,680 / 3,920」「应收账款余额 320 / 580 / 1,280」「应收账款周转天数 62 / 78 / 118」。
- **机械核算**：
  - FY2025 收入同比 = 3,920 ÷ 2,680 − 1 = **+46.27%**
  - FY2025 应收同比 = 1,280 ÷ 580 − 1 = **+120.69%**
  - 应收占当年收入比 = 320÷1,850 = 17.3% → 580÷2,680 = 21.6% → 1,280÷3,920 = **32.7%**
  - 用期末余额校验披露的周转天数：1,280 ÷ 3,920 × 365 = **119.2 天**，与披露的 118 天基本吻合 → 说明周转天数用的是期末余额法而非平均余额法（口径本身偏保守方向需确认）。
- **与矛盾 1 的联动**：若收入按"发货签收"而非"现场验收"确认，则期末存在大量已确认收入但未完成验收的款项，正是应收激增的合理解释之一——这两个异常可能是同一个问题的两面。
- **建议追问**：应收账款账龄分析表（FY2023-2025）、按客户拆分的应收余额、坏账准备计提政策与计提金额、期后（FY2026 至今）回款情况、是否存在已确认收入但客户尚未验收的部分。

### 异常 3：毛利率三年提升 14 个百分点（38%→45%→52%）而净亏损同期扩大

- **问题**：毛利率大幅改善、收入翻倍，净亏损却从 580 扩大至 1,200 万新元，材料未解释。
- **材料中如何体现**：财务摘录「毛利率 38% / 45% / 52%」「净利润 −580 / −850 / −1,200」。
- **机械核算**：
  - 毛利额 = 1,850×38% = **703**；2,680×45% = **1,206**；3,920×52% = **2,038**（万新元）
  - 毛利额三年增加 = 2,038 − 703 = 1,335，而净亏损扩大 = 1,200 − 580 = 620
  - 推得费用（研发费用化 + 销售 + 管理 + 财务 + 税等合计）三年增加 = 1,335 + 620 = **1,955 万新元**
  - 其中费用化研发增加仅 = (1,350−878) − (680−210) = 472 − 470 = **2 万新元**
  - 即：**非研发费用三年增加约 1,953 万新元**，远超同期毛利增长——材料完全未披露销售费用、管理费用、财务费用的任何数字，这块"吃掉全部毛利增长还多"的成本是黑箱。
- **注**：上述推算假设净利润与毛利之间只有期间费用与税项，材料未提供利润表明细，故为倒轧值，需项目组以完整利润表验证。
- **常识基准标注**：「设备类业务毛利率三年提升 14 个百分点属于异常陡峭」属**未取证的常识判断**，材料未提供产品结构拆分。**（前提未取证）** 更可能的解释是收入结构向软件/服务倾斜，但材料未披露收入按设备/软件/服务的拆分——这本身是缺口。
- **建议追问**：完整三年利润表（含期间费用明细）、收入按设备/软件许可/技术服务三类的拆分、毛利率按产品线拆分、毛利率提升的驱动因素说明。
