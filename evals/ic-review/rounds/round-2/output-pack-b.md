### 矛盾-1：收入确认政策两份文件写法不同（设备销售 + 技术服务两处）

### 矛盾-2：前五大客户收入占比 42% vs 明细加总 58.1%（差 16.1 个百分点）

- **问题**：尽调报告称"前五大客户收入占比约 42%"，但财务摘录的 FY2025 客户明细加总为 58.1%，两者相差 16.1 个百分点。
- **机械核算（逐项列出输入项出处）**：
  - Malaysia SemiPack Group 706 万新元（财务摘录 客户明细）
  - 苏州晶方半导体科技 548 万新元（同上）
  - PT Astra Otoparts Tbk 432 万新元（同上）
  - 深圳比亚迪电子 352 万新元（同上）
  - Flex Ltd. (Penang) 240 万新元（同上）
  - 合计 = 706 + 548 + 432 + 352 + 240 = **2,278 万新元**
  - 分母 FY2025 营业收入 = **3,920 万新元**（财务摘录 主要财务数据，与客户明细"合计 3,920"一致）

  - 交叉验证：明细表"其他 1,642 / 41.9%"，1 − 41.9% = **58.1%**，与上式一致，说明**财务摘录内部自洽，是尽调报告的 42% 与之不符**。

- **材料中如何体现**：尽调报告 2.2 "前五大客户收入占比约 42%"；财务摘录 客户明细"其他 1,642 / 41.9%"、"合计 3,920 / 100%"。

- **建议追问**：①确认 42% 系笔误还是另有口径（如剔除某类收入、或按合并集团口径归集）；②若存在集团归集口径，请提供同一控制下客户的合并归集表（例如 Flex Ltd. (Penang) 与 Flex 集团其他实体是否应合并计算，合并后集中度可能进一步上升）；③补 FY2023、FY2024 的客户明细，看集中度是上升还是下降趋势；④五大客户的合同期限、续约状态与控制权变更条款。

### 异常-2：应收账款增速（+120.7%）为收入增速（+46.3%）的 2.6 倍，周转天数 62 → 118 天

- **机械核算（输入项出自 财务摘录 主要财务数据）**：
  - 收入增速 FY2024→FY2025 = 3,920 ÷ 2,680 − 1 = **+46.3%**
