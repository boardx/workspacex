## 任务三：跨文档交叉验证

### 【显性矛盾】

**1. 收入确认政策两份材料口径不一致（设备与技术服务两处都不一样）**
- 问题：设备销售的确认时点、技术服务的确认方法，两份材料各写一套。
- 材料中如何体现：
  - 尽调节选 §3.1：「设备销售按客户现场验收确认后确认收入；软件许可按交付密钥时点确认；技术服务按服务期间分期确认。」
  - 财务摘录 附注 2：「设备销售在产品发出并取得物流签收凭证时确认收入；软件许可在交付密钥时确认；技术服务按完工百分比法确认。」
- 原因：可能是尽调团队按合同实质重述、而财务摘录反映公司账面实际做法；也可能是管理层在两份文件中口径不统一。无论哪种，对收入金额都有方向性影响——「发出签收」早于「现场验收」，工业检测设备的现场验收通常还需调试与产线联调，两者之间可能跨期。
- 建议追问：请标的与财务顾问明确**账面实际执行的是哪一套**；提供 FY2023-FY2025 按「现场验收」口径重述的收入表，并列示两口径差异金额与跨期调整；提供期末已发货未验收的设备清单（金额、发货日、预计验收日）。

**2. 前五大客户集中度：42% vs 58.1%，差 16.1 个百分点**
- 问题：同为 FY2025 口径，尽调报告称前五大占比约 42%，财务摘录明细加总为 58.1%。
- 材料中如何体现：
  - 尽调节选 §2.2：「前五大客户收入占比约 42%」
  - 财务摘录明细：706 + 548 + 432 + 352 + 240 = 2,278 万新元
- 算式与出处：2,278 ÷ 3,920 = 58.11%（分子为财务摘录五行客户金额之和，分母为财务摘录「合计 3,920」）；用材料自带的百分比列交叉验证：18.0 + 14.0 + 11.0 + 9.0 + 6.1 = 58.1%，与金额口径一致。另核：「其他 1,642」÷ 3,920 = 41.89%，与「其他 41.9%」一致，且 2,278 + 1,642 = 3,920 合计闭合。**即财务摘录内部自洽，42% 这个数对不上的是尽调报告。**
- 原因推测：42% 很可能是尽调报告误引了「其他客户占比 41.9%」这一行（两数仅差 0.1 个百分点，高度疑似串行）；也可能是尽调用了不同年度或合并了同一集团口径。
- 建议追问：请尽调团队说明 42% 的取数来源与口径；若确为串行错误，需检查尽调报告其余数字是否存在同类引用错误。这一条直接影响 IC-2-6/IC-3-1 对客户集中风险的定性——58% 与 42% 是两个风险级别。

**3. 最大客户占比两份材料一致（无矛盾，备查）**
- 尽调节选「最大客户…2025 年收入贡献约 18%」；财务摘录 Malaysia SemiPack Group 706 / 3,920 = 18.01%。两者吻合，可作为 706 万新元这一行的相互印证。

### 【隐性异常】

**4. 应收账款增速远超收入增速，周转天数三年翻倍**
- 问题：收入 FY2024→FY2025 增长 46.3%（(3,920-2,680)/2,680），应收账款同期增长 120.7%（(1,280-580)/580），周转天数 62→78→118 天，单调恶化且 FY2025 跳升 40 天。
- 材料中如何体现：财务摘录「应收账款余额 320 / 580 / 1,280」「应收账款周转天数 62 / 78 / 118」。
- 交叉印证：这一趋势与矛盾 1 中的收入确认口径差异方向一致——若按「发出签收」确认收入而客户实际以「现场验收」为付款前提，账面必然先挂应收、回款滞后。两个异常可能同源。
- 原因（待核实）：可能是 FY2025 集中发货、客户验收周期拉长、放宽信用政策冲收入，或存在个别客户逾期。
- 建议追问：FY2025 期末应收账龄表（按客户、按账龄段）、坏账计提政策与计提额、期后回款情况（截至最近一期已收回多少）、是否存在超期 180 天以上款项。

**5. 毛利率三年从 38% 升至 52%，材料未作任何解释**
- 问题：14 个百分点的连续跃升，与「尚处投入期、亏损持续扩大」的叙述并置，材料未给出原因。
- 材料中如何体现：财务摘录「毛利率 38% 45% 52%」；尽调节选 §3.2「尚处投入期，FY2025 净亏损约 1,200 万新元」。
- 可能原因（需材料佐证，非材料所述）：收入结构向软件许可倾斜、规模效应、或**成本口径变化——包括研发资本化把原本进成本的人工挪出损益**（见第 6 条，两者可能同源）。
- 建议追问：FY2023-FY2025 分产品线（设备/软件/服务）的收入与毛利拆分；成本归集口径是否在期间内变更；研发人员成本在「营业成本 / 研发费用 / 资本化」之间的分摊规则。

**6. 研发资本化率 65%，且三年单调抬升，对亏损与净资产的影响未披露（前提未取证）**
- 问题：资本化金额占研发总支出的比例 FY2023 为 30.9%（210/680）、FY2024 为 52.2%（480/920）、FY2025 为 65.0%（878/1,350，材料自述「资本化率 65%」）。比例两年翻一倍，材料未解释政策或项目阶段划分是否发生变化。
- 算式与出处：分子分母均取自财务摘录「研发费用 680 / 920 / 1,350」与「其中：资本化金额 210 / 480 / 878」；65% 一项另有附注 5 自述佐证。
- 机械测算：若 FY2025 研发支出全部费用化，净亏损将从 -1,200 扩大至 -2,078 万新元（-1,200 - 878），即**账面亏损被资本化政策缩小了约 42%**。（仅为口径敏感性测算，未考虑当期开发支出摊销的抵消，实际差额需按摊销政策调整。）
- ⚠ **未取证的常识判断**：「65% 的资本化率相对同业偏高、且连续抬升通常需要解释」属于我的既有行业经验，本次材料中没有任何同业资本化率数据支撑。该判断不得作为其他推论的唯一依据，需以下列材料取证后再定性。
- 建议追问：研究阶段与开发阶段的划分标准与判断依据、逐个资本化项目的技术可行性证据、开发支出的摊销年限与起点、是否已有资本化项目减值迹象、资本化开发支出的期末账面余额；以及新加坡审计师对该政策的意见。

**7. 三年持续亏损且亏损扩大，与「盈亏平衡在 FY2027」之间没有路径**
- 问题：净利润 -580 → -850 → -1,200，亏损额逐年扩大；材料仅给出「管理层预计 FY2027 盈亏平衡」一句，无任何测算。
- 材料中如何体现：财务摘录「净利润 -580 -850 -1,200」；尽调节选 §3.2。
- 建议追问：FY2026-FY2030 经营预测模型（含收入驱动因子、毛利率假设、费用率假设）、在手订单与管线、达成盈亏平衡所需的收入规模测算。
