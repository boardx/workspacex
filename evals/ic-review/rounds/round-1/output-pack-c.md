# 三、跨文档交叉验证

## 【显性矛盾】

### X-1 收购范围自相矛盾：云服务转售到底买不买
- **问题**：情况说明称收购「含 IDC 托管、云服务转售、运维外包三条产品线」；重组方案称「云服务转售业务相关代理协议和客户合同不纳入本次重组范围，由卖方继续持有」。两份材料对交易标的的定义直接冲突。
- **原因**：可能是范围在起草过程中调整而情况说明未同步，也可能是刻意保留高收入低毛利业务以撑大「板块收入」叙事。无论哪种，投委会目前不知道自己在买什么。
- **材料中如何体现**：情况说明 一、交易背景「含 IDC 托管、云服务转售、运维外包三条产品线。初步对价 9.8 亿元」；重组方案 一、重组范围「云服务转售业务相关代理协议和客户合同不纳入本次重组范围」。
- **影响测算**（算式与出处）：
  - 合并口径收入 = 42,000 + 34,000 + 21,000 = 97,000 万元（附注 4）
  - 实际注入口径收入 = 42,000 + 21,000 = 63,000 万元
  - 差异 34,000 万元，占合并口径 **35.1%**（34,000 ÷ 97,000）
  - 毛利影响：合并毛利 15,960 + 1,020 + 4,620 = 21,600 万元；注入口径毛利 = 20,580 万元，仅少 1,020 万元（4.7%）
  - 即：被剥离业务贡献了 35% 的收入却只贡献 4.7% 的毛利。
- **建议追问**：① 以书面确认最终交易范围；② 若排除云服务转售，请提供**仅注入资产口径**的三年备考收入、毛利、净利润、现金流；③ 9.8 亿元对价对应的是哪个口径——如果对价谈判时用的是 9.7 亿元收入的板块故事，而交割拿到的是 6.3 亿元收入的资产，需要重新定价。

### X-2 客户集中度陈述与附注数据严重不符
- **问题**：情况说明称运维外包「部分客户与卖方集团存在关联关系，客户关系总体稳定」；附注数据显示关联方占运维外包收入近八成。「部分」这个措辞与事实不符。
- **原因**：风险提示的措辞淡化了实质，可能出于卖方立场，也可能是买方尚未做穿透。
- **材料中如何体现**：情况说明 4.1「运维外包部分客户与卖方集团存在关联关系，客户关系总体稳定」；附注 3.1 锐思信息 8,200 / 39.0%、云桥云计算 4,500 / 21.4%、星链数字传媒 3,680 / 17.5%。
- **机械核算**（分母来自附注 4 运维外包收入 21,000 万元）：
  - 8,200 ÷ 21,000 = 39.05%（与披露 39.0% 一致）
  - 4,500 ÷ 21,000 = 21.43%（与披露 21.4% 一致）
  - 3,680 ÷ 21,000 = 17.52%（与披露 17.5% 一致）
  - 三家合计 = 8,200 + 4,500 + 3,680 = **16,380 万元，占运维外包收入 78.0%**

### X-4 会计政策变更的时点与业绩承诺期起点完全重合

### X-5 对价 9.8 亿元与可辨认净资产之间约 8 亿元的差额无任何解释
- **机械核算**（全部输入项来自重组方案 二）：
  - 注入设备原值合计 = 28,500 + 4,800 + 12,000 = 45,300 万元

  - 设备净值合计 = 10,300 + 2,700 + 5,200 = **18,200 万元**（与原值-累计折旧 45,300 − 27,100 = 18,200 勾稽一致）

- **问题**：这 7.98 亿元中包含土地使用权、房屋建筑物、在执行合同价值、以及商誉，但材料**没有给出土地和房屋的账面价值或评估值**，因此商誉规模目前无法确定，可能在数亿元量级。

### X-6 服务器 10 年折旧年限显著长于行业惯例，净值可能虚高
- **机械核算**（输入项：重组方案 二 + 附注 2）：

### X-7 云服务转售 3% 毛利率 + 96% 采购来自单一关联方，业务实质存疑
