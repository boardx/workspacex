## 三、跨文档交叉验证

### 1. 显性矛盾

**（1）客户集中度口径不一致，且差距达 16 个百分点**

- 问题：尽调报告称前五大客户收入占比"约 42%"，财务摘录的客户明细加总为 58.1%。
- 原因（待核实的可能解释）：①两份材料统计期间不同（尽调可能用 FY2024 或滚动口径）；②同一集团下的关联客户在一份材料中合并、另一份未合并；③尽调报告笔误或引用了旧版数据。三种解释指向的风险等级完全不同。
- 材料中如何体现：
  - 尽调报告 2.2："前五大客户收入占比约 42%，最大客户为马来西亚某半导体封测集团，2025 年收入贡献约 18%。"
  - 财务摘录"主要客户销售明细（FY2025）"：706 + 548 + 432 + 352 + 240 = **2,278 万新元**；2,278 ÷ 3,920 = **58.11%**。逐项占比加总：18.0% + 14.0% + 11.0% + 9.0% + 6.1% = **58.1%**，与金额法一致。
  - 每个输入项出处：706/18.0% = Malaysia SemiPack Group；548/14.0% = 苏州晶方半导体科技；432/11.0% = PT Astra Otoparts Tbk；352/9.0% = 深圳比亚迪电子；240/6.1% = Flex Ltd. (Penang)；分母 3,920 = 财务摘录"合计 3,920 100%"，亦等于主要财务数据表 FY2025 营业收入。
  - 注：两份材料对**最大客户** 18% 的口径是一致的，说明不是整体期间错配，更可能是"前五大"的计算或引用出错。
- 建议追问：请提供 FY2023-FY2025 三年各自的前五大客户明细（含关联方合并口径说明），并说明尽调报告 42% 的计算过程与数据来源。若实际为 58.1%，客户集中风险的定性与估值折价都需重估。

**（2）收入确认政策两份材料直接冲突（两处冲突点）**

- 问题：设备销售与技术服务的收入确认时点/方法，在两份材料中给出的是不同政策。
- 原因：可能是①尽调团队描述的是标的对外声称的政策，而财务摘录反映的是实际账务处理；②政策在期间内发生过变更未披露；③其中一份表述错误。第①种情况意味着账面收入的确认时点早于应有时点。
- 材料中如何体现：

| 收入类型 | 尽调报告 3.1 | 财务摘录 附注 2 | 是否冲突 |
|---|---|---|---|

**（1）研发资本化率三年从 30.9% 升至 65.0%，且资本化金额的增长吞掉了大部分亏损扩大**

- 问题：资本化率逐年大幅攀升，且无任何解释。
- 算式与出处（全部来自财务摘录"主要财务数据"及附注 5）：
  - FY2023：210 ÷ 680 = **30.9%**
  - FY2024：480 ÷ 920 = **52.2%**
  - FY2025：878 ÷ 1,350 = **65.0%**（附注 5 自述"资本化率 65%"，与计算一致）
- 按"研发全部费用化"口径重算净利润（算式：报表净利润 − 当期资本化金额，未考虑已资本化部分的摊销影响，故为保守估计的上限值）：
  - FY2023：-580 − 210 = **-790 万新元**
  - FY2024：-850 − 480 = **-1,330 万新元**
  - FY2025：-1,200 − 878 = **-2,078 万新元**
  - 即：账面亏损三年扩大 1.07 倍（-580→-1,200），全费用化口径下扩大 1.63 倍（-790→-2,078）。资本化率的提升掩盖了约 **878 万新元**（FY2025）的当期损益压力，相当于当年账面亏损的 73%。
- 行业基准判断：**未取证的常识判断**——工业机器视觉/工业软件类企业在 IFRS/SFRS 下的研发资本化率，多数落在 0%-30% 区间，不少同业出于审慎完全不资本化；65% 属于显著偏高。且资本化的前提是"技术可行性、有意图并有能力完成、能产生未来经济利益、支出能可靠计量"，一家仍在亏损、且自述 FY2027 才盈亏平衡的公司，对 65% 的开发支出主张未来经济利益，需要额外证据。我没有外部数据支撑这一区间，请以此为待验证假设，不要直接引用进上会材料。
- 关联影响：资本化的 878 万新元形成无形资产，若收购后会计政策拉齐为费用化、或触发减值，将直接冲击投后利润与商誉减值测试——而材料中没有商誉减值压力测试（IC-3-8 缺失）。
- 建议追问：①逐项目列示 FY2023-FY2025 资本化的开发项目清单、各自开始资本化的时点与技术可行性判定依据；②已资本化无形资产的摊销政策、摊销年限、期末账面净值与累计摊销；③是否做过减值测试；④审计师（若后续引入）对资本化率提升的意见；⑤按集团会计政策拉齐后重述的三年利润表。

**（2）应收账款增速远超收入增速，周转天数恶化近一倍**

- 问题：应收账款质量快速劣化，材料未作任何解释。
- 算式与出处（财务摘录"主要财务数据"）：
  - 收入增速：FY2024 (2,680−1,850)/1,850 = **+44.9%**；FY2025 (3,920−2,680)/2,680 = **+46.3%**
  - 应收增速：FY2024 (580−320)/320 = **+81.3%**；FY2025 (1,280−580)/580 = **+120.7%**
  - FY2025 应收增速是收入增速的 **2.6 倍**
  - 应收占收入比：320/1,850 = 17.3% → 580/2,680 = 21.6% → 1,280/3,920 = **32.7%**
  - 周转天数口径核对：期末余额法 1,280 ÷ 3,920 × 365 = **119.2 天**，与披露的 118 天基本吻合；平均余额法 (580+1,280)/2 ÷ 3,920 × 365 = **86.6 天**。即披露使用的是**期末余额法**（更"难看"的口径，这一点披露是诚实的），但也意味着不能用披露值与采用平均法的同业直接对比。
- 可能原因：①收入确认时点前移至发货（见显性矛盾 2），收入先行而回款滞后；②为冲收入放宽信用政策；③大客户账期本身较长；④存在回款困难或潜在坏账。四种原因的处置方式不同，但都指向估值需要调整。
- 建议追问：①FY2025 期末应收账龄分析（按客户、按账期分段）；②坏账准备计提政策与计提金额（材料完全未提及坏账准备）；③期后回款情况（截至最近一期已收回多少）；④前五大客户各自的账期与逾期情况；⑤应收中有多少对应"已发货未验收"的设备。

**（3）毛利率三年上升 14 个百分点，同时亏损持续扩大**

- 问题：38% → 45% → 52%，三年提升 14pp，材料未解释驱动因素；且毛利率大幅改善的同时净亏损反而扩大。
- 算式与出处（财务摘录"主要财务数据"）：
  - FY2025 毛利额 = 3,920 × 52% = 2,038 万新元；费用化研发 = 1,350 − 878 = 472 万新元；毛利额 − 费用化研发 = 1,566 万新元，而净利润为 -1,200 万新元 → 隐含其余期间费用（销售/管理/财务等）及其他损益合计约 **2,766 万新元**，占收入 70.6%。
  - FY2023 同法：毛利额 = 1,850 × 38% = 703；费用化研发 = 680 − 210 = 470；703 − 470 = 233，净利 -580 → 隐含其余费用约 813 万新元，占收入 43.9%。
  - 即：其余期间费用占收入比从 43.9% 升至 70.6%，这是亏损扩大的主要来源，但材料完全没有费用明细。
- 行业基准判断：**未取证的常识判断**——工业机器视觉系统集成商毛利率通常在 35%-50%，纯软件/算法授权占比高的公司可更高。52% 本身不算离谱，但**三年连升 14pp 需要解释**（产品结构转向软件？规模效应？还是成本中本应计入的开发人力被资本化了？）。注意第三种解释与异常（1）直接相关：将本应计入营业成本的项目交付人力资本化，会同时推高毛利率和资本化率——两个指标恰好同步上行（毛利率 38→45→52，资本化率 31→52→65），这一同步性值得单独核查。无外部数据支撑，请勿直接引用。
- 建议追问：①三年分产品线（设备/软件/服务）的收入与毛利率拆分；②营业成本构成明细，特别是研发人员成本在"营业成本 / 研发费用 / 资本化"三者之间的分摊规则；③完整利润表（销售费用、管理费用、财务费用逐项）；④是否存在成本归集口径在期间内的变更。
