## 任务三：跨文档交叉验证

### X-1【显性矛盾｜重大】收入确认政策两份材料口径不一致

- **问题**：设备销售与技术服务的收入确认时点/方法，在尽调报告与财务摘录中是两套写法。
- **原因**：尽调报告可能引用了标的对外口径或修订后政策，财务摘录反映管理层报表实际执行口径；也可能是期间发生过政策变更未披露。在两份材料并列提交给投委会的情况下，无法判断哪一套是账上真正执行的。
- **材料中如何体现**：
  - 尽调报告 3.1：「设备销售按客户现场验收确认后确认收入……技术服务按服务期间分期确认」
  - 财务摘录 附注 2：「设备销售在产品发出并取得物流签收凭证时确认收入……技术服务按完工百分比法确认」
- **影响方向**：「发出签收」早于「现场验收」。工业视觉检测设备需现场调试与验收，两个时点间隔可能跨季度甚至跨年度。若账上按发出确认而尽调按验收描述，FY2025 的 3,920 万新元收入中包含尚未验收的部分，且这与 X-4 的应收账款异常方向一致、互相印证。
- **建议追问**：要求提供标的正式的收入确认会计政策文件与审计师意见，并按「现场验收」口径重述 FY2023-2025 收入与应收账款；说明报告期内政策是否发生过变更及变更时点。

### X-2【显性矛盾｜重大】前五大客户集中度 42% vs 58.1%，差 16.1 个百分点

- **问题**：尽调报告的集中度结论与财务摘录客户明细加总对不上，且风险章节据前者下结论。
- **原因**：极可能是取数错误——42% 与明细中「其他」客户的 41.9% 高度吻合，怀疑撰写者误将「其他」占比当作「前五大」占比。
- **材料中如何体现**：
  - 尽调报告 2.2：「前五大客户收入占比约 42%」
  - 财务摘录 主要客户销售明细（FY2025）：18.0% + 14.0% + 11.0% + 9.0% + 6.1%；「其他 1,642 41.9%」
- **机械核算**（输入项全部来自财务摘录「主要客户销售明细（FY2025）」，收入合计 3,920 万新元来自同表「合计」行，与「主要财务数据」FY2025 营业收入 3,920 一致）：
  - 前五大金额合计 = 706 + 548 + 432 + 352 + 240 = 2,278 万新元
  - 前五大占比 = 2,278 ÷ 3,920 = **58.11%**
  - 交叉验证：100% − 41.9%（其他） = 58.1%，两种算法一致
  - 与报告口径差 = 58.1% − 42% = **16.1 个百分点**
  - 明细加总核对：706+548+432+352+240+1,642 = 3,920 ✓（明细内部自洽，问题出在尽调报告的结论句）
  - 第一大客户 706 ÷ 3,920 = 18.01%，与尽调报告「约 18%」一致 ✓
- **建议追问**：请项目组确认 58.1% 为准并修订尽调报告 2.2 与风险章节 4.2 的结论；同时说明前五大客户的合同期限、是否独家、有无续约条款与退出成本；并提供 FY2023、FY2024 的同口径客户明细以判断集中度趋势。

### X-3【隐性异常】研发资本化率三年从 30.9% 升至 65.0%，无解释（前提未取证）

- **问题**：资本化比例逐年大幅抬升，直接减少当期费用、改善利润表，材料对此没有任何说明。
- **材料中如何体现**：财务摘录「研发费用 680 / 920 / 1,350，其中：资本化金额 210 / 480 / 878」；附注 5「资本化率 65%」。
- **机械核算**（输入项均来自财务摘录「主要财务数据」行）：
  - FY2023 资本化率 = 210 ÷ 680 = **30.9%**
  - FY2024 资本化率 = 480 ÷ 920 = **52.2%**
  - FY2025 资本化率 = 878 ÷ 1,350 = **65.0%**
  - 若按 FY2023 的 30.9% 口径重算 FY2025：应资本化 = 1,350 × 30.9% = 417 万新元；多资本化 = 878 − 417 = **461 万新元**
  - 按此重算 FY2025 净利润 = −1,200 − 461 = **约 −1,661 万新元**（亏损扩大 38.4%）
  - 若 FY2025 研发全额费用化：净利润 = −1,200 − 878 = **约 −2,078 万新元**
- **未取证的常识判断**：「同一家公司在产品形态未变的情况下，开发阶段支出占比两年内翻倍，通常需要有产品化节点或政策变更来解释」属行业惯例判断，本次材料未提供任何佐证，也未取得外部数据支撑。
- **建议追问**：提供分研发项目的资本化判断底稿（进入开发阶段的时点依据、技术可行性与商业可行性证据）、资本化资产的摊销政策与已摊销额、报告期内是否发生会计估计变更、有无减值测试。

### X-4【隐性异常】应收账款增速远超收入，周转天数由 62 天升至 118 天
