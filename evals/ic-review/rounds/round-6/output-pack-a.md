## 任务一：资料汇总提纲

**1. 交易概况**
拟以现金方式收购锐恒精密制造有限公司 100% 股权，初步估值 6.2-6.8 亿元；交易对方为创始人李建国及配偶王芳，合计持股 92%。
出处：A 文件 1.2「拟现金收购 100% 股权，初步估值 6.2-6.8 亿元。交易对方为创始人李建国及配偶王芳，合计持股 92%」。

**2. 标的**
2012 年成立于苏州工业园区，注册资本 8,000 万元；主营高精度金属结构件研发生产销售，下游为新能源汽车电驱系统、航空航天液压组件、半导体设备精密部件；员工约 420 人，其中研发 68 人。自述竞争力为「技术领先，客户优质，进入多家行业头部企业供应链体系；团队稳定，核心管理层平均司龄超过 8 年」。
出处：A 文件 1.1、1.3。

**3. 行业**
2025 年中国精密金属结构件市场约 2,800 亿元，2026-2030 年 CAGR 约 9.2%；新能源汽车相关细分约 680 亿元，增速高于均值。行业 CR10 约 18%，标的在新能源电驱结构件细分份额约 1.2%、国内前十。
出处：A 文件 2.1、2.2。

**4. 财务**
三期（年份未标注）营业收入 38,500 / 46,200 / 52,000 万元；净利润 3,200 / 4,100 / 4,800 万元；毛利率 28.5% / 30.2% / 31.0%；净利率 8.3% / 8.9% / 9.2%。材料归因为新能源占比提高及效率改善。
出处：A 文件三、3.2。材料中无资产负债表、现金流量表、审计意见状态说明。

**5. 估值**
方法为收益法（DCF）＋市场法（可比公司法）；DCF 假设永续增长率 2%、WACC 10.5%，得出企业价值 6.5 亿元；结论区间 6.2-6.8 亿元，对应 2025E 净利润 12.9x-14.2x PE。
出处：A 文件 4.1、4.2。可比公司法的可比样本与结果未披露。

**6. 尽调**

**7. 投后**

## 任务三：交叉验证（本次仅 1 份材料，故以单份内部一致性与行业常识核对为主）

### X-1【重大 · 隐性异常】市占率 1.2% 与标的收入规模不自洽
- **问题**：2.2 称在新能源电驱结构件细分份额约 1.2%，但按材料自身数据回算，任何一个可能的分母都与标的收入对不上。
- **机械核算**（分子分母出处与口径均标注）：
  - 口径 A：分母＝2.1「新能源汽车相关细分约 680 亿元」（出处：2.1，行业合计口径）→ 680 亿 × 1.2% = **8.16 亿元**；而分子侧标的最近一期营业收入＝52,000 万元＝**5.2 亿元**（出处：三，公司合计口径，且含航空航天、半导体两块非新能源业务）。5.2 < 8.16，隐含的新能源业务收入还应小于 5.2 亿元，差距至少 2.96 亿元。
  - 口径 B：分母＝2.1「2025 年中国精密金属结构件市场约 2,800 亿元」→ 2,800 亿 × 1.2% = **33.6 亿元**，与 5.2 亿元差 6.5 倍，更不成立。
  - 反算：若份额 1.2% 成立且分母为 680 亿，则标的新能源收入须达 8.16 亿元；若标的新能源收入实为总收入的一半（2.6 亿元），则真实份额约 2.6 / 680 = **0.38%**。
  - （除法复核：680 × 0.012 = 8.16 ✓；2800 × 0.012 = 33.6 ✓；2.6 / 680 = 0.00382 ✓）
- **原因**：分子很可能用了标的全口径收入或某个未披露的口径，分母用了细分市场；也可能「电驱结构件」另有更小的市场口径未在材料中给出。
- **体现**：2.1、2.2 与「三、财务摘要」收入行并列即可见。
- **建议追问**：要求给出 1.2% 的分子（哪一年、哪些产品线、多少金额）与分母（哪一口径市场、多少金额、数据来源与报告名称），并提供收入按下游行业（新能源/航空航天/半导体）的拆分表。「国内前十」的排名依据（第三方报告或客户端份额）一并提供。

### X-2【重大 · 隐性异常】「近三年营收增长 15%+」与明细不符，且增速在下行
- **问题**：3.2 称「近三年营收增长 15%+」，但按三、财务摘要的收入行逐期计算，最近一期增速为 12.55%，不足 15%，且较上一期明显放缓。
- **机械核算**：
  - 期 2 / 期 1 = 46,200 / 38,500 = 1.2000 → **+20.00%**（分子分母均出自「三、营业收入（万元）」行，同一层级）。
  - 期 3 / 期 2 = 52,000 / 46,200 = 1.1255 → **+12.55%**（同上）。
  - 三期 CAGR = (52,000 / 38,500)^(1/2) − 1 = (1.3506)^0.5 − 1 = 1.1621 − 1 = **+16.21%**。
  - （复核：38,500 × 1.2 = 46,200 ✓；46,200 × 1.1255 = 52,000 ✓；1.1621² = 1.3505 ≈ 1.3506 ✓）
- **判读**：「15%+」只有在按两期 CAGR 表述时才成立（16.2%）；若读作「每年增长 15%+」则与最近一期 12.55% 不符。更实质的问题是增速从 20.0% 降至 12.55%，材料的定性表述（「增长 15%+」＋「受益于新能源占比提高」）掩盖了减速趋势，而 DCF 的永续与预测期假设正建立在这条增长线上。
- **建议追问**：明确「15%+」的计算口径；提供分季度收入与在手订单/意向订单金额，说明最近一期减速原因；提供 DCF 预测期逐年收入增速假设，与历史 20.0%→12.55% 的趋势对齐说明。

### X-3【重大 · 隐性异常】财务表三列无年份、无审计状态，却被直接用作估值基准
- **问题**：「三、财务摘要」的三列数据没有年份表头，也未说明是否经审计；4.2 却用「2025E 净利润」作为 PE 倍数的分母。
- **机械核算与判读**：6.2 亿 / 4,800 万 = **12.92x**；6.8 亿 / 4,800 万 = **14.17x**（分子出自 4.2 估值区间，分母推定为财务表第三列净利润 4,800 万元）。与材料所写「12.9x-14.2x」吻合，说明第三列的 4,800 万元被当作 **2025E（预测数）**使用。但该列同时被 3.2 当作已实现的历史业绩来归因（「毛利率稳步提升，受益于……效率改善」）。

### X-4【重大 · 隐性异常】企业价值（EV）与股权价值口径未衔接
