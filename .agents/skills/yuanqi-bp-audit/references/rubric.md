# 逐模块评分细则（Rubric）

每模块 10 分，按检查点给分，落档取整（0/3/5/7/9-10 五档为主）。证据必须引自 BP 原文；信息不足标"未知"并给补查路径，**不得脑补**。改写方向必须落到句子级。

**通则**：模块内容缺失 → 0 分。模块存在但写成传统口径（愿景堆砌、功能清单、TAM 独白）→ 0–3 分。模块成立且有可验证指标 → 7 分起。可验证指标 ＋ 下一周期目标 ＋ 失效信号齐全 → 9–10 分。

---

## 模块 1 · 缘起陈述（10 分）

| 检查点 | 分值 |
|---|---|
| 列出"哪些条件变化使此事现在成为可能"（技术、成本、监管、行为变化） | 3 |
| 条件正在汇合的具体证据（客户、场景、数据、制度，不是宏观叙事） | 3 |
| 反脆弱一问：拿掉哪个条件整盘不成立（可测的"单点依赖"） | 3 |
| 未退化成公司简介/问题宣言/宏大愿景 | 1 |

- **0–3 分典型**：开篇是"公司致力于……成立于……"或"AI 时代大势所趋"。
- **9–10 分典型**："大模型推理成本 18 个月降 X 倍 ＋ 某行业数据接口 2025 年强制开放 ＋ 客户验收标准刚成文——三者汇合使自动化验收成为可能；拿掉数据接口开放，全盘不成立。"

## 模块 2 · 缘起链地图（10 分）

| 检查点 | 分值 |
|---|---|
| 六环齐全：需求触发→数据进入→机器判断→行动执行→结果验证→经验回流 | 4（缺一环 −0.5 起，断在验证之后 −2） |
| 标出关键参与者与依赖条件 | 2 |
| 标出断点（哪里靠人、哪里靠运气、哪里还没跑通） | 2 |
| 指明企业"处于"链路哪一位置 | 2 |

- 画了流程图但全是自家部门名、没有外部节点 → 参与者项 0 分。
- 六环只写了前四环（到结果验证为止，经验回流缺失）——这是最高频断点，扣重，且镜二联动红灯。

## 模块 3 · MVL 最小可验证自治闭环（10 分）

五信号逐项 2 分：

| 信号 | 2 分标准 |
|---|---|
| 自治 | 指得出具体业务，哪一步机器独立拍板、边界在哪、人何时接管 |
| 验证 | 结果可自动或低成本核验，验证方式写明（对账、抽样、回放、双向校验） |
| 迭代 | 回流路径写明：结果如何变成下一次判断的输入 |
| 信任 | 责任、权限、人工接管与审计机制四项至少三项落名 |
| 生长 | 闭环能扩展的新场景、节点、连接被具体点名 |

- 功能清单冒充闭环（"支持智能报告生成、智能客服、智能分析"）→ 0–2 分。
- "接入 GPT／接入大模型"类表述不构成自治证据。
- 五信号全过且给出闭环的运行数据 → 10 分。

## 模块 4 · 网络位置与市场（10 分）

| 检查点 | 分值 |
|---|---|
| 连接了谁（可命名的节点，不是"广大客户"） | 2 |
| 哪些高频价值流流经本节点（频次、方向） | 3 |
| 替代哪段旧流程/旧成本/旧协调方式（可对比） | 2 |
| 被上游平台吸收的风险自答 | 2 |
| TAM 服从网络位置解释（而非独立存在） | 1 |

- 只有 TAM/SAM/SOM 三圈图 → 1 分。
- "护城河"作为答案出现 → 本模块记 0 分（叙事反判据，见词表）。

## 模块 5 · 递归引擎（10 分）

五环链条：交付→数据→改善→成本/成功率→更多使用→回流。

| 检查点 | 分值 |
|---|---|
| 五环链条完整且顺序成立 | 4 |
| 每一环有可验证指标（回流周期、改善幅度、成本曲线） | 4 |
| 写成引擎而非漏斗（未退化为获客-转化-留存） | 2 |

- 写了"数据飞轮"三个字但链条断裂（说不清改善如何带来更多使用）→ ≤3 分。
- "数据飞轮"是本模板最高频的假动作——**飞轮要数齿**：几个齿、咬合处何在、转一圈多久。

## 模块 6 · 四变量仪表盘（10 分）

| 检查点 | 分值 |
|---|---|
| V 公式被正确使用（作为表达框架，不是装饰） | 1 |
| M/D/P/r 各有当前状态描述 | 3 |
| 各有下一周期目标 | 2 |
| 各有可验证指标（如何观测 M 的变化？r 用什么衡量？） | 3 |
| 未退化成收入预测表 | 1 |

- r 写成"增长率"而无递归定义（每轮哪项指标变强多少）→ r 项不得分。
- t 必须是递归周期（轮数），写成日历时间 → 扣 1 分。

## 模块 7 · 条件离散风险（10 分）

六类离散源逐项检查（模型算力/数据授权/客户开放/验证成本/平台监管/节点脱钩），每项落条件需四件套：

| 检查点 | 分值 |
|---|---|
| 覆盖离散源 ≥4 类且是本业务真实依赖 | 3 |
| 每项有失效信号（可观察、可提前报警） | 2 |
| 每项有受影响回路（指明哪条链停转） | 2 |
| 每项有备用因缘与人工接管方案 | 3 |

- 名目式风险清单（"政策风险、市场风险、技术风险"三行字）→ 0 分，且触发一票否决第 3 条。
- "预留 20% 现金"式笼统缓冲 → 缓冲项 0 分（在融资核账中再点名一次）。

## 模块 8 · 30-60-90 天递归路线图（10 分）

| 检查点 | 分值 |
|---|---|
| 三阶段名称与判据正确（闭环/递归/耦合成立） | 3 |
| 每阶段验收是可观察证据（不是"完成开发"） | 4 |
| 60 天阶段证明"下一轮优于上一轮"（有对比指标） | 2 |
| 90 天阶段写明扩展条件、信任机制与经济指标 | 1 |

- 里程碑全是"上线、招聘、签约" → 开发口径，≤3 分。

## 模块 9 · 投资人缘起三问（10 分）

| 检查点 | 分值 |
|---|---|
| 三问都答了（不是只列问题） | 2 |
| 第一问：钱接通的具体因缘被点名（接口、节点、团队、授权） | 3 |
| 第二问：加快哪个回路 ＋ 量化指标 | 3 |
| 第三问：下一递归层新增的是收入还是 M/D/P/r，有明确回答 | 2 |

- 答成"资金将用于产品研发与市场拓展" → 0–2 分。

## 三公理对齐（6 分，A/B/C 各 2 分）

| 档 | 标准 |
|---|---|
| 2 分 | 公理被有意识引用，且落实为具体设计选择（定价、组织、数据策略因此不同） |
| 1 分 | 有意识引用，但只在引言出现，未影响正文设计 |
| 0 分 | 缺失，或与公理相反（按智能成本不变定价、经验即用即弃、价值全归内部存量） |

## 语言清洁度（4 分）

逐千字清点自性动词（词表见附录）。判定按 SKILL.md 第 3 节：≤2 处 4 分；3–5 处 2 分；≥6 处或成段使用 0 分（成段使用同时触发一票否决第 4 条）。

**判卷提醒**：自性动词扎堆处往往就是回路断点处——"我们拥有最大的数据池"一句背后，多半写不出数据流速 D。每处高密度都标记为模块审计疑点。

## 附录 A · 自性动词词表与替换对照

**扫描词表**（含变体）：拥有、持有、掌控、控制、垄断、霸占、占领、占据、壁垒、护城河、护城河效应、打造壁垒、构建壁垒、MOAT（作册标题时）、牢牢掌握、独家掌握、先发优势、领先优势、市场地位、王者、制霸、封杀、卡位（自称时）。

**软性自性词**（不直接计入语言扣分，但必须检查其后有没有实证，无实证则视为空转）：AI 赋能、AI 驱动、最先进大模型、数据飞轮、网络效应、生态闭环。

**替换对照**：

| 自性写法 | 缘起写法 |
|---|---|
| 我们拥有行业最大的数据池 | 某场景数据流经本节点，日流速 X，回流周期 Y 天 |
| 我们构建了深厚的护城河 | 本节点与 Z 节点形成耦合，替换成本为 A |
| 我们占领了细分市场 | 该段旧流程的协调成本正在流经我们 |
| 我们控制了供应链 | 我们处于供需两端的判断环节，双向数据在此汇合 |
| 我们的技术壁垒领先 | 此判断链迁移至他家的重构成本为 B 月 |
| 我们垄断了客户关系 | 客户流程中三处接口与我们耦合，脱钩需改造 C 项 |

**边界说明**：转述竞品行为、引用行业术语、脚注引语中的自性动词不计入；作为被检讨对象出现（"传统写法说护城河，我们答耦合"）反计正向证据。

**"名自性、实缘起"判定规则**（2026-10 实战修正）：自性词只充当小标题或名词、而其下写的是递归机理（"逐期累积""每一期降低下一期成本""位置来自供给质量与关系密度"）时，判为**措辞问题而非论证问题**——只扣语言分，**模块 4 不归零**。归零只在一种情形：自性词本身就是答案、且它替代了网络位置的论证（删掉这个词，模块便无内容）。判词须写清这一点，让对方知道改一个词就能拿回分。

## 附录 B · 好坏写法对照（判卷手感校准）

**MVL——装饰写法**：
> 我们接入了最先进的大模型，AI 全方位赋能业务流程，大幅提升效率。

判：自治证据 0。机器在哪一步拍板？边界在哪？全无。0–2 分。

**MVL——原生写法**：
> 信用初审环节，机器独立完成端到端判断：资料解析→风险评分→授信建议，全程无人工；单件处理成本从 40 元降至 1.2 元；抽检驳回率 2.1% 作为自动验证；每笔人工修正回流为标注数据，下月模型驳回率目标降至 1.8% 以下；触发红线条件（金额 >50 万）自动转人工，接管 SLA 4 小时。

判：五信号全过，有运行数据。10 分。

**风险——许愿写法**：
> 主要风险包括政策风险、市场竞争风险和技术迭代风险，我们将保持关注并预留 20% 现金。

判：名目清单＋笼统缓冲。0 分，触发一票否决第 3 条。

**风险——离散写法**：
> 核心模型接口离散风险：失效信号——调用量配额降至 X 以下或价格上调 >40%；受影响回路——初审闭环第 2 环（数据进入）；备用因缘——已接备用模型 B（精度低 3 个点，可降级运行）；人工接管——初审团队 6 人扩编预案，月成本 30 万；本项缓冲 = 50 万 × 4 月 + 100 万改造 = 300 万。

判：四件套齐全、可折算。10 分。
