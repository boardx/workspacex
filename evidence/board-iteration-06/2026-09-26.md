# Board Iteration 06 Web integration evidence

This iteration connects the multi-selection UI to the canonical selection-layout command port. Align (six directions), horizontal and vertical distribution, Grid, Row, Column, and Tidy Up share one contextual toolbar. Grid columns and the 24 px default gap are user-adjustable. Every dispatch carries geometry, parent, lock, and hidden preconditions for the complete ordered selection and commits through one canonical command transaction.

Fabric now projects an ordered multi-selection as `ActiveSelection`, retains canonical selection order in callbacks, and shows deterministic alignment guides and equal-spacing measurements while moving. Layout calculations use Fabric-compatible rotated scene bounds for visual alignment. Read-only boards and selections containing locked objects disable all layout mutation controls.
