# Board Iteration 06 Web integration evidence

This iteration connects the multi-selection UI to the canonical selection-layout command port. Align (six directions), horizontal and vertical distribution, Grid, Row, Column, and Tidy Up share one contextual toolbar. Grid columns and the 24 px default gap are user-adjustable. Every dispatch carries geometry, parent, lock, and hidden preconditions for the complete ordered selection and commits through one canonical command transaction.

Fabric now projects an ordered multi-selection as `ActiveSelection`, retains canonical selection order in callbacks, and shows deterministic alignment guides and equal-spacing measurements while moving. Layout calculations use Fabric-compatible rotated scene bounds for visual alignment. Read-only boards and selections containing locked objects disable all layout mutation controls.

## Independent review remediation

- Canonical geometry now has one enforced convention: `x/y` is the unrotated
  top-left rotation origin. Fabric outer objects explicitly use `originX=left`
  and `originY=top`. A real (unmocked) Fabric geometry test cross-checks scene
  bounds at 0°, 37°, 90° and -45°.
- Align, distribute, row, column, grid and tidy-up share rotated scene bounds.
  Panel containment and auto-expand transform rotated child corners into panel
  local space. Smart guides and equal-spacing measurements also use scene bounds.
- Layout CAS is mandatory. The precondition builder covers selected roots plus
  every implicit geometry mutation: descendants, attached connectors and an
  auto-expanded parent. Missing or stale members close with a conflict before
  the single canonical transaction.
- The browser acceptance now exercises all twelve layout operations. For each
  operation it asserts changed canonical geometry, observes the same geometry
  from an independent second browser context, then verifies one Undo restores
  both clients to the exact original geometry. It finally reloads and checks the
  restored state. Per assignment, this real-service E2E remains for the main
  session and was not run here; no Docker stack was started.

## Independent re-review remediation

- Added Equal Width, Equal Height and Equal Size to the shared closed contract,
  core implementation and contextual toolbar.
- Added Smart Layout preview as an explicit zero-write operation. Cancel removes
  only the preview; Apply reuses the original guarded command. Any intervening
  Yjs revision, including geometry ABA, text/style changes, connector endpoint
  changes or Panel metadata changes, closes with `LAYOUT_CONFLICT`.
- CAS now carries both full-object state fingerprints for the explicit and
  implicit mutation set and a Yjs state-vector revision fence. This protects
  descendants, attached connectors and auto-expanded parents.
- Fabric ActiveSelection move/resize/rotate decomposes each child's world
  transform and submits one canonical geometry batch. Move, scale and rotation
  show scene-bound guides; holding Alt bypasses snapping. ActiveSelection snap
  excludes every selected child from targets.
- Layout selection is capped at 500 objects. The canonical transaction budget is
  1,000 commands to leave room for connectors and parent expansion; 500 objects
  are tested as one Yjs transaction and one Undo unit.
- Browser acceptance now checks semantic geometry for all fifteen operations,
  exact second-client state and one-step Undo. It also covers Smart Preview's
  zero-write/cancel path and a real second-client concurrent-revision conflict.
  Rotated layout/Panel containment and snap behavior have deterministic core and
  real-Fabric integration coverage. The real-service browser spec was parsed but
  not run here, per the no-Docker assignment.

## Final independent review remediation

- ActiveSelection exposes corner controls only and normalizes every live scale
  gesture to a uniform transform before snapping. The canonical boundary also
  decomposes each real Fabric world matrix and rejects any residual skew rather
  than silently persisting an unrepresentable object. Unmocked Fabric tests prove
  that non-uniform scaling of a rotated child is rejected and uniform
  scale-plus-rotation remains representable.
- Move, resize and rotation now share position guides; rotation also snaps to
  nearby object angles and 15 degree increments. World-space position thresholds
  are divided by the current Fabric zoom so the hit area remains five screen
  pixels at every supported viewport scale. Alt still bypasses snapping.
- Smart Layout exposes selectable zero-write previews for Grid, Cards, Cluster,
  Journey, Mind Map, Flow and Timeline. While a preview is open, Fabric writes,
  creation, editing, paste, delete, Undo/Redo, layout buttons, the title and dock
  tools are fenced until Apply or Cancel. Apply remains revision guarded.
- Browser acceptance now verifies exact three-column Grid/Tidy row sizes, 24 px
  horizontal and vertical gaps and the required selection/visual ordering. It
  additionally specifies real pointer-driven ActiveSelection batch movement and
  guide-visible snap gestures, then checks second-client convergence and one-step
  Undo. Per assignment, the service E2E was listed but not run; no Docker stack
  was started.
