## CI contract-boundary correction

The PR gate exposed a real HTTP contract gap: resource controllers emitted the
closed `whiteboard.WhiteboardErrorCode`, but the global exception boundary did
not yet register that enum, so conflict responses lost their recoverable
`reasonCode`. The boundary now parses the contract enum before projection and
continues to reject arbitrary exception strings.
