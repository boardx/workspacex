## Negative evidence covered

- Header-only PNG/JPEG/GIF inputs fail full raster decode; declared oversized dimensions are rejected before decoder allocation; decoded bitmaps close on invalid or mismatched dimensions.
- VP8, VP8L, and VP8X WebP headers all receive a bounded predecode dimension/pixel check and a full-decode cross-check; unknown chunks and oversized claims never reach the decoder.
- Local selection, clipboard paste, and file drop retain verified bytes outside Yjs; remote URL import makes one bounded credentialless request and Fabric renders the resulting object URL.
- Duplicate/delete, image replace undo/redo, batch remote deletion, and editor unmount preserve then release session assets.
- `contentObject` uses a closed, recursively parsed schema. Unknown fields and nested extras are rejected, sensitive binary aliases reject even short strings, and nested `Blob`, `ArrayBuffer`, typed arrays, base64/data/blob URLs, mixed byte arrays, opaque base64url values, and fragmented chunks are rejected on create, update, remote validation, and copy. Normal short text remains accepted in outer plugin namespaces.
- Deferred local decode and remote fetch completion after editor unmount cannot mutate Yjs, register session assets, or leak object URLs; remote requests receive an abort signal.
- Local and remote decode requests receive abort signals. The DOM Image fallback clears `src`, removes handlers, revokes its temporary object URL, and rejects on abort or a bounded 15-second timeout.
- 513-point and 10,000-point drawings preserve both endpoints, sample deterministically, bound spacing error, and remain below the canonical extension budget.
