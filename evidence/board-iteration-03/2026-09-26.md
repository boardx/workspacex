# Board Iteration 03 — Thinking input acceptance

Issue: #4246

Implementation boundary: `729444ebb`

## Delivered behavior

- Sticky creation by toolbar, double click, drag/drop and `N`; square, rectangle
  and circle variants; eight presets plus custom color; auto-height, fixed and
  auto-size modes.
- Direct Text creation and editing with title/heading/subheading/body/caption,
  font, size, bold, italic, underline, color, alignment, line height, list and
  link metadata.
- IME-safe editing, Tab continuation at a 24px inferred row/column gap,
  `Shift+N` bulk input, and paste-as-stickies.
- Context toolbar for Sticky/Text color, shape, sizing, tags, reactions, links,
  duplicate and canonical delete.
- Provider backpressure keeps at most eight durable updates in flight, retains
  every unacknowledged update, replays the same IDs in FIFO order after reconnect,
  and coalesces presence behind durable writes.
- Create/delete history uses monotonic compensating commands. Undo writes real
  tombstones; redo restores with new IDs and remaps internal parent/connector
  references, so the server validator and every collaborator observe the same
  result without weakening tombstone or object-identity defenses.

The passing run used isolated PostgreSQL, Redis, MinIO, authenticated API,
WebSocket collaboration, Next.js and Chromium. It created 20 Stickies through
continuous input, verified them in a second live page, created three more in one
bulk operation, undid that batch in one action on both pages, redid it on both
pages, reloaded and observed all 23 objects from durable storage. Strict cleanup
permanently deleted the Board; the isolation wrapper removed stack
`wsx-77b13c61fd36b52dab4d`.

Two earlier acceptance runs were useful counterproofs rather than passing
evidence: one exposed an ambiguous `role=status` selector in the test; the next
showed the server correctly rejecting raw UndoManager deletion with
`VALIDATION_FAILED`, which led to the compensating-command implementation above.

This evidence does not authorize merge.
