## Integration boundary

The current sync awareness contract carries world cursor, selection, and editing object identity; it does not define a remote viewport payload. Object comments therefore use the canonical Yjs `commentThreads` root so owner/editor collaboration works through the existing provider. Viewer-authored durable comments require a server comment command endpoint because the gateway correctly rejects viewer document writes. These two contract additions remain integration work rather than UI claims.
