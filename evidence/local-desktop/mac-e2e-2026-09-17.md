## 2026-09-17 深夜：人类实测「skill 池为空 / 画像仍不出画布」——库里根本没有平台库

**现象**：安装版 app 里点 skill 挂载按钮显示「本组织没有『已启用』的 skill 可挂载」；
「生成一个用户画像」始终纯文本。API 直查（`/skills`、`/canvas/templates`，app 的 org）：**0 个 skill、0 个画布模板**。
之前 20/20 模板与 2/3 画像的实测都跑在我的源码栈上，安装版从没有过模板——decision B 的校正无物可校。

**根因（两层）**：
1. `apps/api/scripts/backfill-*.ts` 的入口守卫是 `import.meta.url === \`file://${argv[1]}\``。
   首次安装路径 `…/WorkspaceX Local.app/…` 含空格，`import.meta.url` 是 `%20`，字面量比较恒 false
   → 三个平台种子脚本**什么都没做、退出码 0**。
2. `packages/local-runtime/src/seeds.ts` 只信 `seed-state.json` 的 `platformSeeded: true`，
   不看库；库在 07:04 新建（desktop.log 第 1 行「database created」），种子状态却说已种，之后每次启动都跳过。
   另外 9 个标准 skill 包只有被本地版关掉的 API self-heal 会种，本地路径从未导入。

**修复**（`cli-entry.ts` + `seeds.ts` 探针 + `backfill-standard-skill-packs.ts`）：
- 入口守卫改为 `pathToFileURL(argv[1]).href === import.meta.url`（单测含空格路径反证）。
- owner phase 以超级用户直接数 `organizations/skills/canvas_templates` 里的 `org-platform` 行，缺什么种什么；

## 2026-09-18：「可以连接网络吗」——本地版从没挂过网页工具

**现象**：安装版里问「你可以连接 url 吗」答「无法访问」；给出具体网址后「工具 0 次」，还把读网页写成了 PESTEL 画布。
线程状态：全部 AI 消息 `tool_calls=[]`；系统提示 10 727 字符，其中画布指引约 6 000 字符；沙箱说明里有「NO network access」。

**根因（两层）**：
1. 本地跑 legacy profile（`KERNEL_NATIVE_RUNTIME=0`），`build_tools` 只挂 `list_org_skills / call_skill / spawn_async_task`；
   `fetch_url / web_search` 只在 native profile 的 `native_factory` 里。加了提示后模型去调，得到
   `Error: fetch_url is not a valid tool, try one of [ls, read_file, …, call_skill, spawn_async_task]`。
2. 4B 被画布指引和「沙箱无网络」带偏，把任何请求写成画布、把「沙箱无网」泛化成「我不能上网」。

**修复 `8c11c8dc4`**：本地（HITL 关闭）时 `build_tools` 追加 `*standard_web_tools()`，它们通过
`run_control_callback` 回调本机 API 的 `/internal/agent-runs/:runId/standard-web/invoke`（legacy run 也带该 callback）；
直出提示补三句：只有要画布时才写围栏、消息里有 http(s) 链接先调 fetch_url、「沙箱无网络」只指 run_script。

**实测（源码栈，全新库）**：
| 提示 | 工具 | 结果 |
|---|---|---|
| 分析网址 https://news.cnyes.com/… ×3 | fetch_url ×3（改前 0 次） | 页面本网络不可达（本机 curl `http=000`），工具按设计返回「unavailable or refused」，不再套画布 |
| 读取 https://www.ruanyifeng.com/blog/ | fetch_url → web_search | `/blog/` 是 302，fetch_url 明确拒绝重定向；web_search 返回真实结果 |
| 读取 https://www.ruanyifeng.com/blog/index.html | fetch_url | 返回 `sourceId/contentHash` 与正文，模型据正文作答（「共 2251 篇文章」） |
限制：fetch_url 不跟随重定向、要求 HTTPS 直连 200；本网络不可达的站点（cnyes、维基）失败是网络原因。
