## ① 全栈拉起 + 聊天（本地模型真实回复）

- `pnpm --filter @repo/local-runtime run up`：PGlite 迁移/种子 → Ollama（复用本机）→ 沙箱 3310 → ASR 网关 3320 → API 3200 → deep-agent 2024 → Web 3100，约 75 s 就绪。

- 修复前的四个连锁故障与修法见 issue #3716 评论（PGlite 单会话排队器 ×3、异常过滤器打死进程 ×1；停栈孤儿 worker 假就绪 ×1）。
