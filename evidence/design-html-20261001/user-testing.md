若需要登录，账号信息在本机 `/private/tmp/wsx-html-user-login.txt`。这是本次独立测试数据库，不是线上账号。

建议按这五步测试：

1. 进入「单页」，点击画布标题，确认左侧「针对」显示选中的文字。
2. 输入「只把这个标题改为 今天过得怎么样，其他内容保持原样」，点击发送。确认标题变了，近期日记与另一页未改。
3. 刷新页面：标题仍在。点击「撤销」后刷新：回到修改前。
4. 切「预览」，点击画面底部主按钮：跳到「写日记」。可以在原型内滚动到按钮。
5. 「更多」→导出→HTML，打开下载文件，点击第一页按钮：仍能跳到第二页。

也可以从「工作台」新建设计，描述你想做的产品。本次测试站已接入你批准的真实模型。生成可能需要等待，失败应有回执与重试入口。
